## 产品概述

完成菜单"14.工业级实战项目"章节的代办事项：将 `public/content/14-projects/` 下全部 26 篇文章中 `[!example]` 完整示例卡片的占位符（`// 📝 待补充实际示例代码`）替换为真实可运行、贴合上位机/工控场景的 WPF 示例代码（XAML + C# 两段代码块）。

## 核心功能

- 26 篇文章各编写 1 个可运行 WPF 示例，内容贴合文章知识点与所属项目主题（7 个项目分组：温湿度监控、Modbus PLC 看板、产线状态监控、智能仓储 WMS、视觉检测、多轴运动控制、SCADA 综合监控）
- 仅修改 `[!example]` 卡片，其余 9 个 Callout（plain/def/origin/essentials/scene/pitfall/best/practice/related）及 meta.json、src/styles、index.html 一律不动
- 示例遵循统一模板规范：命名空间 HmiDemo、类 MainWindow、深色工业风配色（背景 #0D1117、面板 #161B22、按钮 #21262D、强调蓝 #58A6FF、文本 #8B949E、成功 #238636、危险 #DA3633）、中文注释、XAML 事件/x:Name 与 C# 严格一一对应
- 用模拟数据与 DispatcherTimer 定时器代替真实硬件（串口/PLC/相机/运动控制卡等），保证示例可直接运行

## 技术栈

- 内容载体：Markdown 文档（项目为 Vite + 原生 JS + marked 的纯前端 SPA，示例为文档内代码块，非可编译工程）
- 示例语言：WPF / .NET，C#（.NET Core 3.1+ 兼容写法）+ XAML
- 编辑方式：仅用文件编辑工具替换 `[!example]` 卡片内占位符代码块

## 实现方案

### 策略

逐篇编辑 26 个 Markdown 文件，将占位符替换为"**MainWindow.xaml：**"+ xml 代码块 + "**MainWindow.xaml.cs —— 后台代码：**"+ csharp 代码块，格式严格参照已完成的 `public/content/04-controls/button-按钮.md` 与 `public/content/06-graphics/wpf-图形渲染概述.md`。

### 各篇示例主题规划（贴合知识点与项目场景）

- 14.1 温湿度监控（6 篇）：需求分析→模拟需求清单与架构图、系统设计与通信协议→自定义帧协议收发演示、串口数据采集→模拟串口数据接收与解析、实时曲线与仪表盘→Polyline+DispatcherTimer 动态绘制曲线、报警功能与历史数据→报警列表+上下限判定、ViewModel 与 UI 设计→INotifyPropertyChanged 双向绑定
- 14.2 Modbus PLC 看板（3 篇）：通信层封装→Modbus 寄存器读写模拟、看板 UI 与读写→寄存器值实时刷新看板、设备管理与采集调度→多设备轮询调度模拟
- 14.3 产线监控（4 篇）：系统架构设计→分层架构示意（数据层/业务层/UI 层）、设备状态机→状态枚举+状态迁移演示、通信管理与 OEE 计算→OEE 指标计算展示、大屏可视化看板→大屏风格 KPI 卡片+实时数据
- 14.4 智能仓储 WMS（4 篇）：需求与数据库设计→实体关系与主外键示意、Prism 模块划分→模块化导航示意、库存管理与 RFID 集成→入库/出库模拟、库位可视化→Grid 库位高亮展示
- 14.5 视觉检测（2 篇）：相机通信与图像显示→图像采集/显示模拟、检测逻辑与结果统计→检测判定+合格率统计
- 14.6 运动控制（2 篇）：运动控制卡通信→点位运动命令模拟、轴状态监控与轨迹编程→轴坐标显示+轨迹点编程
- 14.7 SCADA（5 篇）：系统架构→SCADA 分层结构演示、报警规则引擎→规则匹配与报警触发、历史趋势与报表→历史数据表格+趋势图、组态化设计与 OPC UA→点位绑定组态演示、权限管理与审计→登录角色权限控制

### 关键决策

- 复用既有章节已建立的示例书写模式，避免引入新格式；示例一律用模拟数据保证可编译运行
- 实时刷新统一用 DispatcherTimer（主线程更新 UI 安全）；布局使用 Grid/StackPanel，位移用 TranslateTransform（避开 Canvas.Left 在 StackPanel 不生效的坑）
- 概念性文章（如项目概述、系统架构）也给出最小可运行演示窗口

## 实施注意

- 只动 `[!example]` 卡片块：从 `> [!example] 完整示例` 到占位符代码块结束，其余 Callout 与文档结构保持原样
- 替换内容勿混入 `+` 前缀；保持"**MainWindow.xaml：**"等标题与 04/06 章一致
- 避免大段重复代码，各示例聚焦本知识点，注释解释"为什么这样写"
