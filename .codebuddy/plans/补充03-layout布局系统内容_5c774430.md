## 用户需求
为 `03-layout` 目录（3.布局系统）下全部 20 个 markdown 文件补充完整的 WPF 布局教学内容，替换当前的占位符模板。每个文件需遵循已有的九段式 Callout 结构，填入围绕该布局控件具体特性的实际知识、完整可运行的 XAML+C# 代码示例、真实的踩坑经验和分层练习题。

## 产品概述
03-layout 是 WPF 学习体系的第 3 个板块，承接 02-xaml 的 XAML 语法基础，为学习者提供 WPF 布局系统的系统化知识。内容涵盖 9 个子主题：布局基本概念（3篇）、Grid（4篇）、StackPanel（2篇）、WrapPanel（2篇）、DockPanel（2篇）、Canvas（2篇）、UniformGrid（1篇）、辅助容器 Border/ScrollViewer/Viewbox（3篇）、布局选择策略（1篇），共 20 篇文章。

## 核心功能
- **3.1 布局基本概念**：阐述 WPF 流式布局原理、测量/排列两阶段模型、DP 密度无关像素机制；详解 Width/Height/Margin/Padding/Alignment/Visibility 等通用布局属性；说明 px/Auto/Star 三种尺寸单位及其与物理像素的换算关系
- **3.2 Grid 网格布局**：详解 RowDefinitions/ColumnDefinitions 定义、Grid.Row/Column/RowSpan/ColumnSpan 附加属性；深入 Fixed/Auto/Star 三种尺寸模式及其等比例分配机制；GridSplitter 拖拽分隔条的用法和方向控制；完整的嵌套 Grid 表单布局和自适应三栏示例
- **3.3 StackPanel 堆叠布局**：Orientation 方向控制、子元素排列顺序、性能特点；与 Grid 的选择指南（何时用 StackPanel、何时用 Grid）
- **3.4 WrapPanel 环绕布局**：自动换行/换列机制、ItemWidth/ItemHeight 统一子项尺寸；标签云、工具栏、缩略图列表等实际用法示例
- **3.5 DockPanel 停靠布局**：DockPanel.Dock 附加属性、LastChildFill 特性、子元素顺序的影响；经典主界面框架（上-下-左-右-中）的完整实现
- **3.6 Canvas 画布布局**：Canvas.Left/Top/Right/Bottom 精确坐标定位、ZIndex 层叠控制；绘图和拖拽场景示例，以及分辨率适配的注意事项
- **3.7 UniformGrid 均匀网格**：等大小单元格划分、Rows/Columns 属性、FirstColumn 偏移、自动行列计算
- **3.8 辅助容器**：Border 的边框/圆角/背景/Padding 实现卡片式布局；ScrollViewer 的滚动条可见性、CanContentScroll 逻辑滚动、PanningMode 触摸滚动；Viewbox 的 Stretch 缩放模式和等比缩放
- **3.9 布局选择策略**：提供决策树和对照表，指导在不同场景（表单、主界面、工具栏、仪表盘等）中选择最佳布局容器组合，附带性能优化建议


## 技术栈
- 文件格式：Markdown（.md）
- Front Matter：YAML 格式（title / section / parent）
- Callout 语法：`> [!type]` 引用块格式
- 代码语言：XAML + C#（.NET 6+）

## 实现方案

### 内容生产策略
采用"统一模板 + 个性化填充"策略：所有 20 篇文章遵循相同的九段式 Callout 结构，但每一篇的内容都围绕其具体知识点进行个性化撰写。

### 九段式 Callout 结构（严格顺序）
1. `[!plain]` 白话理解 — 生活化类比，让初学者一眼就懂
2. `[!def]` 官方定义 — 精确技术定义，一句话概括核心
3. `[!origin]` 由来背景 — 对比 WinForms 旧方案，解释设计动机
4. `[!essentials]` 核心要点 — bullet 列表 5-8 条关键知识点
5. `[!example]` 完整示例 — 最长的 section，XAML + C# 完整可运行代码，可附带速查表
6. `[!scene]` 适用场景 — ✅ 适合 / ❌ 不适合 对照列表
7. `[!pitfall]` 常见踩坑 — 3 个具体陷阱 + 解决方案
8. `[!best]` 最佳实践 — 5-6 条简洁编码建议
9. `[!practice]` 上手练习 — Lv.1 照猫画虎 / Lv.2 小试牛刀 / Lv.3 融会贯通
10. `[!related]` 相关知识链接 — ← 前置 / → 后续 / ⇄ 关联 / 官方文档

### 代码示例规范
- 暗色工业主题配色：背景 #0D1117 / #161B22，强调色 #FF6B35（橙）、#3FB950（绿）
- 命名空间：`namespace HmiDemo;`（C# 10 文件作用域命名空间）
- 上位机场景：设备监控面板、参数配置窗口、报警列表、温湿度采集显示等
- 中文注释：解释"为什么这样写"而非仅仅"写的是什么"
- 完整性：XAML + C# 双文件，可直接复制运行

### Callout 格式规范（已知经验）
- Callout 内部每行必须以 `> ` 开头，包括空行（`> `）、代码块围栏（`> ```xml`）、代码内容和表格
- 下一个 `> [!...]` 行标志着前一个 Callout 的自然结束
- 如需批量修复脚本，使用 `.cjs` 扩展名（项目 ES module）

### 文件大小目标
- 核心知识点文件（Grid、DockPanel、Canvas）：8-15 KB
- 简单概念（UniformGrid、辅助容器）：6-10 KB
- 策略总结（布局选择指南）：8-12 KB
