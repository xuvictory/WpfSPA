## 产品概述

以 `public/content/05-core-concepts/什么是依赖属性.md` 的输出质量为基准,对项目全部 17 个章节、约 550 篇菜单文章进行一次全量"高质量输出"审计,生成检查报告,列出未达标文章清单,本次不做内容修复。

## 核心功能

- 全库逐篇程序化审计:frontmatter 完整性、10 种 Callout(白话理解/官方定义/由来背景/核心要点/完整示例/适用场景/常见踩坑/最佳实践/上手练习/相关知识链接)齐全度、正文与代码篇幅深度
- 占位符与废话模板残留检测(参考《章节内容更新经验归档.md》第 8 节特征词与禁用模板)
- 示例代码质量检查:HmiDemo 命名空间、暗色工控主题、xml/csharp 代码块、x:Name 与 Click 事件对应
- related 站内链接有效性检查(链接目标是否真实存在于内容库)
- 全文重复/高度雷同检测(正文哈希)
- 对照 `meta.json` 菜单树校验:幽灵条目(菜单有、文件无)与孤立文件(文件有、菜单无)
- 按章节汇总达标率,输出《高质量输出检查报告.md》,未达标文章逐篇列明缺项与严重程度分级(未达标/边缘/达标),并给出修复建议与优先级

## 技术栈

- 使用项目既有 Node.js 环境(项目为 Vite 6 构建,Node 可用)编写一次性审计脚本 `scripts/audit-quality.mjs`,仅依赖 Node 内置 `fs`/`path`,无新增 npm 依赖
- Markdown 内容为纯文本,审计为只读扫描,不改动任何文章

## 实施方案

编写一个全量审计脚本,遍历 `public/content/` 下全部 `.md` 文件(约 550 篇)与 `meta.json` 菜单树,按以下维度逐篇打分并输出 JSON 明细,再据此人工复核、生成报告。

### 检查维度(以基准文章《什么是依赖属性?》特征为满分参照)

1. **结构完整性**:frontmatter 三项(title/section/parent)是否齐全;一级标题 `# ` 是否存在;10 种 Callout 各出现次数(缺哪种、缺几条)
2. **内容深度**:去掉代码块后的正文字符数、代码块数量与字符数,低于阈值(如全文 < 4KB)标记为可疑
3. **占位符/废话残留**:`待补充`、`待完善`、`TODO`、`TBD`、`占位` 及第 8 节禁用模板特征串(`是 WPF 上位机开发中的一项重要知识`、`微软官方定义和实现`、`请确保你已经理解了本章节之前的内容` 等);每条 Callout 正文过短(< 50 字)标记
4. **示例代码质量**:是否含 `xml`/`csharp` 代码块;是否含 `namespace HmiDemo`;是否含暗色工控主题色(`#0D1117` 等);提取 XAML 中 `x:Name` 与 `Click="..."` 事件名,检查 C# 代码块中是否存在对应声明/处理函数(仅做文本级对应检查)
5. **related 链接有效性**:提取 `[!related]` 中的站内引用(标题或文件名),与内容库真实文件名做模糊匹配,找不到的记为失效
6. **重复检测**:归一化(去空白/代码块)后计算正文哈希,检出完全重复;对未重复文件计算行级 Jaccard 相似度,检出高度雷同对
7. **菜单-文件一致性**:解析 `meta.json` 全部 leaf 的 `file` 字段,检查文件是否真实存在(幽灵条目);反向扫描内容目录中未被菜单引用的 `.md`(孤立文件)

### 判定分级

- **达标**:10 种 Callout 齐全、无占位符/废话模板、示例为 HmiDemo 完整可运行代码且贴合工控场景、related 链接有效、篇幅充足
- **边缘**:缺失 1-2 种 Callout,或篇幅偏低、related 部分失效,但无废话模板
- **未达标**:存在占位符/废话模板残留、示例缺失或占位、缺失 3 种及以上 Callout

### 执行流程

1. 编写脚本并运行,输出全库统计与逐篇明细(JSON)
2. 脚本无法判定的语义质量(白话是否复读标题、踩坑是否真实)通过人工抽查复核,校准阈值、排除误报
3. 汇总生成《高质量输出检查报告.md》,并在对话中给出核心结论摘要

## Agent Extensions

### SubAgent

- **code-explorer**
- 用途:在人工复核阶段批量抽查未达标/边缘候选文章,汇总其 Callout 内容特征(白话是否复读标题、踩坑是否有"现象→原因→解决"、related 是否真实指向),辅助主代理对脚本结果做语义级校准与误报排查
- 预期结果:为每篇候选文章产出结构化的语义质量判断,支撑最终达标/边缘/未达标分级结论,并沉淀进检查报告
