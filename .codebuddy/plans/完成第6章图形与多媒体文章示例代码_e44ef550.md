### 编写模板（严格照抄第 4 章 button-按钮.md 格式）

替换 `> [!example] 完整示例` 卡片内占位符为：

```
> **{上位机场景描述}：{本知识点覆盖的要点}：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow" ...>
>     ...（与后台代码 x:Name 一一对应）
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using ...;
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         ...
>     }
> }
> ```
>
```

### 代码编写规范

- 命名空间统一 `HmiDemo`，主窗口类 `MainWindow`（x:Class 与后台 partial class 一致）
- 窗口使用暗色工控主题：`Background="#0D1117"`，控件配色沿用第 4 章风格（如 `#238636` 绿、`#DA3633` 红、`#21262D` 灰、`#8B949E` 文本、`#58A6FF` 强调蓝）
- 所有事件处理函数与 XAML 中 `Click`、`x:Name` 引用严格对应，确保可编译运行
- 中文注释说明关键 API 用途；每篇示例须展示该文章独有的知识点（如 line 用 X1/Y1/X2/Y2，path 用 Data 微语言，writeablebitmap 用 WritePixels 等）
- 场景贴合上位机：设备启停、参数下发、状态灯、仪表指针、实时曲线、报警闪烁、监控看板、报警音、演示视频、3D 产线等
