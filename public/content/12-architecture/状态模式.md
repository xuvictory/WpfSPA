# 状态模式

> [!plain] 白话理解
> "状态模式"是 WPF 上位机开发中的一项重要知识。在学习 WPF 上位机开发的过程中，"状态模式"是一个重要的知识点。当项目从几百行代码增长到几万行、几十万行时，没有架构的代码会变成一团乱麻。掌握了它，你就能更好地构建工业级上位机应用程序。

> [!def] 官方定义
> 状态模式是 WPF / .NET 技术栈中由微软官方定义和实现的一个特性/概念/控件。它遵循 .NET 标准规范，为开发者提供了一套完整的编程接口（API）和最佳实践指南。详细定义请参考 Microsoft Docs 官方文档。

> [!origin] 由来背景
> 状态模式的诞生源于实际开发中的痛点。微软在设计 .NET 和 WPF 框架时，为了满足企业级应用（尤其是工业自动化、数据可视化等场景）的需求，引入了这一特性。它的设计理念参考了业界最佳实践，并在日后的版本迭代中不断优化。

> 本章节背景：当项目从几百行代码增长到几万行、几十万行时，没有架构的代码会变成一团乱麻。

> [!essentials] 核心要点
> - **概念理解**：首先搞清楚"状态模式"是什么，它解决了什么问题
> - **关键 API**：掌握最常用的属性和方法，能用代码表达你的意图
> - **使用模式**：了解惯用的写法套路，避免重复造轮子
> - **注意事项**：知道什么能做，什么不能做，踩坑前先看清路
> - **实战检验**：用一个小项目或练习来验证你真的理解了

> [!example] 完整示例
> **设备状态机演示：设备在不同状态（待机/运行/报警）下"启动/停止/复位"行为不同，用状态对象替代大量 if-else 判断：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         Title="状态机 - 状态模式" Height="320" Width="420"
>         WindowStartupLocation="CenterScreen" Background="#0D1117">
>     <StackPanel Margin="15">
>         <TextBlock x:Name="StateText" Text="当前状态：待机" Foreground="#58A6FF"
>                    FontSize="16" FontWeight="Bold"/>
>         <Button Content="启动" Click="OnStart" Margin="0,12,0,0" Padding="8"
>                 Background="#21262D" Foreground="White"/>
>         <Button Content="停止" Click="OnStop" Margin="0,8,0,0" Padding="8"
>                 Background="#21262D" Foreground="White"/>
>         <Button Content="触发报警 / 复位" Click="OnAlarmReset" Margin="0,8,0,0" Padding="8"
>                 Background="#21262D" Foreground="White"/>
>         <TextBlock x:Name="OutputText" Margin="0,12,0,0" Foreground="#8B949E" TextWrapping="Wrap"/>
>     </StackPanel>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System.Windows;
> using System.Windows.Media;
>
> namespace HmiDemo
> {
>     // 状态接口：不同状态对同一操作给出不同行为
>     public interface IDeviceState
>     {
>         string HandleStart(Context ctx);
>         string HandleStop(Context ctx);
>         string HandleAlarm(Context ctx);
>     }
>
>     // 状态 A：待机
>     public class IdleState : IDeviceState
>     {
>         public string HandleStart(Context ctx) { ctx.State = new RunState(); return "待机 → 运行：设备启动"; }
>         public string HandleStop(Context ctx) => "已在待机，无需停止";
>         public string HandleAlarm(Context ctx) { ctx.State = new AlarmState(); return "待机 → 报警：发生异常"; }
>     }
>
>     // 状态 B：运行
>     public class RunState : IDeviceState
>     {
>         public string HandleStart(Context ctx) => "已在运行，请勿重复启动";
>         public string HandleStop(Context ctx) { ctx.State = new IdleState(); return "运行 → 待机：设备停止"; }
>         public string HandleAlarm(Context ctx) { ctx.State = new AlarmState(); return "运行 → 报警：设备过温！"; }
>     }
>
>     // 状态 C：报警
>     public class AlarmState : IDeviceState
>     {
>         public string HandleStart(Context ctx) => "报警状态禁止启动，请先复位";
>         public string HandleStop(Context ctx) => "报警状态禁止停止，请先复位";
>         public string HandleAlarm(Context ctx) { ctx.State = new IdleState(); return "报警 → 待机：故障已复位"; }
>     }
>
>     // 上下文：持有当前状态，把操作转发给状态对象
>     public class Context
>     {
>         public IDeviceState State { get; set; } = new IdleState();
>         public string Name => State.GetType().Name.Replace("State", "");
>     }
>
>     public partial class MainWindow : Window
>     {
>         private readonly Context _ctx = new Context();
>
>         public MainWindow() => InitializeComponent();
>
>         private void OnStart(object sender, RoutedEventArgs e) => Do(() => _ctx.State.HandleStart(_ctx));
>         private void OnStop(object sender, RoutedEventArgs e) => Do(() => _ctx.State.HandleStop(_ctx));
>         private void OnAlarmReset(object sender, RoutedEventArgs e) => Do(() => _ctx.State.HandleAlarm(_ctx));
>
>         private void Do(Func<string> action)
>         {
>             OutputText.Text = action();
>             StateText.Text = $"当前状态：{_ctx.Name}";
>             OutputText.Foreground = new SolidColorBrush(Color.FromRgb(0x8B, 0x94, 0x9E));
>         }
>     }
> }
> ```
> 

> [!scene] 适用场景
> ✅ 上位机数据展示与交互界面开发
> ✅ 工业自动化设备状态监控系统
> ✅ 需要高效数据绑定的实时数据处理场景
> ✅ 多窗口、多页面复杂导航的企业级应用
> ❌ 简单的控制台工具程序（用控制台更省事）
> ❌ 对性能要求极端苛刻的底层驱动开发（用 C++ 更合适）

> [!pitfall] 常见踩坑
> 坑 1：**概念理解不清就上手** → 建议先把本章节的前置知识点学完，理解基础原理后再动手写代码
> 
> 坑 2：**忽略了官方文档** → Microsoft Docs 上有最权威的说明和最完整的示例代码，遇到问题先查文档
>
> 坑 3：**代码写的太"一次性"** → 养成写可复用代码的习惯，以后项目中会反复用到这些知识

> [!best] 最佳实践
> - 编写代码时保持一致的命名规范（PascalCase 用于公共成员，_camelCase 用于私有字段）
> - 善用 Visual Studio 的智能提示和代码片段，提高开发效率
> - 每个关键代码块加上注释，解释"为什么这样写"而不仅仅是"写的是什么"
> - 遵循 SOLID 原则，尤其是单一职责原则：一个类只做一件事
> - 经常重构：写完功能后回头看看有没有更简洁的写法

> [!practice] 上手练习
> **Lv.1 照猫画虎**：阅读并运行本节示例代码，确保程序可以正常运行，修改一些参数观察效果变化
