> [!example] 完整示例
> **工控测试要点演示：模拟"上位机对设备心跳超时的处理"，展示边界值测试思路（恰好等于超时阈值 / 超过阈值 / 未超过），并内置一个自检清单界面：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         Title="工控测试要点" Height="400" Width="460"
>         WindowStartupLocation="CenterScreen" Background="#0D1117">
>     <StackPanel Margin="15">
>         <TextBlock Text="心跳超时边界测试（阈值 3000ms）" Foreground="#58A6FF" FontWeight="Bold"/>
>         <ComboBox x:Name="CaseBox" Margin="0,12,0,0" Padding="4"
>                   Background="#161B22" Foreground="#8B949E">
>             <ComboBoxItem Content="用例1：2999ms（未超时）" IsSelected="True"/>
>             <ComboBoxItem Content="用例2：3000ms（边界值）"/>
>             <ComboBoxItem Content="用例3：3001ms（已超时）"/>
>         </ComboBox>
>         <Button Content="执行测试用例" Click="OnRun" Margin="0,10,0,0" Padding="8"
>                 Background="#21262D" Foreground="White"/>
>         <TextBlock x:Name="OutputText" Margin="0,12,0,0" Foreground="#8B949E" TextWrapping="Wrap"/>
>     </StackPanel>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System.Windows;
> using System.Windows.Media;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         private const int TimeoutMs = 3000; // 心跳超时阈值
>
>         public MainWindow() => InitializeComponent();
>
>         // 被测函数：根据距上次心跳的间隔判断设备是否离线
>         private static string CheckHeartbeat(int intervalMs)
>             => intervalMs >= TimeoutMs ? "设备离线，触发报警" : "设备在线，心跳正常";
>
>         private void OnRun(object sender, RoutedEventArgs e)
>         {
>             int interval = CaseBox.SelectedIndex switch
>             {
>                 1 => 3000, // 边界值：等于阈值应判离线
>                 2 => 3001,
>                 _ => 2999,
>             };
>
>             string expected = CaseBox.SelectedIndex == 2 ? "设备离线，触发报警" : "设备在线，心跳正常";
>             string actual = CheckHeartbeat(interval);
>             bool pass = expected == actual;
>
>             OutputText.Text =
>                 $"间隔 {interval}ms → 结果：{actual}\n期望：{expected}\n" +
>                 (pass ? "✅ 用例通过" : "❌ 用例失败（边界值判断有误）");
>             OutputText.Foreground = new SolidColorBrush(Color.FromRgb(
>                 pass ? 0x23 : 0xDA, pass ? 0x86 : 0x36, pass ? 0x36 : 0x33));
>         }
>     }
> }
> ```
>

> [!pitfall] 常见踩坑
> 坑 1：**概念理解不清就上手** → 建议先把本章节的前置知识点学完，理解基础原理后再动手写代码
> 
> 坑 2：**忽略了官方文档** → Microsoft Docs 上有最权威的说明和最完整的示例代码，遇到问题先查文档
>
> 坑 3：**代码写的太"一次性"** → 养成写可复用代码的习惯，以后项目中会反复用到这些知识

> [!best] 最佳实践
> - 编写代码时保持一致的命名规范（PascalCase 用于公共成员，_camelCase 用于私有字段）
> - 善用 Visual Studio 的智能提示和代码片段，提高开发效率
> - 每个关键代码块加上注释，解释"为什么这样写"而不仅仅是"写的是什么"
> - 遵循 SOLID 原则，尤其是单一职责原则：一个类只做一件事
> - 经常重构：写完功能后回头看看有没有更简洁的写法

> [!practice] 上手练习
