> [!example] 完整示例
> **通信模型演示：请求-响应 与 发布-订阅 两种模型对比：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         Title="通信模型分类" Height="460" Width="540"
>         WindowStartupLocation="CenterScreen" Background="#0D1117">
>     <StackPanel Margin="15">
>         <TextBlock Text="两种主流通信模型对比" Foreground="#58A6FF" FontWeight="Bold"/>
>         <RadioButton x:Name="ReqRadio" Content="请求-响应（如 HTTP、Modbus）"
>                      Foreground="#8B949E" Checked="OnModelChanged" Margin="0,8,0,0"/>
>         <RadioButton x:Name="PubRadio" Content="发布-订阅（如 MQTT）"
>                      Foreground="#8B949E" Checked="OnModelChanged" Margin="0,6,0,0"/>
>         <ListBox x:Name="FeatureList" Height="150" Margin="0,10,0,0" Background="#161B22"
>                  Foreground="#8B949E" BorderBrush="#30363D"/>
>         <TextBlock x:Name="DemoText" Foreground="#58A6FF" Margin="0,10,0,0" TextWrapping="Wrap"/>
>     </StackPanel>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System.Windows;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         public MainWindow()
>         {
>             InitializeComponent();
>             ReqRadio.IsChecked = true;
>         }
>
>         private void OnModelChanged(object sender, RoutedEventArgs e)
>         {
>             FeatureList.Items.Clear();
>             if (ReqRadio.IsChecked == true)
>             {
>                 FeatureList.Items.Add("主动问：客户端发请求，服务端回响应");
>                 FeatureList.Items.Add("适合：读 PLC 寄存器、查询设备状态");
>                 FeatureList.Items.Add("特点：一问一答，天然同步，实现简单");
>                 DemoText.Text = "示例：Modbus 轮询读保持寄存器 —— 上位机发 03 请求帧，等待从站返回数据。";
>             }
>             else
>             {
>                 FeatureList.Items.Add("广播式：发布者发消息，所有订阅者都能收到");
>                 FeatureList.Items.Add("适合：设备状态上报、远程监控、多端同步");
>                 FeatureList.Items.Add("特点：异步解耦，一对多，需要 Broker 中转");
>                 DemoText.Text = "示例：MQTT —— 设备发布温度到 topic，上位机与手机端同时订阅该 topic。";
>             }
>         }
>     }
> }
> ```
>

> - 编写代码时保持一致的命名规范（PascalCase 用于公共成员，_camelCase 用于私有字段）
> - 善用 Visual Studio 的智能提示和代码片段，提高开发效率
> - 每个关键代码块加上注释，解释"为什么这样写"而不仅仅是"写的是什么"
> - 遵循 SOLID 原则，尤其是单一职责原则：一个类只做一件事
> - 经常重构：写完功能后回头看看有没有更简洁的写法
