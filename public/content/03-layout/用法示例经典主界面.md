# 用法示例经典主界面

> [!plain] 白话理解
> 几乎每一个 WPF 上位机应用的主窗口都有同样的骨架：最上面一条菜单/工具栏，最下面一条状态栏，左边一个设备树/导航面板，中间一大块是主力干活的内容区。这个结构叫"经典五区布局"，而实现它最优雅的方式就是 **DockPanel 管外围 + Grid 管内部分区**。只需 5 行关键声明，整个应用的主框架就立起来了。这一篇就是给你一个可以直接复制到新项目中的主界面模板。

> [!def] 官方定义
> 经典主界面布局是指以 DockPanel 为最外层容器，通过 DockPanel.Dock 将功能区划分到四边（Top/Bottom/Left/Right），中间区域由一个或多个 Grid（或 TabControl）承担主内容展示的布局模式。这种模式充分利用了 DockPanel 的"先到先得 + 最后填满"特性，是整个 WPF 应用框架的事实标准。

> [!origin] 由来背景
> WinForms 时代做这种布局主流是 MDI（多文档界面）——一个主窗体里嵌套多个子窗体，子窗体可以最大化/最小化/层叠。MDI 的问题是子窗体都有自己的标题栏，看起来很笨重，而且跨子窗体的数据联动很麻烦。WPF 的 DockPanel 方案是单文档界面（SDI）的现代化——没有多余标题栏，所有面板无缝拼接，数据共享通过同一个 Window 的 DataContext 自然实现。

> [!essentials] 核心要点
> - **五区分工**：Top（菜单/工具栏）、Bottom（状态栏）、Left（导航/设备树）、Right（属性/快捷面板）、Center（主内容区）
> - **DockPanel 外层**：处理 Top/Bottom/Left/Right 四个固定区域
> - **Grid 中层**：中间内容区内部再用 Grid 做行列划分
> - **内容区可切换**：中间区域用 TabControl 或 ContentControl + 数据绑定实现视图切换
> - **尺寸靠 Width/Height**：侧边栏设 Width、顶栏/底栏设 Height，中间内容区不设大小（由 LastChildFill 负责）

> [!scene] 适用场景
> ✅ **上位机主窗口**：99% 的上位机项目都以这个模板为起点
> ✅ **IDE 类工具**：代码编辑器、组态软件、SCADA 系统的标准 UI 框架
> ✅ **管理后台**：运维后台、设备管理系统的多面板布局
> ✅ **仪表盘 Dashboard**：顶栏 KPI 概览 + 内容区图表网格
> ❌ **简单弹窗/对话框**：单一功能的确认/输入窗口不需要这么复杂的框架

> [!pitfall] 常见踩坑
> 坑 1：**声明顺序不是"位置顺序"而是"优先级顺序"** → "先 Top 再 Bottom 再 Left 再 Right" 是优先级顺序，不是视觉上的从左到右。很多人按"读"的顺序（Left → Center → Right）来声明，结果 Left 先占了整个左侧，Right 后来被挤到 Left 右边去了。正确顺序永远是：**Top → Bottom → Left → Right → 不设 Dock 的最后**。
>
> 坑 2：**中间内容太简单时忘记嵌套** → DockPanel 只负责把空间预留给中间区，但中间区内部怎么排列它不管。如果你直接在中间区放 3 个 Button，它们会相互覆盖。中间区应该再嵌套一个 Grid 或 StackPanel 来组织子内容。
>
> 坑 3：**侧边栏用固定 Width 但没设 MinWidth** → 当窗口缩得太小时，固定宽度的侧边栏会挤占中间内容区。给所有侧边栏设 `MinWidth` 不如给 Window 设 `MinWidth` 更可靠——从根源上限制最小窗口尺寸。

> [!best] 最佳实践
> - 经典五区声明模板（按此顺序写）：
>   ```xml
>   <DockPanel LastChildFill="True">
>       <Border DockPanel.Dock="Top"    Height="44"  />  <!-- 菜单栏 -->
>       <Border DockPanel.Dock="Bottom" Height="30"  />  <!-- 状态栏 -->
>       <Border DockPanel.Dock="Left"   Width="200"  />  <!-- 导航 -->
>       <Border DockPanel.Dock="Right"  Width="260"  />  <!-- 属性面板 -->
>       <Grid> ... </Grid>                               <!-- 主内容区 -->
>   </DockPanel>
>   ```
> - 中间内容区用 TabControl 组织多视图，比手动切换 Visibility 优雅得多
> - 侧边栏设 MinWidth/MaxWidth + GridSplitter 做可拖动面板（参考上面的右侧面板实现）
> - 把这个模板保存为项目模板或代码片段，新项目直接套用
