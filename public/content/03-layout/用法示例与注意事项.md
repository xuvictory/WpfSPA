# 用法示例与注意事项

> [!plain] 白话理解
> 上一节讲了 Canvas 的"武器说明书"——有哪些属性、能干什么。这一节讲"战场生存手册"——在实际项目里怎么用、哪些地方容易翻车。概括一句话：**Canvas 是画图工具，不是布局工具**。把它当作上位机流程图、拖拽标注、绘图板的底层画板完全没问题；但如果你试图用它来排列表单、做自适应界面，就相当于用螺丝刀敲钉子——能干，但很痛苦。

> [!def] 官方定义
> Canvas 的最佳使用模式是将它作为一个"精确绘制定位区域"，通常嵌套在自适应布局面板（Grid/DockPanel）内部，负责渲染绝对定位的图形元素（Shape 子类、自定义绘图元素、拖拽控件），由外层面板负责整体尺寸管理和自适应。Canvas 本身应被赋予明确的固定尺寸，或通过外层布局的 Star 模式间接获得尺寸。

> [!origin] 由来背景
> 在工业自动化软件中，"工艺流程图"（P&ID）是标配功能——显示设备、管道、阀门、传感器之间的拓扑关系，所有元素都有固定的坐标。这类需求用 Canvas 是天作之合。但很多从 WinForms 转过来的开发者会把 Canvas 当作默认布局面板（因为 WinForms 就是绝对定位思维），写出的界面在 1080p 上好看，换到 4K 屏就面目全非。所以需要特别注意：**在 WPF 项目里，Canvas 永远是被"包着用"的，不是顶层用的**。

> [!essentials] 核心要点
> - Canvas 的定位是 **"精确绘图区域"** 而非 "通用布局面板"
> - Canvas 必须嵌套在自适应面板内部，外层负责尺寸适配，内层负责精确绘图
> - `Canvas.Left/Top` 赋值是运行时动态拖拽的基础，使用 `Canvas.SetLeft(element, x)` 在 C# 代码中更新位置
> - Shape 子类（Line、Rectangle、Ellipse、Polygon、Path）天然适合放在 Canvas 内
> - Canvas 的 `Background` 默认是 `null`（透明、不响应鼠标），设置非 null 的 Brush 才能捕获鼠标事件
> - 分辨率问题推荐用 Viewbox 包裹 Canvas 实现等比缩放（但会牺牲像素精度）；或用固定尺寸+ScrollViewer 提供滚动查看

> **MainWindow.xaml.cs** — 拖拽标注逻辑
> ```csharp
> using System.Windows;
> using System.Windows.Controls;
> using System.Windows.Input;
> using System.Windows.Media;
> using System.Windows.Shapes;
> 
> namespace HmiDemo;
> 
> public partial class MainWindow : Window
> {
>     // 当前正在被拖拽的标注
>     private UIElement? _draggingElement;
>     private Point _dragStartPoint;
>     private double _dragStartLeft;
>     private double _dragStartTop;
>     private int _annotationCount;
> 
>     public MainWindow()
>     {
>         InitializeComponent();
>     }
> 
>     /// <summary>
>     /// 窗口任意位置按下鼠标：在画布上创建一个新标注
>     /// </summary>
>     private void Window_MouseLeftButtonDown(object sender, MouseButtonEventArgs e)
>     {
>         // 获取鼠标在 Canvas 内的坐标
>         Point canvasPos = e.GetPosition(drawCanvas);
> 
>         // 检查是否在 Canvas 区域内（不在则忽略）
>         if (canvasPos.X < 0 || canvasPos.Y < 0 ||
>             canvasPos.X > drawCanvas.ActualWidth ||
>             canvasPos.Y > drawCanvas.ActualHeight)
>             return;
> 
>         // 创建标注标志（带数字的圆点）
>         _annotationCount++;
>         var annotation = CreateAnnotationMarker(canvasPos, _annotationCount);
> 
>         // 放到 Canvas 上（ZIndex 随数量递增，新标注在最上层）
>         Canvas.SetLeft(annotation, canvasPos.X - 14);
>         Canvas.SetTop(annotation, canvasPos.Y - 14);
>         Panel.SetZIndex(annotation, _annotationCount + 10);
>         drawCanvas.Children.Add(annotation);
> 
>         // 为标注绑定拖拽事件
>         annotation.MouseLeftButtonDown += Annotation_MouseLeftButtonDown;
>         annotation.MouseMove += Annotation_MouseMove;
>         annotation.MouseLeftButtonUp += Annotation_MouseLeftButtonUp;
> 
>         txtStatus.Text = $" | 已添加 {_annotationCount} 个标注";
>     }
> 
>     /// <summary>
>     /// 创建一个视觉标注元素（圆形 + 数字）
>     /// </summary>
>     private UIElement CreateAnnotationMarker(Point pos, int number)
>     {
>         var grid = new Grid { Width = 28, Height = 28, Cursor = Cursors.Hand };
> 
>         // 半透明外圈
>         var outerCircle = new Ellipse
>         {
>             Width = 28, Height = 28,
>             Fill = new SolidColorBrush(Color.FromArgb(80, 255, 107, 53)),
>             Stroke = new SolidColorBrush(Color.FromRgb(255, 107, 53)),
>             StrokeThickness = 2
>         };
> 
>         // 数字标签
>         var label = new TextBlock
>         {
>             Text = number.ToString(),
>             Foreground = Brushes.White,
>             FontSize = 12,
>             FontWeight = FontWeights.Bold,
>             HorizontalAlignment = HorizontalAlignment.Center,
>             VerticalAlignment = VerticalAlignment.Center
>         };
> 
>         grid.Children.Add(outerCircle);
>         grid.Children.Add(label);
> 
>         // 存储编号，右键删除时使用
>         grid.Tag = number;
>         return grid;
>     }
> 
>     // --- 拖拽逻辑 ---
>     private void Annotation_MouseLeftButtonDown(object sender, MouseButtonEventArgs e)
>     {
>         _draggingElement = sender as UIElement;
>         if (_draggingElement == null) return;
> 
>         _dragStartPoint = e.GetPosition(drawCanvas);
>         _dragStartLeft = Canvas.GetLeft(_draggingElement);
>         _dragStartTop = Canvas.GetTop(_draggingElement);
> 
>         // 捕获鼠标，防止拖出元素后丢失事件
>         _draggingElement.CaptureMouse();
>         e.Handled = true;
>     }
> 
>     private void Annotation_MouseMove(object sender, MouseEventArgs e)
>     {
>         if (_draggingElement == null) return;
>         if (e.LeftButton != MouseButtonState.Pressed)
>         {
>             // 鼠标左键已释放但未收到 MouseUp（捕获丢失），清理状态
>             _draggingElement.ReleaseMouseCapture();
>             _draggingElement = null;
>             return;
>         }
> 
>         Point currentPos = e.GetPosition(drawCanvas);
> 
>         // 计算新位置（相对于拖拽起点偏移）
>         double newLeft = _dragStartLeft + (currentPos.X - _dragStartPoint.X);
>         double newTop = _dragStartTop + (currentPos.Y - _dragStartPoint.Y);
> 
>         // 边界约束：不能拖出画布
>         if (_draggingElement is FrameworkElement fe)
>         {
>             newLeft = Math.Max(0, Math.Min(newLeft,
>                 drawCanvas.ActualWidth - fe.ActualWidth));
>             newTop = Math.Max(0, Math.Min(newTop,
>                 drawCanvas.ActualHeight - fe.ActualHeight));
>         }
> 
>         Canvas.SetLeft(_draggingElement, newLeft);
>         Canvas.SetTop(_draggingElement, newTop);
>     }
> 
>     private void Annotation_MouseLeftButtonUp(object sender, MouseButtonEventArgs e)
>     {
>         if (_draggingElement != null)
>         {
>             _draggingElement.ReleaseMouseCapture();
>             _draggingElement = null;
>         }
>     }
> 
>     /// <summary>
>     /// 清除所有标注
>     /// </summary>
>     private void BtnClear_Click(object sender, RoutedEventArgs e)
>     {
>         // 只清除标注（从后往前删，避免索引错乱）
>         for (int i = drawCanvas.Children.Count - 1; i >= 0; i--)
>         {
>             if (drawCanvas.Children[i] is Grid g && g.Tag is int)
>             {
>                 drawCanvas.Children.RemoveAt(i);
>             }
>         }
> 
>         _annotationCount = 0;
>         txtStatus.Text = " | 标注已全部清除";
>     }
> }
> ```
>
> 这个完整示例演示了 Canvas 在工业上位机中最核心的两个用法：
> 1. **静态背景**：设备矩形和文字是编译时写好的，充当"地图"
> 2. **动态标注**：运行时点击创建标注，拖拽移动，边界约束防止拖出画布
>
> [!scene] 适用场景
> - ✅ 工艺流程图（P&ID）上的设备、管道、传感器定位
> - ✅ 地图/平面图上可拖拽的标记点（如消防点位标注）
> - ✅ 组态软件中用户自定义的图形元素布局
> - ✅ 板卡、机柜、设备机架的三维示意平面图
> - ✅ 需要鼠标交互的自定义绘图工具（如画线、框选）
> - ❌ 任何需要自动换行、自动排列的内容——用 WrapPanel 或 StackPanel
> - ❌ 表单输入控件（TextBox、ComboBox 等）——用 Grid 表单布局
> - ❌ 整窗口布局——Canvas 不自适应，窗口缩放效果很差

> [!pitfall] 常见踩坑
> - **坑1：背景透明导致鼠标事件穿透**。Canvas 默认 `Background = null`，鼠标点不到"空白区"。解决方案：给 Canvas 设一个 `Background`（哪怕 `Transparent` 也行），或把鼠标事件挂在父容器上再通过 `e.GetPosition(drawCanvas)` 获取坐标。
> - **坑2：动态添加的子元素覆盖了旧的而不自知**。如果所有标注都放在同一个 `Canvas.Left/Top` 位置，后添加的会盖住先添加的。解决方案：用 `Panel.ZIndex` 递增或给每个标注分配不同的坐标。
> - **坑3：MouseMove 事件在拖出元素边界后丢失**。拖拽操作中鼠标可能比元素移动快。解决方案：调用 `element.CaptureMouse()` 捕获鼠标，在 `MouseUp` 时释放，并在 `MouseMove` 中检查 `e.LeftButton` 状态作为兜底。

> [!best] 最佳实践
> - Canvas + Mouse 拖拽逻辑应当封装成独立的帮助类或 Behavior（`DraggableBehavior`），避免在每个窗口里重复写相同的 MouseDown/Move/Up 代码
> - 动态添加子元素后，如果不需要交互，及时移除事件订阅（`-=`），防止内存泄漏
> - 拖拽边界约束建议使用 `Math.Clamp`（.NET 6+）替代手写的 `Math.Max/Min` 嵌套，代码更清晰
> - 工艺流程图如果设备数量 > 100，考虑用 `ItemsControl` 数据驱动 + DataTemplate + Canvas ItemsPanel，而非逐个创建 UIElement
> - Canvas 内的 Shape 元素（Line、Rectangle、Ellipse）默认 `IsHitTestVisible = true`；如果不需要点击，设为 `false` 可以提升鼠标事件穿透性能

> [!practice] 上手练习
> - **Lv.1 照猫画虎**：修改上面示例中设备矩形的颜色——将未标注设备从绿色(#3FB950)改为灰色(#555)，在 XAML 中直接改
> - **Lv.2 小试牛刀**：增强拖拽逻辑——按 `Shift` 键拖拽时，标注只能水平移动（锁定 Y 坐标）；松开 `Shift` 键恢复自由拖拽
> - **Lv.3 融会贯通**：实现框选功能——在 Canvas 上按住鼠标拖出一个虚线矩形框，松开时计算哪些标注的圆心落在选框内，将它们批量高亮
