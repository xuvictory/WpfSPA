# 用法示例与选择指南

> [!plain] 白话理解
> 写 WPF 的时候最常纠结的问题之一：**这个地方用 StackPanel 还是 Grid？** 答案是：看你要不要"按比例分空间"。如果你的控件排列纯粹是"一个接一个"的关系（比如 3 个按钮横排、5 个状态卡片竖排），用 StackPanel——它简单、快速、不易出错。如果你需要"这个占 30%、那个占 50%、剩下的自动填满"，用 Grid。本章用实际的上位机场景帮你建立"一眼判断用哪个容器"的直觉。

> [!def] 官方定义
> StackPanel 和 Grid 的选择基于布局需求的变化程度：StackPanel 适用于**序列化排列场景**（子元素按固定顺序一字排开），Grid 适用于**空间分区场景**（子元素需要按比例或固定位置占据不同区域）。从性能角度看，StackPanel 的 Measure/Arrange 复杂度为 O(n)，Grid 涉及列宽计算和比例分配，略高于 O(n)，但在常规场景下差异可忽略。

> [!origin] 由来背景
> 很多从 WinForms 转过来的开发者有一个惯性思维："把所有东西放进一个 Grid 里总没错"。但过度使用 Grid 会让 XAML 变得臃肿——一个 6 列 3 行的 Grid 光列定义就要 12 行代码，而同样的按钮横排用 StackPanel 只需要 3 行。另一方面，StackPanel 不能做比例分配，如果你需要"左边固定 200px，右边填满"，StackPanel 做不到（至少需要一个 Grid）。理解两者的边界，才能写出干净且高效的布局。

> [!essentials] 核心要点
> - **用 StackPanel 的场景**：控件沿单方向线性排列，没有复杂的空间分割需求
> - **用 Grid 的场景**：需要按比例分配空间，或者多行多列的表格布局
> - **性能**：StackPanel 略快于 Grid（无列宽计算），但差异仅在极致嵌套时明显
> - **可读性**：简单排列 StackPanel 更直观；复杂排列 Grid 虽然冗长但逻辑清晰
> - **组合使用**：`Grid → StackPanel → 子控件` 是最常见的嵌套模式——外层 Grid 分区域，区域内 StackPanel 排控件

> [!scene] 适用场景
> ✅ **StackPanel 最适**：按钮栏、工具栏、标签页标题、菜单项、状态卡片列表、简单信息行
> ✅ **Grid 最适**：表单（标签+输入框）、数据表格、多区域面板、仪表盘 Dashboard
> ✅ **组合使用**：`Grid（分大区）→ StackPanel（排小控件）` 是上位机 90% 界面的配方
> ❌ **StackPanel 做表单**：输入框对不齐、无法随窗口缩放——看似能跑，实则在坑里

> [!pitfall] 常见踩坑
> 坑 1：**滥用 StackPanel 做复杂布局** → 一个 StackPanel 套一个 StackPanel 再套一个 StackPanel——3 层之后连自己都不知道第几个按钮在哪层。超过 2 层嵌套就改用 Grid。
>
> 坑 2：**StackPanel 里的 Width 写死** → 写 `Width="200"` 可以，但如果你希望它"撑满父容器"，StackPanel 做不到——因为它沿排列方向不会拉伸。想拉伸用 Grid。
>
> 坑 3：**Toolbar 场景忘记考虑溢出** → 水平 StackPanel 里的按钮数量不固定（用户自定义工具栏）时，按钮多了会溢出。应改用 WrapPanel 或 ToolBar 控件（自带 Overflow 处理）。

> [!best] 最佳实践
> - 简单排列：`StackPanel` > `Grid`（代码少、意图清晰）
> - 复杂分区：`Grid` > `n×StackPanel`（一个 Grid 管全局 > 三个 StackPanel 嵌套）
> - 典型上位机布局公式：`Grid（分区） → StackPanel（控件行） → Button/TextBox/Label`
> - 当你不确定时，用 Grid——它的灵活性意味着你不会被"只能用 Auto 排列"限制住

> [!practice] 上手练习
> **Lv.1 照猫画虎**：运行示例，左右对比 StackPanel 表单和 Grid 表单的视觉效果差异
> **Lv.2 小试牛刀**：把场景 B 中的错误表单改为正确的 Grid 表单格式（Auto 标签列 + * 输入框列），去掉所有写死的 Width
> **Lv.3 融会贯通**：设计一个"设备配置"对话框：用 Grid 做整体分区（标题区、表单区、按钮区），表单区内部用 Grid（标签+输入框），按钮区用 StackPanel（横排按钮）
