# 弱事件模式

> [!plain] 白话理解
> "弱事件模式"是 WPF 上位机开发中的一项重要知识。在学习 WPF 上位机开发的过程中，"弱事件模式"是一个重要的知识点。工控现场对稳定性的要求近乎苛刻。性能优化不是"加分项"，而是"必须项"。掌握了它，你就能更好地构建工业级上位机应用程序。

> [!example] 完整示例
> **WeakEventManager 弱事件订阅：事件源长期存活时，订阅对象仍可被正常回收：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         Title="弱事件模式" Height="340" Width="560"
>         WindowStartupLocation="CenterScreen" Background="#0D1117">
>     <StackPanel Margin="15" Background="#161B22" Padding="15">
>         <TextBlock Text="WeakEventManager 弱事件订阅演示"
>                    Foreground="#58A6FF" FontSize="16" FontWeight="Bold"/>
>         <TextBlock x:Name="InfoText" Foreground="#8B949E" Margin="0,10,0,0" TextWrapping="Wrap"/>
>         <StackPanel Orientation="Horizontal" Margin="0,14,0,0">
>             <Button Content="创建弱事件订阅" Click="OnSubscribe" Padding="8"
>                     Background="#21262D" Foreground="White"/>
>             <Button Content="触发一次报警事件" Click="OnRaise" Padding="8" Margin="8,0,0,0"
>                     Background="#21262D" Foreground="White"/>
>         </StackPanel>
>         <Button Content="强制 GC 检查对象存活" Click="OnCheck" Padding="8" Margin="0,10,0,0"
>                 Background="#21262D" Foreground="White" HorizontalAlignment="Left"/>
>         <TextBlock x:Name="StatusText" Foreground="#58A6FF" Margin="0,14,0,0" TextWrapping="Wrap"/>
>     </StackPanel>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System;
> using System.Windows;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         private readonly AlarmCenter _center = new AlarmCenter();
>         private WeakReference _subRef;   // 弱引用观测订阅对象是否存活
>
>         public MainWindow()
>         {
>             InitializeComponent();
>             InfoText.Text = "普通事件（+=）会强引用订阅者导致泄漏；WeakEventManager 改为弱引用，订阅者可随时被 GC 回收。";
>         }
>
>         // 用 WeakEventManager 订阅：事件源只持有弱引用，不阻止订阅对象回收
>         private void OnSubscribe(object sender, RoutedEventArgs e)
>         {
>             var sub = new AlarmSubscriber(_center);
>             _subRef = new WeakReference(sub);
>             sub = null;   // 局部变量置空
>             StatusText.Text = "已用 WeakEventManager 创建订阅，局部引用已置空";
>         }
>
>         // 触发一次报警事件，验证弱事件仍能正常收到
>         private void OnRaise(object sender, RoutedEventArgs e) => _center.Raise("温度越限");
>
>         // 强制 GC 后检查：弱事件订阅对象应能被回收（无泄漏）
>         private void OnCheck(object sender, RoutedEventArgs e)
>         {
>             GC.Collect();
>             GC.WaitForPendingFinalizers();
>             GC.Collect();
>             bool alive = _subRef?.IsAlive == true;
>             StatusText.Text = alive
>                 ? "订阅对象仍存活：如果这是强事件订阅，就形成了泄漏"
>                 : "订阅对象已被回收：弱事件模式没有阻止 GC，无泄漏";
>         }
>     }
>
>     // 事件源：模拟上位机报警中心，生命周期与程序一致
>     public class AlarmCenter
>     {
>         public event EventHandler<AlarmEventArgs> AlarmRaised;
>         public void Raise(string msg) => AlarmRaised?.Invoke(this, new AlarmEventArgs(msg));
>     }
>
>     public class AlarmEventArgs : EventArgs
>     {
>         public AlarmEventArgs(string message) => Message = message;
>         public string Message { get; }
>     }
>
>     // 弱事件订阅者：事件源持有弱引用，订阅对象可随时被回收
>     public class AlarmSubscriber
>     {
>         public AlarmSubscriber(AlarmCenter center) =>
>             WeakEventManager<AlarmCenter, AlarmEventArgs>.AddHandler(
>                 center, nameof(AlarmCenter.AlarmRaised), OnAlarm);
>
>         private void OnAlarm(object sender, AlarmEventArgs e) =>
>             Console.WriteLine($"收到报警：{e.Message}");
>     }
> }
> ```

> [!best] 最佳实践
> - 编写代码时保持一致的命名规范（PascalCase 用于公共成员，_camelCase 用于私有字段）
> - 善用 Visual Studio 的智能提示和代码片段，提高开发效率
> - 每个关键代码块加上注释，解释"为什么这样写"而不仅仅是"写的是什么"
> - 遵循 SOLID 原则，尤其是单一职责原则：一个类只做一件事
> - 经常重构：写完功能后回头看看有没有更简洁的写法
