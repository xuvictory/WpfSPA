# 选择文件夹对话框

> [!plain] 白话理解
> 「选择文件夹对话框」就是系统标准的「选目录」窗口：和「打开文件」不同，它只让用户挑一个文件夹，不涉及具体文件。上位机里「数据存储目录」「日志保存位置」「工程目录」这类设置都要用到它。WPF 原生没有这个控件，通常借 Windows Forms 的 `FolderBrowserDialog` 来实现。

> [!def] 官方定义
> WPF 没有内建的文件夹选择对话框，实践中借用 `System.Windows.Forms.FolderBrowserDialog`（WinForms）：设置 `Description`（顶部说明文字）、`SelectedPath`（初始目录）、`ShowNewFolderButton`（允许新建文件夹）后调用 `ShowDialog()`，返回 `DialogResult.OK` 表示确定，选择结果在 `SelectedPath` 属性。官方文档：https://learn.microsoft.com/zh-cn/dotnet/api/system.windows.forms.folderbrowserdialog

> [!origin] 由来背景
> 「文件夹选择」需求源自文件管理场景：用户要指定数据存放目录而不是具体文件。Win32 的 `SHBrowseForFolder` API 提供了标准实现，WinForms 将其封装为 `FolderBrowserDialog`。WPF 在 .NET Framework 3.0 中只提供了文件对话框，没有文件夹对话框，因此社区通行的做法是引用 WinForms 组件；.NET Core 3.0+ 下需在 csproj 中启用 `UseWindowsForms`。直到 WinUI / 新版工具链才出现原生方案。

> [!essentials] 核心要点
> - 引入方式：项目需引用 `System.Windows.Forms`（.NET Core 用 `<UseWindowsForms>true</UseWindowsForms>`）
> - `SelectedPath`：初始目录与最终选择结果
> - `Description`：对话框顶部的说明文字
> - `ShowNewFolderButton`：是否允许在对话框中新建文件夹
> - 判断结果用 `DialogResult.OK`（与 OpenFileDialog 的 `bool?` 不同）

> [!example] 完整示例
> **选择存储目录演示：WPF 原生没有文件夹选择对话框，用 WinForms 的 FolderBrowserDialog 实现：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         Title="选择文件夹" Height="300" Width="480"
>         WindowStartupLocation="CenterScreen" Background="#0D1117">
>     <StackPanel Margin="15" Width="420">
>         <TextBlock Text="数据存储目录：" Foreground="White"/>
>         <DockPanel Margin="0,6,0,12">
>             <Button DockPanel.Dock="Right" Content="浏览…" Click="OnBrowse" Padding="10,4"/>
>             <TextBox x:Name="txtPath" IsReadOnly="True" Text="C:\HmiData"
>                      Padding="4" Background="#161B22" Foreground="White"/>
>         </DockPanel>
>         <Button Content="保存设置" Click="OnSave" Padding="8" HorizontalAlignment="Left"
>                 Background="#238636" Foreground="White"/>
>     </StackPanel>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System.Windows;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         public MainWindow() => InitializeComponent();
>
>         private void OnBrowse(object sender, RoutedEventArgs e)
>         {
>             // 注意：WPF 原生没有文件夹选择框，借用 WinForms 的 FolderBrowserDialog。
>             // 需要在项目引用中添加 System.Windows.Forms（.NET Core 需另装 WinForms 包）。
>             using var dlg = new System.Windows.Forms.FolderBrowserDialog
>             {
>                 Description = "请选择数据存储目录",
>                 ShowNewFolderButton = true,
>                 SelectedPath = string.IsNullOrEmpty(txtPath.Text)
>                     ? @"C:\"
>                     : txtPath.Text
>             };
>
>             if (dlg.ShowDialog() == System.Windows.Forms.DialogResult.OK)
>             {
>                 txtPath.Text = dlg.SelectedPath;
>             }
>         }
>
>         private void OnSave(object sender, RoutedEventArgs e)
>         {
>             MessageBox.Show($"存储目录已保存：{txtPath.Text}", "设置完成");
>         }
>     }
> }
> ```
> 

> [!scene] 适用场景
> ✅ 设置数据存储目录、日志归档目录、报警历史目录
> ✅ 选择工程 / 配方库所在文件夹
> ✅ 批量导出时指定输出目录
> ✅ 选择 U 盘 / 移动盘作为备份目标
> ❌ 需要选择具体文件时（改用 [openfiledialog-打开文件对话框](openfiledialog-打开文件对话框)）
> ❌ 目录路径需要「新建 / 重命名 / 浏览树」等高级交互时（考虑第三方 FolderBrowser 控件）

> [!pitfall] 常见踩坑
> 坑 1：**编译报错：找不到 FolderBrowserDialog** → 现象：代码里用了 `System.Windows.Forms.FolderBrowserDialog`，编译失败。原因：项目未引用 WinForms 程序集。解决：.NET Framework 在「添加引用」勾选 System.Windows.Forms；.NET Core / 5+ 在 csproj 加 `<UseWindowsForms>true</UseWindowsForms>`。
> 
> 坑 2：**默认目录没有展开到 SelectedPath** → 现象：设置了 `SelectedPath` 但对话框打开在「我的电脑」。原因：某些系统版本下目录不存在时不会自动定位。解决：先 `Directory.CreateDirectory` 确保目录存在，再设 `SelectedPath`。
>
> 坑 3：**对话框风格老旧，与 WPF 界面不协调** → 现象：WinForms 对话框是经典样式，深色 WPF 界面里显得突兀。原因：WinForms 对话框无法完全自定义外观。解决：接受系统原生外观（操作员熟悉），或改用第三方库（如 Ookii.Dialogs.Wpf 的 VistaFolderBrowserDialog）获得新版风格。

> [!best] 最佳实践
> - 目录不存在时先创建再打开对话框（`Directory.CreateDirectory`），避免定位失败
> - 选择结果立即回显到输入框并持久化到配置，下次启动恢复
> - 校验所选目录可写：尝试创建临时文件验证权限，失败给出提示
> - 路径含中文 / 空格是常态，保存与读取都用原值，不要手动截断
> - 封装成 `SelectFolderHelper` 静态方法，全站统一调用，避免每处引用 WinForms 细节

> [!practice] 上手练习
> **Lv.1 照猫画虎**：运行示例代码，点「浏览…」选择目录，观察路径回显与「保存设置」提示
> **Lv.2 小试牛刀**：把 `Description` 改为「请选择日志归档目录」；默认路径改为 `D:\Logs` 并先 `Directory.CreateDirectory` 再打开
> **Lv.3 融会贯通**：把选中的目录保存到配置文件，程序重启后自动回填 `txtPath`
> **Lv.4 挑战进阶**：实现「目录可用性校验」：选择目录后检查其剩余空间（`DriveInfo`），低于阈值时在界面用红色文字提示「空间不足」，并禁止「保存设置」按钮
