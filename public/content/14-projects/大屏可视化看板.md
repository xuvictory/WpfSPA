> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System;
> using System.Windows;
> using System.Windows.Media;
> using System.Windows.Threading;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         private readonly DispatcherTimer _timer = new DispatcherTimer();
>         private readonly Random _rand = new Random();
>
>         public MainWindow()
>         {
>             InitializeComponent();
>             _timer.Interval = TimeSpan.FromSeconds(2); // 大屏每 2 秒刷新一批数据
>             _timer.Tick += OnRefresh;
>             _timer.Start();
>         }
>
>         // 大屏数据模拟刷新：实际项目从各设备服务聚合而来
>         private void OnRefresh(object sender, EventArgs e)
>         {
>             double output = 500 + _rand.NextDouble() * 300; // 今日产量
>             double rate = 70 + _rand.NextDouble() * 28;     // 达成率
>             double quality = 96 + _rand.NextDouble() * 4;   // 良品率
>             int online = 3 + _rand.Next(2);                 // 在线设备数
>
>             Kpi1Text.Text = $"{output:F0}";
>             Kpi2Text.Text = $"{rate:F1}%";
>             Kpi3Text.Text = $"{quality:F1}%";
>             Kpi4Text.Text = $"{online} / 4";
>             LineStateText.Text = $"运行中  ·  数据更新 {DateTime.Now:HH:mm:ss}";
>         }
>     }
> }
> ```

> 
> 坑 2：**忽略了官方文档** → Microsoft Docs 上有最权威的说明和最完整的示例代码，遇到问题先查文档
>
> 坑 3：**代码写的太"一次性"** → 养成写可复用代码的习惯，以后项目中会反复用到这些知识

> [!best] 最佳实践
> - 编写代码时保持一致的命名规范（PascalCase 用于公共成员，_camelCase 用于私有字段）
> - 善用 Visual Studio 的智能提示和代码片段，提高开发效率
> - 每个关键代码块加上注释，解释"为什么这样写"而不仅仅是"写的是什么"
> - 遵循 SOLID 原则，尤其是单一职责原则：一个类只做一件事
> - 经常重构：写完功能后回头看看有没有更简洁的写法
