# 库位可视化展示

> [!plain] 白话理解
> 仓库地图比表格直观得多：一整面货架，哪些格子空着、哪些装着货、装着什么，一眼扫过去全明白。库位可视化就是把库存数据画成"仓库平面图"——每个格子一张卡片，空位是深色、占用是橙色，点一下卡片，下面立刻显示"库位 B-03：已占用 → 轴承 6204 × 57"。
> 示例的特别之处是**用代码动态生成界面**：12 个库位不是一个个手写在 XAML 里，而是 `BuildBins()` 用双重循环（3 排 × 4 列）在后台生成 12 张卡片，`UniformGrid` 自动把它们排成整齐的网格。这样库位数量、排布规则一变，只改循环参数即可。真实系统里，"占用/空位"来自「需求与数据库设计」的库位表，「库存管理与-rfid-集成」每次出入库后刷新地图——可视化只是数据的另一种表达。

> [!def] 官方定义
> **库位可视化**是 WMS（仓库管理系统）的仓储地图功能：将库位（Bin）的占用状态、货品信息以图形化网格呈现，是"数据 → 界面"的可视化映射。实现要点：
> - **动态控件构建**：在 C# 中用 `Border`/`TextBlock` 等元素按数据循环创建，加入 `UniformGrid` 自动排布，适合数量与布局由数据决定的场景；
> - **状态颜色编码**：以颜色表达状态（空位/占用/选中），属于可视化编码（Visual Encoding）；
> - **事件绑定**：动态创建的元素通过事件（`MouseLeftButtonUp`）挂接交互逻辑。
> UniformGrid 文档见 https://learn.microsoft.com/zh-cn/dotnet/api/system.windows.controls.primitives.uniformgrid

> [!origin] 由来背景
> "把仓库画成图"来自仓储运营的实践需求：早期仓库靠货架标签 + 手工台账，找货要凭记忆；1950 年代仓库分区编号（货架/排/位）出现，1960-70 年代计算机辅助的库位管理把编号与库存数据关联；现代 WMS 的"库位视图"则把这份数据画成屏幕上的彩色格子图，用颜色表达状态成为通用惯例（红=满、绿=空、黄=待出库）。
> WPF 实现库位地图非常自然：`UniformGrid` 天然适合等尺寸网格，代码循环创建卡片让"库位数量"由数据决定，点击事件把"地图"变成可交互界面。本篇示例用随机数据模拟占用状态，真实项目中占用数据来自数据库库位表、货品信息来自库存表——可视化层只负责"把数据变成格子"，与数据层解耦（见「系统架构设计」的分层思想）。

> [!essentials] 核心要点
> - **代码生成 UI**：`BuildBins()` 双重循环（3 排 × 4 列）创建 12 张库位卡片，`UniformGrid Columns="4"` 自动网格排布
> - **状态颜色编码**：空位深色 `#21262D` / 占用橙色 `#B88A00` / 选中绿色 `#238636`，状态一屏可读
> - **数据与控件分离**：`_occupied`/`_goods` 字典记录状态，卡片外观只是状态投影，改数据即改界面
> - **点击交互**：`MouseLeftButtonUp` 事件挂到每张卡片，点击后下方 `InfoText` 显示库位与货品详情
> - **可配置布局**：排数/列数由循环参数决定，货架扩容只改代码常量，无需重排 XAML

> [!example] 完整示例
> **库位可视化演示：用 UniformGrid 动态生成 3 排 × 4 列库位卡片（空位深色 / 占用橙色），点击库位在下方显示货品信息，直观呈现仓储库位占用情况：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         Title="库位可视化展示" Height="420" Width="540"
>         WindowStartupLocation="CenterScreen" Background="#0D1117">
>     <Grid Margin="15">
>         <Grid.RowDefinitions>
>             <RowDefinition Height="Auto"/>
>             <RowDefinition Height="*"/>
>             <RowDefinition Height="Auto"/>
>         </Grid.RowDefinitions>
>         <TextBlock Text="库位可视化（A 排 / B 排 / C 排）" Foreground="#58A6FF" FontSize="14"
>                    FontWeight="Bold" Margin="0,0,0,10"/>
>         <!-- 库位网格：由后台代码动态生成 3×4 卡片 -->
>         <UniformGrid Grid.Row="1" x:Name="BinGrid" Columns="4"/>
>         <StackPanel Grid.Row="2" Margin="0,10,0,0">
>             <TextBlock x:Name="InfoText" Text="点击库位查看详情" Foreground="#8B949E"/>
>             <TextBlock Text="图例：空位(深色)  占用(橙色)  目标入库(绿色)" Foreground="#8B949E"
>                        FontSize="11" Margin="0,4,0,0"/>
>         </StackPanel>
>     </Grid>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System;
> using System.Collections.Generic;
> using System.Windows;
> using System.Windows.Controls;
> using System.Windows.Input;
> using System.Windows.Media;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         private readonly Random _rand = new Random();
>         // 记录每个库位卡片的占用状态，便于点击时查询
>         private readonly Dictionary<Border, bool> _occupied = new Dictionary<Border, bool>();
>         // 占用库位的货品信息
>         private readonly Dictionary<Border, string> _goods = new Dictionary<Border, string>();
>
>         public MainWindow()
>         {
>             InitializeComponent();
>             BuildBins();
>         }
>
>         // 动态生成库位卡片（UniformGrid 自动按 4 列排布）
>         private void BuildBins()
>         {
>             for (int row = 0; row < 3; row++)
>             {
>                 for (int col = 0; col < 4; col++)
>                 {
>                     string code = $"{(char)('A' + row)}-0{col + 1}";
>                     var border = new Border
>                     {
>                         Background = new SolidColorBrush(Color.FromRgb(0x21, 0x26, 0x2D)),
>                         CornerRadius = new CornerRadius(6),
>                         Margin = new Thickness(3),
>                         Child = new TextBlock
>                         {
>                             Text = code,
>                             Foreground = new SolidColorBrush(Color.FromRgb(0x8B, 0x94, 0x9E)),
>                             HorizontalAlignment = HorizontalAlignment.Center,
>                             VerticalAlignment = VerticalAlignment.Center,
>                             FontSize = 14
>                         }
>                     };
>                     // 随机模拟占用状态与货品
>                     bool occupied = _rand.Next(2) == 1;
>                     if (occupied)
>                     {
>                         border.Background = new SolidColorBrush(Color.FromRgb(0xB8, 0x8A, 0x00));
>                         _occupied[border] = true;
>                         _goods[border] = $"轴承 6204 × {30 + _rand.Next(70)}";
>                     }
>                     else
>                     {
>                         _occupied[border] = false;
>                         _goods[border] = "";
>                     }
>                     border.MouseLeftButtonUp += OnBinClick; // 点击库位查看详情
>                     BinGrid.Children.Add(border);
>                 }
>             }
>         }
>
>         private void OnBinClick(object sender, MouseButtonEventArgs e)
>         {
>             var border = (Border)sender;
>             string code = ((TextBlock)border.Child).Text;
>             InfoText.Text = _occupied[border]
>                 ? $"库位 {code}：已占用 → {_goods[border]}"
>                 : $"库位 {code}：空位，可入库";
>             // 目标入库库位高亮为绿色（选中效果）
>             border.Background = new SolidColorBrush(Color.FromRgb(0x23, 0x86, 0x36));
>         }
>     }
> }
> ```
> 
> 

> [!scene] 适用场景
> ✅ 仓储库位地图：货架占用状态一屏可视化，仓管员快速定位空位、查找货品
> ✅ 出入库指引：点击空位标绿作为"目标入库位"，引导上架作业（WMS 上架推荐位）
> ✅ 数量随数据变化的网格：库位数、排布由配置决定，代码循环生成比手写 XAML 更灵活
> ✅ 资产/货架位置管理：机柜、工具柜、实验室设备位置同样适用"网格 + 状态色"模型
> ❌ 固定几个格子、永不变更的界面：手写 XAML 更直观，动态生成反而绕
> ❌ 需要复杂交互（拖拽换位、缩放）：Grid 静态布局不够，需虚拟化列表或第三方控件

> [!pitfall] 常见踩坑
> 坑 1：**动态创建的控件忘记挂事件** → 点击卡片毫无反应，调试半天找不到原因 → 创建时逐一 `border.MouseLeftButtonUp += OnBinClick`，并确保事件处理里正确取 `sender`
>
> 坑 2：**状态字典与界面不同步**（`_occupied` 只写不更新）→ 点击显示的状态与颜色不一致，如"显示空位却橙色" → 状态字典与卡片外观必须同源更新：入库/出库后先改字典再刷外观（见「库存管理与-rfid-集成」联动）
>
> 坑 3：**卡片在窗口 Resize 时变形**（文字溢出/挤压）→ 格子太小字被截断 → UniformGrid 固定最小尺寸或设 `MinWidth`，卡片用 Grid 内边距自适应
>
> 坑 4：**库位编号语义混乱**（A-1 与 A01 混用）→ 排序与检索对不上 → 编号规则统一（如 `A-01`，排-位两位补齐），生成与查询用同一套规则

> [!best] 最佳实践
> - 库位卡片用"数据驱动"生成：`List<BinInfo>` → 循环建卡片，新增库位只加数据不改 UI 代码
> - 状态颜色集中定义成常量/静态 Brush，避免散落魔法色值；状态色语义统一（空/占/选/异常）
> - 点击选中要做"取消选中"处理：再次点击恢复原色，避免地图越来越花
> - 空位直接允许入库、占用位禁止操作，交互规则与状态绑定，从 UI 层杜绝误操作
> - 与「库存管理与-rfid-集成」「需求与数据库设计」联动：地图数据来自数据库，出入库后刷新地图
> - 大仓库（数千库位）改用 `ItemsControl` + 虚拟化，避免一次性创建过多控件

> [!practice] 上手练习
> **Lv.1 照猫画虎**：运行示例，观察 3×4 库位网格的空位/占用配色，点击不同卡片看下方详情与绿色高亮
> **Lv.2 小试牛刀**：把布局改为 4 排 × 5 列，并给库位编号加"排-列"格式（如 `B-03`），验证循环参数驱动布局
> **Lv.3 融会贯通**：增加"再次点击恢复原色"的取消选中逻辑，并让占用卡片的货品名显示在卡片内（不只详情区）
> **Lv.4 挑战**：把库位数据接到 SQLite 库位表（`BinCode/Occupied/GoodsName`），启动时读库生成地图；再实现"点击空位 → 弹出入库框 → 写库 → 刷新地图"的完整闭环
