# 运动控制卡通信

> [!plain] 白话理解
> "运动控制卡通信"是 WPF 上位机开发中的一项重要知识。本项目控制多轴运动平台，实现点位运动、连续轨迹和轴状态监控。掌握了它，你就能更好地构建工业级上位机应用程序。

> [!def] 官方定义

> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System;
> using System.Windows;
> using System.Windows.Media;
> using System.Windows.Threading;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         // 轴当前状态（实际项目由控制卡驱动轮询回读）
>         private double _x, _y;
>         private double _xTarget, _yTarget;
>         private double _speed = 50; // 单位/秒
>         private bool _moving;
>         private readonly DispatcherTimer _timer = new DispatcherTimer();
>
>         public MainWindow()
>         {
>             InitializeComponent();
>             _timer.Interval = TimeSpan.FromMilliseconds(100); // 100ms 轮询一次
>             _timer.Tick += OnPoll;
>             _timer.Start();
>         }
>
>         // 下发点位运动命令：设定目标位置与速度
>         private void OnMove(object sender, RoutedEventArgs e)
>         {
>             double target = double.Parse(TargetBox.Text);
>             _speed = double.Parse(SpeedBox.Text);
>             if (AxisBox.SelectedIndex == 0) _xTarget = target; else _yTarget = target;
>             _moving = true;
>             CmdLog.Text = $"命令已下发：{(AxisBox.SelectedIndex == 0 ? "X" : "Y")} 轴 → {target} @ {_speed}/s";
>             CmdLog.Foreground = Brushes.Orange;
>         }
>
>         // 回原点命令
>         private void OnHome(object sender, RoutedEventArgs e)
>         {
>             _xTarget = 0; _yTarget = 0; _moving = true;
>             CmdLog.Text = "回原点命令已下发";
>             CmdLog.Foreground = Brushes.Orange;
>         }
>
>         // 轮询状态：控制卡按速度朝目标移动，这里模拟位置积分推进
>         private void OnPoll(object sender, EventArgs e)
>         {
>             double step = _speed * 0.1; // 100ms × 速度 = 每拍位移
>             if (_moving)
>             {
>                 _x += Math.Sign(_xTarget - _x) * Math.Min(Math.Abs(_xTarget - _x), step);
>                 _y += Math.Sign(_yTarget - _y) * Math.Min(Math.Abs(_yTarget - _y), step);
>                 if (Math.Abs(_x - _xTarget) < 0.01 && Math.Abs(_y - _yTarget) < 0.01)
>                 {
>                     _moving = false; // 到达目标，读回"运动到位"完成信号
>                     CmdLog.Text = "运动到位（完成信号）";
>                     CmdLog.Foreground = Brushes.LimeGreen;
>                 }
>             }
>             AxisStateText.Text = $"X 轴：{_x:F1}　Y 轴：{_y:F1}　{(_moving ? "运动中" : "运动停止")}";
>         }
>     }
> }
> ```

> [!best] 最佳实践
> - 编写代码时保持一致的命名规范（PascalCase 用于公共成员，_camelCase 用于私有字段）
> - 善用 Visual Studio 的智能提示和代码片段，提高开发效率
> - 每个关键代码块加上注释，解释"为什么这样写"而不仅仅是"写的是什么"
> - 遵循 SOLID 原则，尤其是单一职责原则：一个类只做一件事
> - 经常重构：写完功能后回头看看有没有更简洁的写法
