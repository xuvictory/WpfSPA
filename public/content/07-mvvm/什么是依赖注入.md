> [!example] 完整示例
> **依赖注入演示：数据服务通过构造函数注入到 ViewModel，而不是在 ViewModel 里 new 出来。这样更换服务实现（真实 PLC / Mock）只需改一处：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         Title="什么是依赖注入" Height="340" Width="400"
>         WindowStartupLocation="CenterScreen" Background="#0D1117">
>     <StackPanel Margin="20">
>         <TextBlock Text="产量统计（依赖注入）" Foreground="#58A6FF" FontSize="16" FontWeight="Bold"/>
>         <TextBlock Text="数据来源" Foreground="#8B949E" Margin="0,15,0,4"/>
>         <TextBlock Text="{Binding SourceName}" Foreground="#58A6FF" FontSize="14"/>
>         <TextBlock Text="今日产量（件）" Foreground="#8B949E" Margin="0,12,0,4"/>
>         <TextBlock Text="{Binding TodayOutput}" Foreground="White" FontSize="28" FontWeight="Bold"/>
>         <TextBlock Text="{Binding Remark}" Foreground="#238636" Margin="0,4,0,15"/>
>         <Button Content="刷新产量" Command="{Binding RefreshCommand}" Padding="8"
>                 Background="#21262D" Foreground="White" HorizontalAlignment="Left"/>
>     </StackPanel>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 构造函数注入：**
> ```csharp
> using System;
> using System.ComponentModel;
> using System.Windows;
> using System.Windows.Input;
>
> namespace HmiDemo
> {
>     // 数据服务接口：定义"取产量"能力，不关心具体实现
>     public interface IProductionService
>     {
>         int GetTodayOutput();
>         string SourceName { get; }
>     }
>
>     // 真实实现：连接 MES 系统（此处用随机数模拟）
>     public class MesProductionService : IProductionService
>     {
>         private readonly Random _rand = new Random();
>         public string SourceName => "MES 系统";
>         public int GetTodayOutput() => 800 + _rand.Next(400);
>     }
>
>     // 测试实现：固定返回值，便于单元测试（这就是注入的好处）
>     public class MockProductionService : IProductionService
>     {
>         public string SourceName => "测试 Mock";
>         public int GetTodayOutput() => 100;
>     }
>
>     public class MainViewModel : INotifyPropertyChanged
>     {
>         private readonly IProductionService _service; // 只依赖接口
>         private int _todayOutput;
>
>         // 依赖通过构造函数注入：谁想用，谁就传进来
>         public MainViewModel(IProductionService service)
>         {
>             _service = service;
>             RefreshCommand = new RelayCommand(Refresh);
>             Refresh();
>         }
>
>         public string SourceName => _service.SourceName;
>         public string TodayOutput => _todayOutput.ToString();
>         public string Remark => "注入的服务可在 MainWindow 里一行切换";
>         public ICommand RefreshCommand { get; }
>
>         private void Refresh()
>         {
>             _todayOutput = _service.GetTodayOutput();
>             OnPropertyChanged(nameof(TodayOutput));
>         }
>
>         public event PropertyChangedEventHandler PropertyChanged;
>         private void OnPropertyChanged(string name) =>
>             PropertyChanged?.Invoke(this, new PropertyChangedEventArgs(name));
>     }
>
>     public class RelayCommand : ICommand
>     {
>         private readonly Action _execute;
>         public RelayCommand(Action execute) => _execute = execute;
>         public bool CanExecute(object parameter) => true;
>         public void Execute(object parameter) => _execute();
>         public event EventHandler CanExecuteChanged;
>     }
>
>     public partial class MainWindow : Window
>     {
>         public MainWindow()
>         {
>             InitializeComponent();
>             // 想换数据源，只改这一行：new MockProductionService() 即可
>             DataContext = new MainViewModel(new MesProductionService());
>         }
>     }
> }
> ```

> - 善用 Visual Studio 的智能提示和代码片段，提高开发效率
> - 每个关键代码块加上注释，解释"为什么这样写"而不仅仅是"写的是什么"
> - 遵循 SOLID 原则，尤其是单一职责原则：一个类只做一件事
> - 经常重构：写完功能后回头看看有没有更简洁的写法
