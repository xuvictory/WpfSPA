# 动态切换主题

> [!plain] 白话理解
> 动态切换主题就像**给车间换照明方案**：晚上开深色模式（不刺眼），白天开浅色模式（看得清）。实施方法很简单——准备两套"颜色配方"（资源字典），界面上的颜色引用都写成"配方名"（`{DynamicResource Accent}`）而不是写死颜色；要换肤时，把当前配方整个抽走、换上另一套，所有引用"配方名"的地方自动跟着变。示例里 `dicts.Clear()` 再 `dicts.Add(...)` 就是"换配方"，按钮文字还会反过来提示现在该切到哪个主题。

> [!def] 官方定义
> 动态切换主题指在程序运行时替换主题资源字典，使界面全局换肤的技术。核心机制是 `ResourceDictionary.MergedDictionaries` 的**运行时重组**：维护多套同 Key 的资源字典（如深色/浅色），切换时从 `Application.Current.Resources.MergedDictionaries` 移除旧字典、插入新字典。所有界面引用必须使用 `DynamicResource`（而非 `StaticResource`）才能感知资源替换并自动刷新。详见官方文档：[DynamicResource 标记扩展](https://learn.microsoft.com/zh-cn/dotnet/desktop/wpf/advanced/dynamicresource-markup-extension)、[ResourceDictionary.MergedDictionaries](https://learn.microsoft.com/zh-cn/dotnet/api/system.windows.resourcedictionary.mergeddictionaries)。

> [!origin] 由来背景
> "运行时换肤"的需求在桌面开发中由来已久：早期 Web 时代是换 CSS，WinForms 时代靠遍历控件改属性，既慢又容易漏。WPF（2006 年随 .NET Framework 3.0 发布）的资源系统天然支持运行时替换：`ResourceDictionary` 里的资源可以整体增删，`DynamicResource` 引用会在资源变化时重新求值。于是"维护 N 套同 Key 字典 + 运行时替换 MergedDictionaries"成为 WPF 换肤的标准做法，后被 MaterialDesignInXAML、HandyControl 等控件库的主题切换机制广泛采用，也是上位机支持"日班/夜班"、"高亮/护眼"等主题切换需求的常见实现。

> [!essentials] 核心要点
> - **两套同 Key 字典**：深色/浅色（或 N 套主题）字典内 Key 完全一致，只是值不同——这是"换肤"的前提
> - **界面必须用 `DynamicResource`**：`StaticResource` 在编译期固定值，换了资源也不会更新；`DynamicResource` 运行时重新解析
> - **切换动作**：`Application.Current.Resources.MergedDictionaries` 移除旧字典、添加新字典（示例 `Clear()` + `Add()`）
> - **切换入口**：按钮（示例）或设置持久化（`Properties.Settings`）+ 启动时加载上次主题
> - **查找验证**：`FindResource` 找不到抛异常、`TryFindResource` 返回 null，切换后可用它确认资源已就位（示例 `OnCheckTheme`）
> - **窗口级 vs 应用级**：主题放 `Application` 级全局生效；仅某窗口换肤可放窗口资源并同样操作

> [!example] 完整示例
> **明暗主题切换演示：准备深色/浅色两套颜色资源字典，点击按钮通过运行时替换 MergedDictionaries 实现一键换肤，界面全部用 DynamicResource 自动跟随：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         Title="动态切换主题" Height="360" Width="440"
>         WindowStartupLocation="CenterScreen"
>         Background="{DynamicResource WindowBg}">
>     <Window.Resources>
>         <ResourceDictionary>
>             <ResourceDictionary.MergedDictionaries>
>                 <!-- 深色主题字典（默认） -->
>                 <ResourceDictionary x:Name="DarkTheme" x:Key="DarkTheme">
>                     <SolidColorBrush x:Key="WindowBg" Color="#0D1117"/>
>                     <SolidColorBrush x:Key="PanelBg" Color="#161B22"/>
>                     <SolidColorBrush x:Key="Accent" Color="#58A6FF"/>
>                     <SolidColorBrush x:Key="TextColor" Color="#8B949E"/>
>                     <SolidColorBrush x:Key="ButtonBg" Color="#21262D"/>
>                 </ResourceDictionary>
>                 <!-- 浅色主题字典：同 key，替换后界面自动换肤 -->
>                 <ResourceDictionary x:Name="LightTheme" x:Key="LightTheme">
>                     <SolidColorBrush x:Key="WindowBg" Color="#F6F8FA"/>
>                     <SolidColorBrush x:Key="PanelBg" Color="#FFFFFF"/>
>                     <SolidColorBrush x:Key="Accent" Color="#0969DA"/>
>                     <SolidColorBrush x:Key="TextColor" Color="#57606A"/>
>                     <SolidColorBrush x:Key="ButtonBg" Color="#D0D7DE"/>
>                 </ResourceDictionary>
>             </ResourceDictionary.MergedDictionaries>
>         </ResourceDictionary>
>     </Window.Resources>
>     <StackPanel Margin="15" Background="{DynamicResource PanelBg}" Padding="20">
>         <TextBlock Text="明暗主题动态切换（DynamicResource 自动跟随）"
>                    Foreground="{DynamicResource Accent}" FontSize="14" FontWeight="Bold"/>
>         <TextBlock Text="替换 MergedDictionaries 中同一 key 的资源即可全局换肤"
>                    Foreground="{DynamicResource TextColor}" Margin="0,12,0,0"/>
>         <StackPanel Orientation="Horizontal" Margin="0,20,0,0">
>             <Button x:Name="ThemeBtn" Content="切换到浅色主题" Padding="14,8" Margin="0,0,10,0"
>                     Background="{DynamicResource ButtonBg}" Foreground="{DynamicResource TextColor}"
>                     Click="OnToggleTheme"/>
>             <Button Content="验证资源存在" Padding="14,8"
>                     Background="{DynamicResource ButtonBg}" Foreground="{DynamicResource TextColor}"
>                     Click="OnCheckTheme"/>
>         </StackPanel>
>         <TextBlock x:Name="StatusText" Foreground="{DynamicResource TextColor}" Margin="0,15,0,0"/>
>     </StackPanel>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System.Windows;
> using System.Windows.Media;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         private bool _isLight; // 当前是否浅色主题
>
>         public MainWindow()
>         {
>             InitializeComponent();
>             StatusText.Text = "当前：深色主题";
>         }
>
>         // 核心：从 MergedDictionaries 中移除旧主题，插入新主题字典
>         private void OnToggleTheme(object sender, RoutedEventArgs e)
>         {
>             var dicts = Application.Current.Resources.MergedDictionaries;
>             dicts.Clear();
>
>             // 按需装载深色或浅色资源字典（这里直接取窗口资源中的两套字典）
>             if (_isLight)
>             {
>                 dicts.Add((ResourceDictionary)TryFindResource("DarkTheme"));
>                 ThemeBtn.Content = "切换到浅色主题";
>                 StatusText.Text = "当前：深色主题";
>             }
>             else
>             {
>                 dicts.Add((ResourceDictionary)TryFindResource("LightTheme"));
>                 ThemeBtn.Content = "切换到深色主题";
>                 StatusText.Text = "当前：浅色主题";
>             }
>             _isLight = !_isLight;
>         }
>
>         // 用 FindResource 验证资源是否可解析（查不到会抛异常）
>         private void OnCheckTheme(object sender, RoutedEventArgs e)
>         {
>             var accent = (SolidColorBrush)FindResource("Accent");
>             StatusText.Text = $"当前强调色：{accent.Color}";
>         }
>     }
> }
> ```
> 

> [!scene] 适用场景
> ✅ 上位机需要日/夜班主题切换（监控室白天看浅色、夜班看深色护眼）
> ✅ 同一产品卖给不同客户，用主题定制品牌色（换肤 = 换一套字典，不改代码）
> ✅ 需要"高对比度模式"供视力受限操作员使用
> ✅ 多窗口应用全局统一换肤（主题放 `Application` 级）
> ❌ 界面完全不换肤的展示程序（`StaticResource` 足够，动态机制徒增复杂度）
> ❌ 只有局部一两个控件需要变色（直接用 `DataTrigger`/`Style` 即可，不必全局换肤）

> [!pitfall] 常见踩坑
> 坑 1：**界面引用写的是 `StaticResource`** → 现象：切换主题后颜色没变 → 原因：`StaticResource` 编译期固定，不响应运行时替换 → 解决：需要随主题变化的引用一律改 `DynamicResource`；`StaticResource` 只用于真正固定的值
> 
> 坑 2：**切换后 `FindResource` 抛异常** → 现象：点切换按钮直接崩溃 → 原因：`TryFindResource` 返回 null 后 `Add((ResourceDictionary)null)`，或旧字典被 `Clear()` 后新字典还没就位 → 解决：切换前先判空、用 `TryFindResource`，字典引用先取出再 Clear/Add
>
> 坑 3：**换肤只换了一半** → 现象：窗口和面板变了，但图标、按钮模板没变 → 原因：部分资源（如 `ControlTemplate` 内的颜色）未用 `DynamicResource`，或第三方控件有自己的主题资源 → 解决：全面检查所有颜色引用；第三方控件库用其官方主题切换 API（见 `materialdesigninxaml-与-handycontrol-主题定制`）

> [!best] 最佳实践
> - 主题字典 Key 设计成"语义名"（`Accent`/`WindowBg`）而非"色值名"（`Blue`），换肤只换值不换名
> - 切换逻辑收敛到 `ThemeManager` 单例：`SetTheme("Dark")`，记录当前主题并持久化到设置，启动时自动恢复
> - 全部界面引用统一 `DynamicResource`，避免"局部不换肤"的排查噩梦；模板内 Setter 同样用 `DynamicResource`
> - 切换前 `TryFindResource` 确认新字典可解析，失败则保持旧主题并记录日志，不闪退
> - 主题切换后刷新数据绑定相关的 `DynamicResource`（通常自动生效），如有个别静态缓存需手动 `InvalidateVisual`

> [!practice] 上手练习
> **Lv.1 照猫画虎**：运行示例，反复点"切换主题"观察窗口、面板、按钮、文字整体换肤；点"验证资源存在"看强调色值变化
> **Lv.2 小试牛刀**：新增"护眼绿"第三套主题（`GreenTheme`），三个按钮循环切换，验证同 Key 多主题管理
> **Lv.3 融会贯通**：把 `_isLight` 状态与选择存到 `Properties.Settings`，程序启动时自动恢复上次主题；再加 `ComboBox` 选择主题代替按钮
> **Lv.4 拆层挑战**：把主题切换封装成 `ThemeManager`（`SetTheme`/`GetTheme`/`ThemeChanged` 事件），并让 `Button` 样式模板里也用 `DynamicResource` 引用主题色，验证模板级换肤
