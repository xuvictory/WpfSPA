# 自定义依赖属性

> [!plain] 白话理解
> 普通 CLR 属性就像配电柜里的"机械锁扣"——值存哪儿就在哪儿，改了只能靠别人主动来问。依赖属性则像一块**可广播的仪表盘**：值存在一个集中台账里，只要登记了"我对这个值感兴趣"，值一变你就自动收到通知。这就是上位机里 `绑定`、`样式`、`动画`、`触发器` 能"隔空"生效的底层原因。比如示例里的 `StatusLight.State`，下拉框一选"运行"，灯自己就变绿——中间没有任何手动刷新代码，因为属性变更回调 `OnStateChanged` 被自动触发。自定义依赖属性就是按规范在 `DependencyObject` 上注册自己的这种"仪表盘"。

> [!def] 官方定义
> 依赖属性（Dependency Property）是一种由 WPF 属性系统托管、值来自多方的特殊属性：最终值由"本地值、样式、模板、数据绑定、动画、继承"等来源按**优先级**计算得出，且任何变化都会自动通知所有 `Binding` 订阅者。自定义依赖属性即通过 `DependencyProperty.Register`（普通依赖属性）或 `DependencyProperty.RegisterAttached`（附加属性）注册到 `DependencyObject` 派生类上的属性。每个依赖属性都要同时提供 `GetValue`/`SetValue` 包装和 `static readonly DependencyProperty` 字段。详见官方文档：[依赖属性概述](https://learn.microsoft.com/zh-cn/dotnet/desktop/wpf/advanced/dependency-properties-overview)、[自定义依赖属性](https://learn.microsoft.com/zh-cn/dotnet/desktop/wpf/advanced/custom-dependency-properties)。

> [!origin] 由来背景
> WPF 属性系统的设计目标是为"UI 场景的属性"提供超过普通 CLR 属性的能力。2006 年 WPF 随 .NET Framework 3.0 发布前，WinForms 的控件属性是纯 CLR 属性：样式、模板、动画、绑定都要靠大量手工代码协调，一个属性的变化不会自动通知其他部分。WPF 引入依赖属性后，属性值有了**优先级链**（本地值 > 动画 > 模板绑定 > 样式触发器 > 样式 Setter > 继承 > 默认值），并内建变更通知。开发者要扩展 UI 能力（自定义控件的新属性）时，只需按规范 `Register` 一次，就能免费获得绑定、样式、动画等全套 WPF 特性。

> [!essentials] 核心要点
> - **三步注册法**：`static readonly DependencyProperty` 字段 + `DependencyProperty.Register(nameof(X), typeof(T), typeof(Owner), new PropertyMetadata(默认值, 回调))` + `GetValue`/`SetValue` 包装属性
> - **属性变更回调**：`PropertyChangedCallback` 签名 `(DependencyObject d, DependencyPropertyChangedEventArgs e)`，改值自动触发，`e.NewValue`/`e.OldValue` 取值
> - **附加属性**：用 `RegisterAttached` 注册，配 `Set/Get` 静态方法，可"挂"到任意元素（如示例的 `StatusLight.DeviceNo`）
> - **命名规范**：字段名 = 包装属性名 + "Property" 后缀，注册名用 `nameof` 避免魔法字符串
> - **元数据控制**：`PropertyMetadata` 可设默认值、`FrameworkPropertyMetadata` 可加 `AffectsRender`/`BindsTwoWayByDefault` 等渲染/绑定影响标志
> - **默认值类型注意**：引用类型默认值每次注册共享同一实例，用 `DefaultValueFactory`（`PropertyMetadata(工厂)`）创建

> [!example] 完整示例
> **设备状态指示灯演示：自定义 StatusLight 控件注册依赖属性（Register）与附加属性（RegisterAttached），切换状态自动触发属性变更回调并重绘颜色：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         xmlns:local="clr-namespace:HmiDemo"
>         Title="自定义依赖属性 - 状态灯" Height="340" Width="440"
>         WindowStartupLocation="CenterScreen" Background="#0D1117">
>     <StackPanel Margin="15">
>         <!-- 使用自定义控件，并通过附加属性给指示灯绑定设备编号 -->
>         <local:StatusLight x:Name="Lamp" Width="220" Height="110"
>                            local:StatusLight.DeviceNo="PLC-01"/>
>         <TextBlock Text="当前状态" Foreground="#8B949E" Margin="0,18,0,6"/>
>         <ComboBox x:Name="StateBox" SelectedIndex="0" Width="200" HorizontalAlignment="Left"
>                   Background="#21262D" Foreground="White" SelectionChanged="OnStateChanged">
>             <ComboBoxItem Content="停止"/>
>             <ComboBoxItem Content="运行"/>
>             <ComboBoxItem Content="报警"/>
>         </ComboBox>
>         <TextBlock x:Name="InfoText" Foreground="#8B949E" Margin="0,18,0,0" TextWrapping="Wrap"/>
>     </StackPanel>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码与自定义控件：**
> ```csharp
> using System;
> using System.Globalization;
> using System.Windows;
> using System.Windows.Controls;
> using System.Windows.Media;
>
> namespace HmiDemo
> {
>     // 上位机设备运行状态
>     public enum RunState { 停止, 运行, 报警 }
>
>     // 自定义状态指示灯控件：演示普通依赖属性 + 附加属性 + 属性变更回调
>     public class StatusLight : FrameworkElement
>     {
>         // 1. 普通依赖属性 Register：支持数据绑定、动画、样式等高级特性
>         public static readonly DependencyProperty StateProperty = DependencyProperty.Register(
>             nameof(State), typeof(RunState), typeof(StatusLight),
>             new PropertyMetadata(RunState.停止, OnStateChanged));
>
>         public RunState State
>         {
>             get => (RunState)GetValue(StateProperty);
>             set => SetValue(StateProperty, value);
>         }
>
>         // 属性变更回调：状态一变，立即请求重绘
>         private static void OnStateChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
>         {
>             ((StatusLight)d).InvalidateVisual();
>         }
>
>         // 2. 附加属性 RegisterAttached：可"挂"到任意元素上，常用于附加额外信息
>         public static readonly DependencyProperty DeviceNoProperty = DependencyProperty.RegisterAttached(
>             "DeviceNo", typeof(string), typeof(StatusLight),
>             new PropertyMetadata("未知设备", OnDeviceNoChanged));
>
>         public static void SetDeviceNo(DependencyObject o, string v) => o.SetValue(DeviceNoProperty, v);
>         public static string GetDeviceNo(DependencyObject o) => (string)o.GetValue(DeviceNoProperty);
>
>         private static void OnDeviceNoChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
>         {
>             ((StatusLight)d).InvalidateVisual();
>         }
>
>         // 按当前状态自绘：圆灯 + 状态文字 + 设备编号
>         protected override void OnRender(DrawingContext dc)
>         {
>             Brush lamp = State switch
>             {
>                 RunState.运行 => new SolidColorBrush(Color.FromRgb(0x23, 0x86, 0x36)), // 运行绿
>                 RunState.报警 => new SolidColorBrush(Color.FromRgb(0xDA, 0x36, 0x33)), // 报警红
>                 _ => new SolidColorBrush(Color.FromRgb(0x8B, 0x94, 0x9E))               // 停止灰
>             };
>             dc.DrawEllipse(lamp, null, new Point(40, 40), 26, 26);
>             dc.DrawText(NewText(State.ToString(), 20, "#58A6FF", true), new Point(82, 14));
>             dc.DrawText(NewText($"设备编号：{GetDeviceNo(this)}", 14, "#8B949E", false), new Point(82, 52));
>         }
>
>         // 生成带格式的文本，供 DrawingContext 直接绘制
>         private static FormattedText NewText(string text, double size, string color, bool bold)
>         {
>             var brush = new SolidColorBrush((Color)ColorConverter.ConvertFromString(color));
>             brush.Freeze();
>             return new FormattedText(text, CultureInfo.GetCultureInfo("zh-cn"),
>                 FlowDirection.LeftToRight,
>                 new Typeface("Microsoft YaHei UI", FontStyles.Normal,
>                     bold ? FontWeights.Bold : FontWeights.Normal, FontStretches.Normal),
>                 size, brush);
>         }
>     }
>
>     public partial class MainWindow : Window
>     {
>         public MainWindow()
>         {
>             InitializeComponent();
>             // 用静态 Get/Set 方法读取附加属性
>             InfoText.Text = $"指示灯已创建，附加属性读到设备编号：{StatusLight.GetDeviceNo(Lamp)}";
>         }
>
>         // 切换下拉框时把状态写进依赖属性，触发回调并重绘
>         private void OnStateChanged(object sender, SelectionChangedEventArgs e)
>         {
>             if (Lamp == null) return;
>             Lamp.State = (RunState)StateBox.SelectedIndex;
>         }
>     }
> }
> ```
> 

> [!scene] 适用场景
> ✅ 自定义控件的公开属性需要支持数据绑定（如把设备状态 `State` 绑给 VM 属性）
> ✅ 属性变化要驱动界面更新、动画或重绘（回调里 `InvalidateVisual`、`RaiseEvent`）
> ✅ 需要给"别人的控件"附加额外信息（附加属性：设备编号、工位号、报警级别）
> ✅ 属性值可能来自样式、模板绑定、触发器的场景（依赖属性的优先级链才排得清）
> ❌ 控件内部用的私有状态字段（不对外、不绑定，用普通字段即可，别过度注册）
> ❌ 纯计算属性（如根据其他属性算出的值，用只读 CLR 属性 + 依赖属性变更联动）

> [!pitfall] 常见踩坑
> 坑 1：**字段名没加 Property 后缀** → 现象：XAML 里写属性名报 `Property was already registered` 或解析失败 → 原因：WPF 属性系统靠约定在 XAML 解析时查找 `XxxProperty` 静态字段 → 解决：字段统一命名 `{属性名}Property`
> 
> 坑 2：**包装属性里做业务逻辑** → 现象：绑定、动画改值时逻辑不执行或执行多次 → 原因：绑定/动画走 `SetValue` 直达属性系统，**不经过**包装属性 setter → 解决：所有"值变化后要做的动作"放进 `PropertyChangedCallback`
>
> 坑 3：**默认值用可变的共享实例** → 现象：一个控件改了列表默认值，其他控件跟着变 → 原因：`PropertyMetadata` 里的引用类型默认值全局共享 → 解决：用 `PropertyMetadata(() => new List<string>())` 工厂为每个实例创建独立默认值

> [!best] 最佳实践
> - 属性值变化驱动 UI 时，回调里调用 `InvalidateVisual()` 或 `CoerceValue`，保持"属性 → 表现"单向流动
> - 依赖属性包装属性写成 lambda 表达式体（`get => (T)GetValue(...)`），保持干净
> - 涉及布局的属性（如宽度）在元数据中加 `FrameworkPropertyMetadataOptions.AffectsRender`，让系统自动重绘
> - 需要双向绑定的属性在元数据里设 `BindsTwoWayByDefault = true`，省去调用侧写 `Mode=TwoWay`
> - 附加属性提供 `SetXxx`/`GetXxx` 静态方法，内部调用 `SetValue`/`GetValue`，方便代码与 XAML 两用

> [!practice] 上手练习
> **Lv.1 照猫画虎**：运行示例，切换下拉框观察状态灯颜色与文字变化；把 `DeviceNo="PLC-01"` 改成其他编号，看 `InfoText` 的变化
> **Lv.2 小试牛刀**：给 `StatusLight` 新增一个 `int Intensity` 依赖属性（1~100），让 `OnRender` 里用透明度或尺寸反映强度，并在 XAML 中给它设置值
> **Lv.3 融会贯通**：把 `State` 属性绑定到 ViewModel：实现 `INotifyPropertyChanged` 后 `State = 运行`，观察灯是否自动变绿，体会依赖属性与数据绑定的衔接
> **Lv.4 拆层挑战**：给 `StateProperty` 增加 `CoerceValueCallback`：当控件 `IsEnabled=false` 时强制把状态钳制为"停止"，并验证本地赋值无法突破钳制
