# 自定义依赖属性

> [!plain] 白话理解
> "自定义依赖属性"是 WPF 上位机开发中的一项重要知识。在学习 WPF 上位机开发的过程中，"自定义依赖属性"是一个重要的知识点。当你掌握了基础控件，高级 UI 开发能让你的上位机从"能用"变成"好用"再变成"出彩"。掌握了它，你就能更好地构建工业级上位机应用程序。

> [!def] 官方定义
> 自定义依赖属性是 WPF / .NET 技术栈中由微软官方定义和实现的一个特性/概念/控件。它遵循 .NET 标准规范，为开发者提供了一套完整的编程接口（API）和最佳实践指南。详细定义请参考 Microsoft Docs 官方文档。

> [!origin] 由来背景
> 自定义依赖属性的诞生源于实际开发中的痛点。微软在设计 .NET 和 WPF 框架时，为了满足企业级应用（尤其是工业自动化、数据可视化等场景）的需求，引入了这一特性。它的设计理念参考了业界最佳实践，并在日后的版本迭代中不断优化。

> 本章节背景：当你掌握了基础控件，高级 UI 开发能让你的上位机从"能用"变成"好用"再变成"出彩"。

> [!example] 完整示例
> **设备状态指示灯演示：自定义 StatusLight 控件注册依赖属性（Register）与附加属性（RegisterAttached），切换状态自动触发属性变更回调并重绘颜色：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         xmlns:local="clr-namespace:HmiDemo"
>         Title="自定义依赖属性 - 状态灯" Height="340" Width="440"
>         WindowStartupLocation="CenterScreen" Background="#0D1117">
>     <StackPanel Margin="15">
>         <!-- 使用自定义控件，并通过附加属性给指示灯绑定设备编号 -->
>         <local:StatusLight x:Name="Lamp" Width="220" Height="110"
>                            local:StatusLight.DeviceNo="PLC-01"/>
>         <TextBlock Text="当前状态" Foreground="#8B949E" Margin="0,18,0,6"/>
>         <ComboBox x:Name="StateBox" SelectedIndex="0" Width="200" HorizontalAlignment="Left"
>                   Background="#21262D" Foreground="White" SelectionChanged="OnStateChanged">
>             <ComboBoxItem Content="停止"/>
>             <ComboBoxItem Content="运行"/>
>             <ComboBoxItem Content="报警"/>
>         </ComboBox>
>         <TextBlock x:Name="InfoText" Foreground="#8B949E" Margin="0,18,0,0" TextWrapping="Wrap"/>
>     </StackPanel>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码与自定义控件：**
> ```csharp
> using System;
> using System.Globalization;
> using System.Windows;
> using System.Windows.Controls;
> using System.Windows.Media;
>
> namespace HmiDemo
> {
>     // 上位机设备运行状态
>     public enum RunState { 停止, 运行, 报警 }
>
>     // 自定义状态指示灯控件：演示普通依赖属性 + 附加属性 + 属性变更回调
>     public class StatusLight : FrameworkElement
>     {
>         // 1. 普通依赖属性 Register：支持数据绑定、动画、样式等高级特性
>         public static readonly DependencyProperty StateProperty = DependencyProperty.Register(
>             nameof(State), typeof(RunState), typeof(StatusLight),
>             new PropertyMetadata(RunState.停止, OnStateChanged));
>
>         public RunState State
>         {
>             get => (RunState)GetValue(StateProperty);
>             set => SetValue(StateProperty, value);
>         }
>
>         // 属性变更回调：状态一变，立即请求重绘
>         private static void OnStateChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
>         {
>             ((StatusLight)d).InvalidateVisual();
>         }
>
>         // 2. 附加属性 RegisterAttached：可"挂"到任意元素上，常用于附加额外信息
>         public static readonly DependencyProperty DeviceNoProperty = DependencyProperty.RegisterAttached(
>             "DeviceNo", typeof(string), typeof(StatusLight),
>             new PropertyMetadata("未知设备", OnDeviceNoChanged));
>
>         public static void SetDeviceNo(DependencyObject o, string v) => o.SetValue(DeviceNoProperty, v);
>         public static string GetDeviceNo(DependencyObject o) => (string)o.GetValue(DeviceNoProperty);
>
>         private static void OnDeviceNoChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
>         {
>             ((StatusLight)d).InvalidateVisual();
>         }
>
>         // 按当前状态自绘：圆灯 + 状态文字 + 设备编号
>         protected override void OnRender(DrawingContext dc)
>         {
>             Brush lamp = State switch
>             {
>                 RunState.运行 => new SolidColorBrush(Color.FromRgb(0x23, 0x86, 0x36)), // 运行绿
>                 RunState.报警 => new SolidColorBrush(Color.FromRgb(0xDA, 0x36, 0x33)), // 报警红
>                 _ => new SolidColorBrush(Color.FromRgb(0x8B, 0x94, 0x9E))               // 停止灰
>             };
>             dc.DrawEllipse(lamp, null, new Point(40, 40), 26, 26);
>             dc.DrawText(NewText(State.ToString(), 20, "#58A6FF", true), new Point(82, 14));
>             dc.DrawText(NewText($"设备编号：{GetDeviceNo(this)}", 14, "#8B949E", false), new Point(82, 52));
>         }
>
>         // 生成带格式的文本，供 DrawingContext 直接绘制
>         private static FormattedText NewText(string text, double size, string color, bool bold)
>         {
>             var brush = new SolidColorBrush((Color)ColorConverter.ConvertFromString(color));
>             brush.Freeze();
>             return new FormattedText(text, CultureInfo.GetCultureInfo("zh-cn"),
>                 FlowDirection.LeftToRight,
>                 new Typeface("Microsoft YaHei UI", FontStyles.Normal,
>                     bold ? FontWeights.Bold : FontWeights.Normal, FontStretches.Normal),
>                 size, brush);
>         }
>     }
>
>     public partial class MainWindow : Window
>     {
>         public MainWindow()
>         {
>             InitializeComponent();
>             // 用静态 Get/Set 方法读取附加属性
>             InfoText.Text = $"指示灯已创建，附加属性读到设备编号：{StatusLight.GetDeviceNo(Lamp)}";
>         }
>
>         // 切换下拉框时把状态写进依赖属性，触发回调并重绘
>         private void OnStateChanged(object sender, SelectionChangedEventArgs e)
>         {
>             if (Lamp == null) return;
>             Lamp.State = (RunState)StateBox.SelectedIndex;
>         }
>     }
> }
> ```

> [!pitfall] 常见踩坑
> 坑 1：**概念理解不清就上手** → 建议先把本章节的前置知识点学完，理解基础原理后再动手写代码
> 
> 坑 2：**忽略了官方文档** → Microsoft Docs 上有最权威的说明和最完整的示例代码，遇到问题先查文档
>
> 坑 3：**代码写的太"一次性"** → 养成写可复用代码的习惯，以后项目中会反复用到这些知识

> [!best] 最佳实践
> - 编写代码时保持一致的命名规范（PascalCase 用于公共成员，_camelCase 用于私有字段）
> - 善用 Visual Studio 的智能提示和代码片段，提高开发效率
> - 每个关键代码块加上注释，解释"为什么这样写"而不仅仅是"写的是什么"
> - 遵循 SOLID 原则，尤其是单一职责原则：一个类只做一件事
> - 经常重构：写完功能后回头看看有没有更简洁的写法
