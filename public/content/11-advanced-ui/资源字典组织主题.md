> [!example] 完整示例
> **上位机深色主题演示：把颜色与控件样式按职责拆成独立资源字典（真实项目可拆分为 Colors.xaml / Styles.xaml 文件），MainWindow 通过 MergedDictionaries 合并，运行时用代码查找并修改资源实现整体换色：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         Title="资源字典 - 深色主题" Height="380" Width="460"
>         WindowStartupLocation="CenterScreen" Background="{DynamicResource Brush.Window}">
>     <Window.Resources>
>         <!--
>             真实项目中建议拆成独立文件：
>             App.xaml 里通过 ResourceDictionary.MergedDictionaries
>             合并 Colors.xaml（颜色）、Styles.xaml（控件样式），
>             这里为便于单文件演示直接内联组织，结构完全相同。
>         -->
>         <ResourceDictionary>
>             <ResourceDictionary.MergedDictionaries>
>                 <!-- 第 1 份：颜色字典，主题色统一收口在这里管理 -->
>                 <ResourceDictionary>
>                     <Color x:Key="Color.Window">#0D1117</Color>
>                     <Color x:Key="Color.Panel">#161B22</Color>
>                     <Color x:Key="Color.Accent">#58A6FF</Color>
>                     <SolidColorBrush x:Key="Brush.Window" Color="{StaticResource Color.Window}"/>
>                     <SolidColorBrush x:Key="Brush.Panel" Color="{StaticResource Color.Panel}"/>
>                     <SolidColorBrush x:Key="Brush.Accent" Color="{StaticResource Color.Accent}"/>
>                     <SolidColorBrush x:Key="Brush.ButtonBg" Color="#21262D"/>
>                     <SolidColorBrush x:Key="Brush.Text" Color="#8B949E"/>
>                 </ResourceDictionary>
>                 <!-- 第 2 份：控件样式字典，样式里只引用上面定义的颜色资源 -->
>                 <ResourceDictionary>
>                     <Style x:Key="ThemeButton" TargetType="Button">
>                         <Setter Property="Background" Value="{StaticResource Brush.ButtonBg}"/>
>                         <Setter Property="Foreground" Value="White"/>
>                         <Setter Property="Padding" Value="12,6"/>
>                         <Setter Property="Template">
>                             <Setter.Value>
>                                 <ControlTemplate TargetType="Button">
>                                     <Border x:Name="Bd" Background="{TemplateBinding Background}"
>                                             CornerRadius="4">
>                                         <ContentPresenter HorizontalAlignment="Center"
>                                                           VerticalAlignment="Center"/>
>                                     </Border>
>                                     <ControlTemplate.Triggers>
>                                         <Trigger Property="IsMouseOver" Value="True">
>                                             <Setter TargetName="Bd" Property="Background"
>                                                     Value="{StaticResource Brush.Accent}"/>
>                                         </Trigger>
>                                     </ControlTemplate.Triggers>
>                                 </ControlTemplate>
>                             </Setter.Value>
>                         </Setter>
>                     </Style>
>                 </ResourceDictionary>
>             </ResourceDictionary.MergedDictionaries>
>         </ResourceDictionary>
>     </Window.Resources>
>     <StackPanel Margin="15" Background="{StaticResource Brush.Panel}" Padding="15">
>         <TextBlock Text="资源字典组织主题（颜色 / 样式分离管理）"
>                    Foreground="{StaticResource Brush.Accent}" FontSize="14" FontWeight="Bold"/>
>         <TextBlock Text="按钮样式来自 Styles 字典，颜色来自 Colors 字典"
>                    Foreground="{StaticResource Brush.Text}" Margin="0,10,0,0"/>
>         <Button Content="更换强调色为绿色" Style="{StaticResource ThemeButton}"
>                 HorizontalAlignment="Left" Margin="0,18,0,0" Click="OnChangeAccent"/>
>         <TextBlock x:Name="StatusText" Foreground="{StaticResource Brush.Text}"
>                    Margin="0,12,0,0"/>
>     </StackPanel>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System.Windows;
> using System.Windows.Media;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         public MainWindow()
>         {
>             InitializeComponent();
>             // TryFindResource：沿 控件 → 窗口 → Application 资源树向上查找
>             var accent = (Brush)TryFindResource("Brush.Accent");
>             StatusText.Text = $"窗口查找到主题强调色：{accent}";
>         }
>
>         // 运行时直接替换资源字典中的颜色：所有引用该资源的元素同步刷新
>         private void OnChangeAccent(object sender, RoutedEventArgs e)
>         {
>             Application.Current.Resources["Color.Accent"] = Color.FromRgb(0x23, 0x86, 0x36);
>             StatusText.Text = "已将强调色替换为绿色（#238636）";
>         }
>     }
> }
> ```
>

> [!pitfall] 常见踩坑
> 坑 1：**概念理解不清就上手** → 建议先把本章节的前置知识点学完，理解基础原理后再动手写代码
> 
> 坑 2：**忽略了官方文档** → Microsoft Docs 上有最权威的说明和最完整的示例代码，遇到问题先查文档
>
> 坑 3：**代码写的太"一次性"** → 养成写可复用代码的习惯，以后项目中会反复用到这些知识

> [!best] 最佳实践
> - 编写代码时保持一致的命名规范（PascalCase 用于公共成员，_camelCase 用于私有字段）
> - 善用 Visual Studio 的智能提示和代码片段，提高开发效率
> - 每个关键代码块加上注释，解释"为什么这样写"而不仅仅是"写的是什么"
> - 遵循 SOLID 原则，尤其是单一职责原则：一个类只做一件事
> - 经常重构：写完功能后回头看看有没有更简洁的写法
