# 控件间拖拽

> [!plain] 白话理解
> 控件间拖拽像**用机械手把工件从料架夹到加工台**：左手（拖拽源）把工件"拿起来"（`DoDragDrop` 发起拖拽），右手（拖拽目标）提前声明"我这台子能接货"（`AllowDrop=true`），中间靠一个"托盘"（`DataObject`）传工件（数据）。示例里左侧列表是料架，右侧监控区是加工台：按住设备拖过去，松手时 `Drop` 事件里从托盘取出设备名加入监控列表。至于"按多久算拖、拖多远算拖"由 `SystemParameters.MinimumHorizontalDragDistance` 这些系统阈值决定，示例里已写清楚。

> [!def] 官方定义
> 控件间拖拽基于 WPF 的 OLE 拖放机制（`System.Windows.DragDrop`）：拖拽源调用 `DragDrop.DoDragDrop(source, dataObject, allowedEffects)` 启动拖放操作，`DataObject` 承载数据（`DataFormats` 标识格式）；拖拽目标需设 `AllowDrop="True"`，并处理 `DragEnter`/`DragOver`（通过设置 `e.Effects` 提供放置反馈）与 `Drop`（从 `e.Data.GetData(format)` 取数据）。整个拖放过程由操作系统 OLE 参与协调，可跨进程/跨窗口。详见官方文档：[拖放概述](https://learn.microsoft.com/zh-cn/dotnet/desktop/wpf/advanced/drag-and-drop-overview)、[DragDrop 类](https://learn.microsoft.com/zh-cn/dotnet/api/system.windows.dragdrop)。

> [!origin] 由来背景
> 拖拽交互的历史可以追溯到 1990 年代 Windows OLE 拖放规范（OLE2 Drag & Drop）：微软定义了一套跨应用搬运数据的协议——发起方把数据封装成 `IDataObject`，系统在鼠标拖动期间维护数据，目标方在进入/离开/释放时收到回调。WinForms 用 `Control.DoDragDrop` + `AllowDrop` 实现了简化版。WPF（2006 年随 .NET Framework 3.0 发布）在托管层重新实现了一套 `DragDrop`/`DataObject` API，兼容原生 OLE（因此 WPF 控件可以拖到 Word、Explorer），并利用路由事件让"目标判定"沿可视化树冒泡。上位机里"设备列表拖进监控区""报警条目拖到工单"这类交互，正是这套机制的典型应用。

> [!essentials] 核心要点
> - **拖拽源三件事**：`PreviewMouseLeftButtonDown` 记录起点 → `PreviewMouseMove` 超阈值后 `DragDrop.DoDragDrop(...)` 携带 `DataObject`（示例 `OnDeviceMouseDown`/`OnDeviceMouseMove`）
> - **拖拽目标两件事**：`AllowDrop="True"` + 处理 `Drop`（取数据）；`DragEnter`/`DragOver` 里设 `e.Effects` 控制光标反馈
> - **`DataObject` 与格式**：`new DataObject(DataFormats.Text, value)`，接收时 `GetDataPresent` 先验格式、`GetData` 再取数据
> - **`DragDropEffects`**：`Copy`/`Move`/`Link`/`None`，决定光标形态与"是否允许放置"
> - **区分点击与拖拽**：用 `SystemParameters.MinimumHorizontalDragDistance`/`MinimumVerticalDragDistance` 阈值判断（示例 `Math.Abs(...) < 阈值`）
> - **`e.Handled = true`**：拖放事件处理完要标记，防止继续冒泡干扰上层处理

> [!example] 完整示例
> **设备列表拖拽到监控区域演示：左侧 ListBox 项用 DoDragDrop 发起拖拽，右侧监控区设置 AllowDrop，通过 DragOver/DragEnter 显示反馈、Drop 事件接收文本数据并添加到监视列表：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         Title="控件间拖拽 - 设备监控" Height="420" Width="520"
>         WindowStartupLocation="CenterScreen" Background="#0D1117">
>     <Grid Margin="15">
>         <Grid.RowDefinitions>
>             <RowDefinition Height="Auto"/>
>             <RowDefinition Height="*"/>
>         </Grid.RowDefinitions>
>         <TextBlock Text="把左侧设备拖到右侧监控区（DoDragDrop / AllowDrop / Drop）"
>                    Foreground="#58A6FF" FontSize="14" FontWeight="Bold" TextWrapping="Wrap"/>
>         <Grid Grid.Row="1" Margin="0,12,0,0">
>             <Grid.ColumnDefinitions>
>                 <ColumnDefinition Width="*"/>
>                 <ColumnDefinition Width="*"/>
>             </Grid.ColumnDefinitions>
>             <!-- 拖拽源：列表项需允许被拖起 -->
>             <ListBox x:Name="DeviceList" Background="#161B22" BorderBrush="#21262D"
>                      PreviewMouseLeftButtonDown="OnDeviceMouseDown"
>                      PreviewMouseMove="OnDeviceMouseMove" Margin="0,0,6,0"/>
>             <!-- 拖拽目标：AllowDrop 决定能否接收拖拽 -->
>             <Border Grid.Column="1" x:Name="DropZone" Background="#161B22"
>                     BorderBrush="#21262D" BorderThickness="1" CornerRadius="4"
>                     Margin="6,0,0,0" AllowDrop="True"
>                     DragEnter="OnDragEnter" DragOver="OnDragOver" Drop="OnDrop">
>                 <StackPanel Margin="10">
>                     <TextBlock Text="已监控设备" Foreground="#58A6FF" FontWeight="Bold"
>                                HorizontalAlignment="Center"/>
>                     <ListBox x:Name="MonitoredList" Background="Transparent" BorderThickness="0"/>
>                 </StackPanel>
>             </Border>
>         </Grid>
>     </Grid>
> </Window>
> ```

> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System;
> using System.Collections.Generic;
> using System.Windows;
> using System.Windows.Controls;
> using System.Windows.Input;
> using System.Windows.Media;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         private Point _dragStart; // 记录按下位置，区分点击与拖拽
>
>         public MainWindow()
>         {
>             InitializeComponent();
>             DeviceList.ItemsSource = new List<string>
>             {
>                 "1# 注塑机", "2# 注塑机", "3# 注塑机", "4# 注塑机"
>             };
>             MonitoredList.ItemsSource = new List<string>();
>         }
>
>         // 按下时记录起点，并取出被按中的列表项
>         private void OnDeviceMouseDown(object sender, MouseButtonEventArgs e)
>         {
>             _dragStart = e.GetPosition(null);
>             var item = (ListBoxItem)ContainerFromItem(e);
>             if (item != null) item.IsSelected = true;
>         }
>
>         // 按住并移动超过阈值时启动拖拽：DoDragDrop 携带文本数据
>         private void OnDeviceMouseMove(object sender, MouseEventArgs e)
>         {
>             if (e.LeftButton != MouseButtonState.Pressed) return;
>             var pos = e.GetPosition(null);
>             if (Math.Abs(pos.X - _dragStart.X) < SystemParameters.MinimumHorizontalDragDistance &&
>                 Math.Abs(pos.Y - _dragStart.Y) < SystemParameters.MinimumVerticalDragDistance) return;
>
>             if (DeviceList.SelectedItem is string device)
>             {
>                 // DataObject 封装拖拽数据，格式为文本
>                 var data = new DataObject(DataFormats.Text, device);
>                 DragDrop.DoDragDrop(DeviceList, data, DragDropEffects.Copy);
>             }
>         }
>
>         // 拖拽进入：通过 Effect 给出可放置的光标反馈
>         private void OnDragEnter(object sender, DragEventArgs e)
>         {
>             e.Effects = e.Data.GetDataPresent(DataFormats.Text)
>                 ? DragDropEffects.Copy : DragDropEffects.None;
>             e.Handled = true;
>         }
>
>         private void OnDragOver(object sender, DragEventArgs e)
>         {
>             // 无文本数据时禁止放置
>             if (!e.Data.GetDataPresent(DataFormats.Text)) e.Effects = DragDropEffects.None;
>             e.Handled = true;
>         }
>
>         // 松手落点：从 e.Data 取出数据，加入监控列表
>         private void OnDrop(object sender, DragEventArgs e)
>         {
>             if (e.Data.GetData(DataFormats.Text) is string device)
>             {
>                 var items = (List<string>)MonitoredList.ItemsSource;
>                 items.Add(device);
>                 MonitoredList.Items.Refresh();
>             }
>             e.Handled = true;
>         }
>
>         // 根据鼠标位置返回其所属的 ListBoxItem（拖拽源辅助方法）
>         private static ListBoxItem ContainerFromItem(MouseEventArgs e)
>         {
>             var dep = (DependencyObject)e.OriginalSource;
>             while (dep != null && dep is not ListBoxItem)
>                 dep = VisualTreeHelper.GetParent(dep);
>             return dep as ListBoxItem;
>         }
>     }
> }
> ```
> 

> [!scene] 适用场景
> ✅ 把设备/报警/工单条目从列表拖到监控区、处理区（示例场景）
> ✅ 拖拽排序：调整工艺步骤、点位顺序（源与目标都是同一列表）
> ✅ 把外部文件（配方、参数表）拖进窗口触发导入
> ✅ 把列表项拖到回收区/删除区执行批量操作
> ❌ 鼠标操作受限的纯触屏工业平板（触控环境拖拽手感差，改用长按或按钮）
> ❌ 数据量大、拖拽频率极低的场景（按钮 + 命令更可靠、更易测试）

> [!pitfall] 常见踩坑
> 坑 1：**没设 `AllowDrop` 或忘了处理 `DragOver`** → 现象：鼠标拖过去没有"可放置"光标，松手无效 → 原因：目标未声明可接收，或 `DragOver` 里没设置 `e.Effects` → 解决：目标设 `AllowDrop="True"`，并在 `DragEnter`/`DragOver` 中按数据格式给 `e.Effects`
> 
> 坑 2：**点击列表项也会误触发拖拽** → 现象：只想点选却进入拖拽状态、列表抖动 → 原因：没做"位移阈值"判断，按下就 `DoDragDrop` → 解决：按示例用 `SystemParameters.MinimumHorizontalDragDistance`/`MinimumVerticalDragDistance` 判断，按住没动不算拖
>
> 坑 3：**`Drop` 里取不到数据** → 现象：松手后 `GetData` 返回 null → 原因：发起方与接收方 `DataFormats` 不一致，或 `DataObject` 未正确填充 → 解决：发起用 `new DataObject(DataFormats.Text, ...)`、接收用相同格式 `GetDataPresent(DataFormats.Text)` 先验证再取值

> [!best] 最佳实践
> - 拖拽数据格式用明确的 `DataFormats`（文本/文件/自定义），接收方先 `GetDataPresent` 校验格式再取值
> - 区分"点击"与"拖拽"用系统阈值（示例），避免误拖；拖拽起点建议在 `PreviewMouseLeftButtonDown` 记录
> - `DragOver` 里按数据合法性给 `e.Effects`（可拖/不可拖光标），比全靠 `Drop` 兜底体验好
> - 复杂对象拖拽用自定义 `DataFormats` 字符串（见 `自定义拖拽数据格式`），不要塞 `ToString()` 文本
> - 拖放事件统一 `e.Handled = true`，防止事件冒泡到外层容器重复处理

> [!practice] 上手练习
> **Lv.1 照猫画虎**：运行示例，把左侧设备逐个拖到右侧监控区，观察"可放置"光标与列表变化；把设备拖到空白处观察被拒绝的光标
> **Lv.2 小试牛刀**：给监控区增加"双击移回"功能；再给左侧列表增加"拖动排序"（同列表内拖拽调整顺序）
> **Lv.3 融会贯通**：把拖入的设备去重（`Contains` 判断）并显示拖入时间戳；右侧列表用 `ObservableCollection` 自动刷新
> **Lv.4 拆层挑战**：用自定义 `DataFormats` 传递 `Device` 对象（含状态、IP），拖到监控区后自动建立连接，体会数据对象与文本格式的差异
