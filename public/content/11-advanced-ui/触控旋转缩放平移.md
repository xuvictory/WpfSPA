# 触控旋转、缩放、平移

> [!plain] 白话理解
> 这一篇是 `manipulation-事件` 的"全家桶"升级版：上一篇只用了位移（Translation），这里把手势的**三个增量全用上**——单指拖动平移画面、双指捏合缩放画面、双指转动旋转画面，一次手势三种变换同时叠加，就像在手机上双指看照片一样。示例模拟工业相机查看器：一个"相机画面"矩形，`ManipulationDelta` 里的 `Scale` 驱动缩放（并限制在 0.5~4 倍）、`Rotation` 驱动旋转、`Translation` 驱动平移，三个变换挂在同一个 `TransformGroup` 上，右下角还有"复位"按钮一键回到原始状态。对做视觉检测、AOI 的上位机来说，这是查看大分辨率相机图的标配交互。

> [!def] 官方定义
> 触控旋转/缩放/平移指通过 `ManipulationDeltaEventArgs.DeltaManipulation`（`ManipulationDelta` 结构）一次性获取的单次手势增量：`Translation`（`Vector`，两指重心/单指的平移量）、`Scale`（`Vector`，相对上一帧的缩放倍率）、`Rotation`（`double`，相对上一帧的旋转角度，单位度）。将三者分别累加到 `RenderTransform` 的 `TransformGroup` 成员（`ScaleTransform` / `RotateTransform` / `TranslateTransform`）即可实现复合手势。变换顺序影响结果（`TransformGroup` 按声明顺序依次作用，示例为 Scale → Rotate → Translate）；`RenderTransformOrigin` 决定缩放/旋转的基准点。详见官方文档：[ManipulationDelta 结构](https://learn.microsoft.com/zh-cn/dotnet/api/system.windows.input.manipulationdelta)、[TransformGroup 类](https://learn.microsoft.com/zh-cn/dotnet/api/system.windows.media.transformgroup)、[WPF 变换概述](https://learn.microsoft.com/zh-cn/dotnet/desktop/wpf/graphics-multimedia/transforms-overview)。

> [!origin] 由来背景
> 传统工业相机上位机查看图片用鼠标三件套：滚轮缩放、中键拖动、右键旋转，每个操作一根"独立手势"，学习成本高，且滚轮一次一格很难平滑放大。WPF 4 引入 Manipulation 后，多点触控天然适合"三合一"手势——系统已经把触点合成为平移/缩放/旋转增量，开发者只需把它们映射到 `RenderTransform`。这一交互范式最早被地图应用与手机相册普及（2008 年前后 iPhone 的捏合手势），微软在 Win7/WPF 4 把同一范式带给桌面应用；对视觉检测上位机，它让"放大看缺陷、旋转对位、拖动找区域"变成一个连贯动作，效率远超鼠标三件套。`TransformGroup` 中缩放先于平移、旋转的顺序约定，也来自图形学变换矩阵的左乘叠加规则。

> [!essentials] 核心要点
> - **三合一增量**：`e.DeltaManipulation` 一次给全 `Translation`（平移）/`Scale`（缩放）/`Rotation`（旋转度），直接分派给三个变换
> - **累乘不赋值**：缩放是**相对倍率**，`ImageScale.ScaleX *= delta.Scale.X` 累乘（示例），直接 `=` 会导致跳变
> - **限幅保护**：缩放夹在 0.5~4 倍（示例 `Math.Max/Min`），旋转、平移按需求可无界或限制
> - **变换顺序**：`TransformGroup` 按声明顺序作用，示例 Scale → Rotate → Translate；顺序颠倒会导致缩放中心偏移、平移方向异常
> - **基准点**：`RenderTransformOrigin="0.5,0.5"` 让缩放/旋转围绕元素中心，默认 0,0 会绕左上角转
> - **复位**：重置 `ScaleX/Y=1`、`Angle=0`、`X/Y=0`（示例 `OnReset`），是手势应用必备的兜底入口

> [!example] 完整示例
> **工业相机图像手势控制演示：双指捏合缩放、双指旋转、单指平移同时作用于一张图片，通过 ManipulationDelta 里的 Scale / Rotation / Translation 组合更新 RenderTransform（旋转变换 + 缩放变换 + 平移变换）：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         Title="触控旋转缩放平移" Height="460" Width="560"
>         WindowStartupLocation="CenterScreen" Background="#0D1117">
>     <Grid Margin="15">
>         <Grid.RowDefinitions>
>             <RowDefinition Height="Auto"/>
>             <RowDefinition Height="*"/>
>             <RowDefinition Height="Auto"/>
>         </Grid.RowDefinitions>
>         <TextBlock Text="双指缩放 / 双指旋转 / 单指平移（ManipulationDelta 组合变换）"
>                    Foreground="#58A6FF" FontSize="14" FontWeight="Bold" TextWrapping="Wrap"/>
>         <!-- 手势作用区域：IsManipulationEnabled 开启后接收触控输入 -->
>         <Border Grid.Row="1" Margin="0,12,0,0" Background="#161B22"
>                 BorderBrush="#21262D" BorderThickness="1" CornerRadius="6"
>                 IsManipulationEnabled="True"
>                 ManipulationStarting="OnManipStarting"
>                 ManipulationDelta="OnManipDelta"
>                 ManipulationCompleted="OnManipCompleted">
>             <Grid>
>                 <!-- 模拟相机画面：矩形当图片，接受三种手势 -->
>                 <Rectangle x:Name="ImageFrame" Width="180" Height="120"
>                            Fill="#1F3A5F" Stroke="#58A6FF" StrokeThickness="1"
>                            HorizontalAlignment="Center" VerticalAlignment="Center"
>                            RenderTransformOrigin="0.5,0.5">
>                     <Rectangle.RenderTransform>
>                         <TransformGroup>
>                             <ScaleTransform x:Name="ImageScale"/>       <!-- 缩放 -->
>                             <RotateTransform x:Name="ImageRotate"/>     <!-- 旋转 -->
>                             <TranslateTransform x:Name="ImageMove"/>    <!-- 平移 -->
>                         </TransformGroup>
>                     </Rectangle.RenderTransform>
>                 </Rectangle>
>             </Grid>
>         </Border>
>         <StackPanel Grid.Row="2" Orientation="Horizontal" Margin="0,10,0,0">
>             <Button Content="复位" Click="OnReset" Padding="12,6" Margin="0,0,10,0"
>                     Background="#21262D" Foreground="White"/>
>             <TextBlock x:Name="StatusText" Foreground="#8B949E" VerticalAlignment="Center"/>
>         </StackPanel>
>     </Grid>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System.Windows;
> using System.Windows.Input;
> using System.Windows.Media;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         public MainWindow()
>         {
>             InitializeComponent();
>         }
>
>         private void OnManipStarting(object sender, ManipulationStartingEventArgs e)
>         {
>             e.ManipulationContainer = this;
>             e.Handled = true;
>         }
>
>         // 手势进行中：增量同时驱动 缩放 / 旋转 / 平移
>         private void OnManipDelta(object sender, ManipulationDeltaEventArgs e)
>         {
>             var delta = e.DeltaManipulation;
>
>             // 1. 缩放：捏合时 Scale 变化，限制在 0.5x ~ 4x
>             double scale = ImageScale.ScaleX * delta.Scale.X;
>             scale = System.Math.Max(0.5, System.Math.Min(scale, 4.0));
>             ImageScale.ScaleX = ImageScale.ScaleY = scale;
>
>             // 2. 旋转：双指转动时 Rotation 累计（单位：度）
>             ImageRotate.Angle += delta.Rotation;
>
>             // 3. 平移：单指拖动时 Translation 生效
>             ImageMove.X += delta.Translation.X;
>             ImageMove.Y += delta.Translation.Y;
>
>             StatusText.Text = $"缩放 {scale:F2}x　旋转 {ImageRotate.Angle:F0}°　" +
>                               $"位置 ({ImageMove.X:F0},{ImageMove.Y:F0})";
>             e.Handled = true;
>         }
>
>         private void OnManipCompleted(object sender, ManipulationCompletedEventArgs e)
>         {
>             e.Handled = true;
>         }
>
>         // 复位所有变换
>         private void OnReset(object sender, RoutedEventArgs e)
>         {
>             ImageScale.ScaleX = ImageScale.ScaleY = 1;
>             ImageRotate.Angle = 0;
>             ImageMove.X = ImageMove.Y = 0;
>             StatusText.Text = "已复位";
>         }
>     }
> }
> ```

> [!scene] 适用场景
> ✅ 工业相机 / 视觉检测上位机：放大看缺陷、旋转对位、拖动找区域一气呵成（示例场景）
> ✅ AOI / 显微镜图像查看器：双指捏合放大细节，单指平移扫描全图
> ✅ 工艺图纸 / 管路图浏览：触屏上缩放旋转查看，代替鼠标滚轮+旋转按钮
> ✅ 远程运维触屏终端：操作员远程查看现场画面时手势缩放定位
> ❌ 需要 1:1 像素精确测量的质检工具（缩放会破坏像素对应关系，应另设"测量模式"锁定视图）
> ❌ 纯鼠标环境（手势退化为鼠标事件，建议保留滚轮缩放等鼠标兜底路径）

> [!pitfall] 常见踩坑
> 坑 1：**缩放用赋值而不是累乘，画面"跳变"** → 现象：双指捏合时画面不是平滑缩放，而是每帧跳到固定倍率 → 原因：`DeltaManipulation.Scale` 是**相对上一帧的倍率**（如 1.03），直接 `ScaleX = delta.Scale.X` 会把当前倍率覆盖成 1.03 → 解决：`ImageScale.ScaleX *= delta.Scale.X`（示例写法），再夹紧到合理区间
> 
> 坑 2：**`TransformGroup` 顺序颠倒，缩放中心乱跑** → 现象：放大时画面不是围绕中心扩散，而是朝一角偏移 → 原因：Translate 在 Scale 之前时，平移量先作用、再被整体缩放放大 → 解决：保持 Scale → Rotate → Translate 顺序（示例声明顺序），并设 `RenderTransformOrigin="0.5,0.5"`
>
> 坑 3：**旋转后平移方向"反直觉"** → 现象：画面转 90° 后，单指右滑画面却往下跑 → 原因：平移发生在旋转后的局部坐标系里，方向被旋转矩阵扭转 → 解决：这是变换叠加的正常结果；若希望"指哪打哪"，可把 Translation 换算到窗口坐标系（用 `ManipulationContainer` 与当前角度做矩阵变换），或接受"画面局部系平移"并提示操作员
>
> 坑 4：**复位只清一个变换** → 现象：点了复位画面仍残留缩放或旋转 → 原因：只重置了 `ScaleX` 忘了 `ScaleY`，或平移旋转没归零 → 解决：三个变换全部归位（示例 `OnReset`），并用 StatusText 反馈"已复位"

> [!best] 最佳实践
> - 缩放用累乘并设上下限（示例 0.5~4），避免无限缩小/放大导致画面"失踪"
> - 复杂变换一律用 `TransformGroup` + 具名子变换，代码里按名称更新，别拼 `MatrixTransform` 手算矩阵
> - 手势区域与"复位"按钮保持同一容器，用户随时能一键找回初始视图
> - 给缩放/旋转加最小阈值（如 `|delta-1|>0.02` 才更新），过滤触控抖动造成的画面微颤
> - 与 `manipulation-事件` 一致：`ManipulationContainer = this` 统一坐标系，事件处理末尾 `e.Handled = true`
> - 相机查看场景建议叠加惯性（`ManipulationInertiaStarting`），松手后画面平滑滑动，观感更接近手机相册

> [!practice] 上手练习
> **Lv.1 照猫画虎**：触屏运行示例，分别用单指拖、双指捏、双指转操作矩形，观察状态栏的缩放/旋转/位置数值；点"复位"验证归零
> **Lv.2 小试牛刀**：把示例矩形换成一张真实相机图片（`Image` + `Source`），并把缩放上限提高到 8x；新增"双击复位"（`ManipulationCompleted` 时判断时间间隔与位移）
> **Lv.3 融会贯通**：实现"视图锁定"按钮：锁定后手势只平移不缩放旋转，模拟质检时的 1:1 查看模式；再叠加惯性滑动（`ManipulationInertiaStarting`）
> **Lv.4 拆层挑战**：封装 `GestureImageViewer` 用户控件（图片、手势、复位、惯性、缩放限幅、可选锁定模式），并把"当前视图参数（缩放/旋转/偏移）"暴露为依赖属性，接入 MVVM 实现"一键复位到上次视图"
