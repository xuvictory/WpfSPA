# 动画基础概念

> [!plain] 白话理解
> 动画就是"让属性随时间平滑变化"：把"灯的透明度、块的大小"当成数字，在指定时长内从起点插值到终点，WPF 的渲染线程每帧自动刷新。你不需要自己写 Timer 逐帧改值，只要声明"从 1 变到 1.25、用时 300ms、自动回放、无限循环"，引擎自己就跑起来了。工控里最常见的用途是心跳指示灯、报警闪烁、状态过渡。

> [!def] 官方定义
> WPF 动画体系核心在 `System.Windows.Media.Animation`：`Timeline`（时间线基类：Duration、AutoReverse、RepeatBehavior、BeginTime）、`AnimationTimeline`（动画时间线）、`DoubleAnimation` 等 From/To/By 型动画类。机制：动画通过时钟（Clock）按帧推进，在依赖属性上叠加"动画层"（优先级高于本地值，低于强制值）。启动方式：`BeginAnimation(DependencyProperty, AnimationTimeline)` 或 Storyboard。
>
> 官方文档：https://learn.microsoft.com/zh-cn/dotnet/api/system.windows.media.animation.timeline

> [!origin] 由来背景
> WPF 动画吸收了 Flash 时间轴的"时间线"思想，但实现方式完全不同：不做"帧序列"，而是基于属性插值的"属性动画"，由渲染线程的统一时钟驱动。保留模式渲染让动画天然 GPU 友好。相比 WinForms 时代用 Timer 手动刷值的做法，WPF 把"属性 + 时间"声明式表达，且所有动画共享时钟源保证全局同步——工控界面的状态动效由此变得简单可靠。

> [!essentials] 核心要点
> - **动画三要素**：目标属性（必须是依赖属性 DP）、时间线（Duration 时长）、插值（From 起点 → To 终点）
> - **时间线属性**：`Duration`（时长）、`AutoReverse`（播完自动倒放）、`RepeatBehavior`（次数或 Forever 无限）、`BeginTime`（延迟启动）
> - **启动方式**：`HeartScale.BeginAnimation(ScaleTransform.ScaleXProperty, anim)` 直接绑定属性
> - **只能动画 DP**：普通 CLR 属性无法动画，这也是 WPF 依赖属性体系的重要应用
> - **结束行为**：默认 `FillBehavior=Stop` 动画结束回原值；要保留终值设 `HoldEnd`

> [!example] 完整示例
> **心跳指示灯演示：用 DoubleAnimation 动画时间线（Duration、AutoReverse、RepeatBehavior）驱动指示灯闪烁，说明动画基础三要素——目标属性、时间线、插值：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         Title="心跳灯 - 动画基础" Height="380" Width="400"
>         WindowStartupLocation="CenterScreen" Background="#0D1117">
>     <Grid Margin="15">
>         <Grid.RowDefinitions>
>             <RowDefinition Height="Auto"/>
>             <RowDefinition Height="*"/>
>             <RowDefinition Height="Auto"/>
>         </Grid.RowDefinitions>
>         <TextBlock Text="设备心跳指示灯" Foreground="#58A6FF" FontSize="16" FontWeight="Bold"/>
>         <Grid Grid.Row="1" HorizontalAlignment="Center" VerticalAlignment="Center">
>             <Ellipse x:Name="Heart" Width="90" Height="90" Fill="#238636">
>                 <Ellipse.RenderTransform>
>                     <ScaleTransform x:Name="HeartScale" ScaleX="1" ScaleY="1"/>
>                 </Ellipse.RenderTransform>
>             </Ellipse>
>         </Grid>
>         <Button Grid.Row="2" Content="开始心跳" Click="OnStart" Margin="0,12,0,0"
>                 Padding="8" Background="#21262D" Foreground="White" HorizontalAlignment="Left"/>
>     </Grid>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System.Windows;
> using System.Windows.Media.Animation;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         public MainWindow()
>         {
>             InitializeComponent();
>         }
>
>         private void OnStart(object sender, RoutedEventArgs e)
>         {
>             // 动画基础：目标属性(ScaleX) + 时间线(Duration) + 插值(From/To)
>             var anim = new DoubleAnimation
>             {
>                 From = 1.0,
>                 To = 1.25,
>                 Duration = new Duration(System.TimeSpan.FromMilliseconds(300)),
>                 AutoReverse = true,                                  // 自动回放
>                 RepeatBehavior = RepeatBehavior.Forever              // 无限循环
>             };
>             HeartScale.BeginAnimation(System.Windows.Media.ScaleTransform.ScaleXProperty, anim);
>             HeartScale.BeginAnimation(System.Windows.Media.ScaleTransform.ScaleYProperty, anim);
>         }
>     }
> }
> ```
> 

> [!scene] 适用场景
> ✅ 心跳/运行指示灯：设备运行时绿色呼吸跳动，停止时灰暗
> ✅ 界面淡入淡出：窗口、弹窗、面板切换的过渡效果
> ✅ 状态变化过渡：数值更新时平滑滑到新值（如仪表指针、进度）
> ✅ 操作反馈：按钮按下/松开的弹性反馈
> ❌ 复杂多段动作序列：用关键帧动画 或 storyboard-故事板 编排
> ❌ 需要逐帧精确控制（如波形绘制）：用 CompositionTarget.Rendering 或 DispatcherTimer

> [!pitfall] 常见踩坑
> 坑 1：**动画没生效** → 现象：`BeginAnimation` 调了属性纹丝不动 → 原因：目标属性不是依赖属性（DP），或目标对象/属性名写错 → 解决：确认动画的是 DP（如 `ScaleTransform.ScaleXProperty`），并保证目标对象已实例化
> 
> 坑 2：**动画结束跳回原值** → 现象：心跳灯闪完跳回原始大小 → 原因：默认 `FillBehavior=Stop`，动画结束属性还原 → 解决：设 `FillBehavior=HoldEnd`，或 `RepeatBehavior=Forever` 让它不结束
>
> 坑 3：**两个动画抢同一属性** → 现象：后启动的动画覆盖前一个，状态混乱 → 原因：动画层"后到覆盖"，旧动画未清理 → 解决：切换动画前先 `BeginAnimation(prop, null)` 移除旧动画，或统一走 Storyboard 控制

> [!best] 最佳实践
> - 动画集中到渲染属性：`RenderTransform`（Scale/Rotate）+ Opacity，不动画 Width/Margin 等布局属性
> - 常驻动画（心跳）用 `RepeatBehavior=Forever`，一次性动画用完即止，不空转
> - 动画时长统一用资源常量（如 `AnimationDuration`），全局节奏一致
> - 动画只在状态变化时启动，空闲界面零动画开销
> - 动画目标用 `x:Name` 引用，属性路径用强类型常量，减少拼写错误

> [!practice] 上手练习
> **Lv.1 运行体验**：运行示例，观察心跳灯从 1.0→1.25 呼吸跳动的节奏
> **Lv.2 动手改造**：修改 Duration/AutoReverse/RepeatBehavior，感受时间线参数的影响
> **Lv.3 综合实战**：做"设备运行/停止"双态灯：运行绿心跳、停止灰静止，切状态动画自动启停
> **Lv.4 挑战进阶**：用 storyboard-故事板 把心跳灯 + 文字淡入编排成开机动画，统一 Begin
