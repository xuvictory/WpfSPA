# 上位机应用场景

> [!plain] 白话理解
> 这篇是把 path-路径 和 geometry-类型 用在上位机里的"实战总动员"：电源符号、报警三角、运行箭头——工控画面上最常出现的矢量小图标，全部可以用几个字母的 Data 画出来。理解了"图标 = Data 数据 + 一个 Path"，你就拥有了用代码组装任意上位机画面的能力。
>
> 类比：别人用截图当图标，你用 Data 当图标——就像用乐高说明书拼零件，而不是买成品贴纸。

> [!def] 官方定义
> 上位机（HMI/SCADA，Human Machine Interface）图形界面由状态图标、指示灯、趋势曲线、设备示意图等组成。本节是 Path 与 Geometry 在 HMI 场景的**综合应用**，不引入新 API，而是把 `Path.Data`、`GeometryGroup`、`Fill`/`Stroke` 状态切换组合成完整的工控面板元素（电源、报警、运行/停止、急停等）。
>
> 参考：工控组态软件（WinCC、组态王）的矢量画面与 WPF 的矢量模型同源，但 WPF 可用代码自由控制状态，远超固定图元。

> [!origin] 由来背景
> 传统组态软件用位图素材做状态图标：放大模糊、换肤要重做素材、状态色靠多张图片切换。WPF 用 Path 矢量图标后，一套 Data 可无限缩放、任意变色、随状态实时切换——这是 WPF 上位机相对传统组态软件的技术代差之一。图标还可与 MVVM 绑定，把"设备状态"直接映射为"图标颜色"，形成数据驱动的画面。

> [!essentials] 核心要点
> - **图标数据化**：电源（圆+竖线）、报警（三角）、运行（右箭头）都可压缩为 Data 字符串
> - **状态变色**：`Fill`/`Stroke` 随运行状态切换，是上位机图标的核心交互
> - **组合图标**：多段几何用 GeometryGroup 或叠加多个 Path 拼复杂图标
> - **尺寸统一**：图标设统一 Width/Height + `Stretch="Uniform"`，保证视觉整齐
> - **资源管理**：把图标 Data 存为 `x:Key` 资源，一处定义、多处复用，后续用 Style 统一

> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System.Windows;
> using System.Windows.Media;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         private bool _running;
>
>         public MainWindow()
>         {
>             InitializeComponent();
>         }
>
>         // 上电/断电：电源、报警灯、运行箭头同步变色
>         private void OnSwitch(object sender, RoutedEventArgs e)
>         {
>             _running = !_running;
>             var on = new SolidColorBrush(Color.FromRgb(0x23, 0x86, 0x36));
>             var off = new SolidColorBrush(Color.FromRgb(0x8B, 0x94, 0x9E));
>             var alarm = new SolidColorBrush(Color.FromRgb(0xDA, 0x36, 0x33));
>             if (_running)
>             {
>                 PowerRing.Stroke = on;
>                 PowerBar.Stroke = on;
>                 AlarmLight.Fill = alarm;      // 报警灯常亮红色
>                 RunArrow.Fill = on;
>             }
>             else
>             {
>                 PowerRing.Stroke = off;
>                 PowerBar.Stroke = off;
>                 AlarmLight.Fill = off;
>                 RunArrow.Fill = off;
>             }
>         }
>     }
> }
> ```

> [!scene] 适用场景
> ✅ 设备状态图标面板：电源、运行、报警、急停、待机等矢量图标阵列
> ✅ 状态变色联动：设备启停时图标颜色同步变化（绿/灰/红）
> ✅ 报警指示：三角/圆形报警图标配合颜色 + 闪烁动画
> ✅ 数据驱动画面：设备状态（bool）绑定图标颜色（Brush），实现 MVVM 化
> ❌ 需要照片/实景图：用 image-控件 或 imagebrush-图像画刷
> ❌ 动态数值型图形（曲线/柱状）：用 line-直线、polyline-折线 等数据图形

> [!pitfall] 常见踩坑
> 坑 1：**图标只有静态外观，状态切换不联动** → 现象：运行/停止时图标不变色 → 原因：只在 XAML 里画了图形，没写状态切换逻辑 → 解决：像示例一样在后台（或绑定）统一管理 Fill/Stroke 状态色
> 
> 坑 2：**手写 Data 让图标"歪掉"** → 现象：箭头/三角比例不协调 → 原因：手工估算坐标，缺乏辅助工具 → 解决：用简单对称坐标（如三角形 `0,34 40,34 20,0`）或 Blend 绘制
>
> 坑 3：**图标尺寸不统一导致面板凌乱** → 现象：各图标大小不一、对齐错位 → 原因：每个 Path 单独设尺寸、没有统一规范 → 解决：统一 Width/Height + `Stretch="Uniform"`，用相同 Margin 与对齐方式

> [!best] 最佳实践
> - 建图标资源库：把常用图标 Data 统一收进 `ResourceDictionary`，按用途命名（PowerIcon/AlarmIcon/RunIcon）
> - 状态颜色做成资源（`Brush x:Key="RunBrush"` 等），切换时查表赋值，不散落色值
> - 复杂图标叠加多个 Path 时用 Grid 对齐，保证各部件相对位置稳定
> - 用 MVVM 值转换器（bool→Brush）让图标颜色由数据驱动，见第 7 章
> - 图标旁边配 TextBlock 说明（如"电源""报警"），提升可读性，字体色与图标色统一

> [!practice] 上手练习
> **Lv.1 运行体验**：运行指示灯面板示例，点"切换状态"，观察电源/报警/运行图标颜色整体变化
> **Lv.2 动手改造**：新增一个"急停"图标（红色圆圈 + 红色横杠），切换状态时它保持红色但可置灰禁用
> **Lv.3 综合实战**：把状态色抽成 Brush 资源，用按钮切换三态（运行/停止/报警），图标颜色随之联动
> **Lv.4 挑战进阶**：用 Data 资源 + Style 重构整个面板，让每个图标都从 `ResourceDictionary` 引用，并尝试用数据绑定（IsRunning 布尔）驱动颜色
