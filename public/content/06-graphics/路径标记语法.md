# 路径标记语法

> [!plain] 白话理解
> 路径标记语法是"用一句话把图形画出来"的速记法。比如 `Data="M 40,180 A 100,100 0 0 1 240,180"` 翻译过来就是："把笔挪到 (40,180)，然后画一段半径 100 的圆弧，终点停在 (240,180)"。它省去了一堆对象嵌套，像暗号一样紧凑——学会读暗号，仪表盘刻度、指针、图标就都能手写了。
>
> 类比：对象写法是"用乐高一块块拼"，标记语法是"照着图纸用一句话报尺寸"。后者更快，但得先背命令表。

> [!def] 官方定义
> 路径标记语法（Path Mini-Language）是 WPF 为 `Path.Data` 提供的紧凑字符串语法。核心命令：`M`/`m`（MoveTo 移动起点）、`L`/`l`（LineTo 直线）、`H`/`h`（水平线）、`V`/`v`（垂直线）、`C`/`c`（三次贝塞尔）、`Q`/`q`（二次贝塞尔）、`A`/`a`（圆弧）、`Z`/`z`（闭合）。**大写 = 绝对坐标，小写 = 相对坐标**。
>
> 官方文档：https://learn.microsoft.com/zh-cn/dotnet/desktop/wpf/graphics-multimedia/path-markup-syntax

> [!origin] 由来背景
> 手写 PathGeometry 对象树冗长笨重，WPF 因此参考 SVG 的 path 设计，提供字符串微语言。命令集与 SVG `<path d="...">` 几乎一一对应，意味着设计师导出的 SVG 矢量素材可以几乎原样贴进 `Data` 属性；紧凑的字符串也方便存成资源、序列化，还能由 Blend 等工具自动生成——这是 WPF 图标/异形控件开发的"快捷键"。

> [!essentials] 核心要点
> - **命令表**：`M` 起点、`L/H/V` 直线、`C/Q` 贝塞尔、`A` 圆弧、`Z` 闭合——够用的就这几种
> - **大小写规则**：大写绝对坐标、小写相对坐标，混用会"飞线"，务必统一
> - **A 命令参数多**：`A rx ry rotate isLargeArc sweep x y`，前四参数决定弧的形状，最易写错
> - **分隔符**：坐标用空格或逗号分隔，命令间空格可省略（`M40 180L240 180`）
> - **Stretch 配合**：Data 写的是逻辑坐标，配合 Path 的 Width/Height + Stretch 自适应缩放

> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System.Windows;
> using System.Windows.Media;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         private bool _high;
>
>         public MainWindow()
>         {
>             InitializeComponent();
>         }
>
>         // 切换指针旋转角度，演示路径绘制与变换结合
>         private void OnToggle(object sender, RoutedEventArgs e)
>         {
>             _high = !_high;
>             Pointer.RenderTransform = new RotateTransform(_high ? 60 : 0);
>             Pointer.RenderTransformOrigin = new Point(0.5, 0.9);   // 以指针底部为旋转中心
>             Arc.Stroke = _high
>                 ? new SolidColorBrush(Color.FromRgb(0xDA, 0x36, 0x33)) // 高压告警红
>                 : new SolidColorBrush(Color.FromRgb(0x58, 0xA6, 0xFF));
>         }
>     }
> }
> ```

> [!scene] 适用场景
> ✅ 固定图标/符号：电源、报警、方向箭头等，Data 一行搞定
> ✅ 仪表盘刻度：M/L 命令批量画刻度短线的捷径（多条路径拼一个 Data）
> ✅ 圆弧进度/刻度：A 命令画弧形轨迹（压力表、转速表半圆）
> ✅ SVG 素材导入：设计师的 SVG path 直接贴成 Data
> ❌ 动态变化几何（需要代码改参数）：用 geometry-类型 的对象模型更可控
> ❌ 超复杂图形（几十段命令）：手写易错，用矢量编辑器生成

> [!pitfall] 常见踩坑
> 坑 1：**大小写命令混用导致图形错乱** → 现象：路径出现奇怪连线或飞离预期位置 → 原因：大写是绝对坐标、小写是相对坐标，混用坐标基准错乱 → 解决：同一 Data 统一用大写或小写体系，相对坐标只在小写命令里用
> 
> 坑 2：**A 圆弧命令参数写错** → 现象：弧的方向/大小不对，甚至画反 → 原因：A 命令有 7 个参数（起点、半径、旋转、大小弧、顺逆、终点），isLargeArc 和 sweep 最容易弄反 → 解决：记住 "0 0 1" 的常用组合先跑通，再调整；用注释标清每个参数
>
> 坑 3：**忘了 Z 闭合导致填充不完整** → 现象：图标底部"开口"，填充颜色从开口漏出 → 原因：图形未闭合 → 解决：末尾补 `Z`（闭合命令），形状封闭后才正确填充

> [!best] 最佳实践
> - Data 字符串写成多行并加注释，说明每段命令的用途，可读性远胜一行长串
> - 图标存成 `x:Key` 资源（`<Geometry x:Key="PowerIcon">...`），多处引用不重复
> - 从 SVG 导入时检查是否绝对坐标、有无缺失的 M 起点
> - 复杂图形用 Expression Blend 或矢量工具绘制后导出 Data，手写只用于简单形状
> - 先用 `Stretch="Uniform"` 固定尺寸预览，再微调坐标，避免"看不见/超出画布"来回折腾

> [!practice] 上手练习
> **Lv.1 运行体验**：运行压力表示例，点"切换指针位置"，观察 Data 路径 + RenderTransform 组合效果
> **Lv.2 动手改造**：手写一个对勾 Data（`M 2,6 L 7,11 L 14,2`）替换示例中的某个图形，并调整尺寸
> **Lv.3 综合实战**：用 M/L 命令给仪表盘加 8 根刻度线（长线+短线），替换示例中的固定刻度
> **Lv.4 挑战进阶**：找 3 个常用 SVG 图标（停止/暂停/急停），把它们转成 Data 并做成可切换状态的图标面板
