# 缓动函数

> [!plain] 白话理解
> 缓动函数管"运动节奏"：同一段位移，Linear 是匀速直冲，Quadratic 是慢起快停，Bounce 是落地弹两下，Elastic 是冲过头再收回。它不改变起点终点，只改变"中间怎么走"——就像开车油门踩法不同，路程相同但体感完全不同。工控里"滑块到位减速、弹窗弹出回弹、物料到位轻弹"都由它实现。

> [!def] 官方定义
> `System.Windows.Media.Animation.EasingFunctionBase`（抽象基类）实现 `IEasingFunction` 接口。常用实现：`LinearEase`、`QuadraticEase`、`CubicEase`、`PowerEase`（幂函数）、`BounceEase`（弹跳）、`ElasticEase`（振荡回弹）、`BackEase`（先退后进）、`CircleEase`、`SineEase`。`EasingMode` 枚举：`EaseIn`（加速）、`EaseOut`（减速）、`EaseInOut`（两端减速）。赋值给动画的 `EasingFunction` 属性即生效；`EasingDoubleKeyFrame` 用它的 EasingFunction 控制段内节奏。
>
> 官方文档：https://learn.microsoft.com/zh-cn/dotnet/api/system.windows.media.animation.easingfunctionbase

> [!origin] 由来背景
> 现实机械运动几乎不存在匀速——启停都有加/减速过程，生硬的 Linear 动画显得"机器化"。WPF 早期只有 Linear 插值，.NET 4.0 引入 EasingFunctionBase 体系，用数学函数（幂/贝塞尔/正弦/指数）调制"时间—值"曲线，让 UI 运动接近物理真实。工控 HMI 从"硬邦邦跳变"进化到"丝滑过渡"，弹窗、滑块、状态切换的体验都依赖这一套曲线。

> [!essentials] 核心要点
> - **EasingMode 三态**：EaseIn 慢起快停、EaseOut 快起慢停、EaseInOut 两端慢，视觉上多用 EaseOut/EaseInOut
> - **常用函数与感受**：Quadratic 柔和起步、Bounce 落地弹跳、Elastic 冲过头振荡回弹、Back 先退后进
> - **赋值方式**：`anim.EasingFunction = new QuadraticEase { EasingMode = EasingMode.EaseOut }`
> - **与关键帧配合**：`EasingDoubleKeyFrame` 的 EasingFunction 只控制该段内节奏
> - **自定义**：继承 `EasingFunctionBase` 重写 `EaseInCore` 可定制任意曲线

> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System.Windows;
> using System.Windows.Media;
> using System.Windows.Media.Animation;
> using System.Windows.Shapes;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         public MainWindow()
>         {
>             InitializeComponent();
>         }
>
>         private void OnPlay(object sender, RoutedEventArgs e)
>         {
>             // 同一属性、同一时长，仅 EasingFunction 不同
>             Play(R1, new LinearEase());
>             Play(R2, new QuadraticEase { EasingMode = EasingMode.EaseOut });
>             Play(R3, new BounceEase());
>             Play(R4, new ElasticEase());
>         }
>
>         private void Play(Rectangle r, IEasingFunction easing)
>         {
>             // 用 TranslateTransform 承载位移，动画作用于 X 属性
>             var t = new TranslateTransform();
>             r.RenderTransform = t;
>             var anim = new DoubleAnimation(360, new Duration(System.TimeSpan.FromSeconds(1.6)))
>             {
>                 EasingFunction = easing   // 关键：缓动函数决定运动节奏
>             };
>             t.BeginAnimation(TranslateTransform.XProperty, anim);
>         }
>     }
> }
> ```

> [!scene] 适用场景
> ✅ 滑块/门体到位减速：EaseOut 让滑动末端自然减速停下
> ✅ 弹窗弹出回弹：BackEase/ElasticEase 制造"弹出"手感
> ✅ 物料到位轻弹：BounceEase 让物料落到终点轻轻弹一下
> ✅ 仪表指针到位：指针滑到刻度时减速停稳（QuadraticEase）
> ❌ 需要精确匀速（如倒计时进度）：直接用 LinearEase
> ❌ 真实机械运动模拟：需物理公式计算，缓动只是视觉近似

> [!pitfall] 常见踩坑
> 坑 1：**弹跳/回弹"过头"夸张** → 现象：Bounce/Elastic 动画越界或幅度过大 → 原因：EasingMode 不当或振荡参数没收敛 → 解决：用 EaseInOut 收敛两端；ElasticEase 减小 Oscillations，BounceEase 减小 Bounciness
> 
> 坑 2：**缓动赋了但没生效** → 现象：EasingFunction 赋值后运动仍是匀速 → 原因：赋错对象——赋给了动画而非关键帧，或动画类型不支持 → 解决：DoubleAnimation 直接赋 `EasingFunction`；段内节奏赋给 `EasingDoubleKeyFrame.EasingFunction`
>
> 坑 3：**动画"停不下来"** → 现象：Elastic/Back 结束后还振荡好几下 → 原因：振荡类函数本身特性，参数偏大 → 解决：调小 Oscillations/Springiness，或改用 BounceEase/CircleEase

> [!best] 最佳实践
> - 沉淀常用节奏：进入页 EaseOut、弹窗弹出 EaseOutBack、报警闪烁 Linear、指针到位 QuadraticEase
> - EasingMode 默认是 EaseIn（生硬），视觉上多用 EaseOut/EaseInOut
> - 时长与函数参数资源化统一管理，改风格只动资源
> - 与关键帧组合：EasingDoubleKeyFrame 控制段内节奏，实现"到位减速"的真实机械手感
> - 自定义曲线时重写 `EaseInCore` 并缓存计算结果，避免每帧重复计算

> [!practice] 上手练习
> **Lv.1 运行体验**：运行示例，对比 Linear 与 Quadratic/Back/Bounce 的运动手感差异
> **Lv.2 动手改造**：把示例换成 BackEase、CircleEase、ElasticEase，记录各自的视觉特征
> **Lv.3 综合实战**：做"弹窗弹出"动画：Scale 从 0→1 + EaseOutBack 回弹，配透明度淡入
> **Lv.4 挑战进阶**：做"仪表指针到位"动画：指针从 0 转到目标刻度，QuadraticEase 慢停并停留在终值
