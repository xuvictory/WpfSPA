# 2D 绘图综合

> [!plain] 白话理解
> 这一篇是把前面学的"零件"组装成"设备图纸"：Shape 是成品贴纸、Brush 是颜料、Geometry 是形状模具、Transform 是摆位工具，而 `OnRender` 自绘是"直接用画笔在画布上画"。2D 绘图综合不是新控件，而是教你按画面复杂度和动态需求，在"XAML 声明"与"自绘"之间选对路线，把设备俯视图、工艺流程、产线布局画成一张完整的上位机画面。

> [!def] 官方定义
> 本篇综合 `System.Windows.Shapes`（Shape 家族）、`System.Windows.Media`（Brush/Geometry/Transform）与 `FrameworkElement.OnRender(DrawingContext dc)` 自绘三条绘图路径。自绘核心是 `DrawingContext`：提供 `DrawLine`、`DrawRectangle`、`DrawEllipse`、`DrawRoundedRectangle`、`DrawText`、`DrawGeometry`、`DrawImage` 等绘制 API；配合 `InvalidateVisual()` 请求重绘（WPF 会重新调用 OnRender）。适用基类：`FrameworkElement` 或 `UIElement`。
>
> 官方文档：https://learn.microsoft.com/zh-cn/dotnet/api/system.windows.media.drawingcontext

> [!origin] 由来背景
> 早期 Windows 图形编程（GDI/GDI+）是"立即模式"：每帧手工重绘、句柄管理繁琐。WPF 采用保留模式渲染，图形对象由引擎维护，开发者只描述"画面是什么"。OnRender 自绘继承自 UIElement 渲染管线（`Render()` 内部调用 `OnRender`），适合动态、数据驱动的复杂画面；与声明式 Shape 结合，就构成了 WPF 2D 绘图的完整打法——这是工控设备图、动态看板的标准实现思路。

> [!essentials] 核心要点
> - **三条路径选型**：Shape 声明式（静态设备图）、OnRender 自绘（动态频繁重绘）、DrawingVisual（高性能批量绘制）
> - **DrawingContext API**：DrawLine/DrawEllipse/DrawRoundedRectangle/DrawText/DrawGeometry/DrawImage，坐标即 OnRender 的绘图区域
> - **重绘触发**：数据变更后调用 `InvalidateVisual()`，WPF 才重新执行 OnRender
> - **文字绘制**：OnRender 里用 `FormattedText` + `DrawText`，TextBlock 是控件不能在 DrawingContext 里用
> - **组合套路**：静态结构用 XAML Shape/Path 声明，动态细节（实时数值、状态色）用 OnRender 自绘

> [!example] 完整示例
> **OnRender 自绘演示：继承 FrameworkElement 重写 OnRender，用 DrawingContext 的 DrawLine/DrawEllipse/DrawText 绘制设备简图：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         xmlns:local="clr-namespace:HmiDemo"
>         Title="2D 自绘 - OnRender" Height="420" Width="460"
>         WindowStartupLocation="CenterScreen" Background="#0D1117">
>     <Grid Margin="15">
>         <Grid.RowDefinitions>
>             <RowDefinition Height="Auto"/>
>             <RowDefinition Height="*"/>
>             <RowDefinition Height="Auto"/>
>         </Grid.RowDefinitions>
>         <TextBlock Text="输送线俯视图（DrawingContext 自绘）" Foreground="#58A6FF" FontSize="16" FontWeight="Bold"/>
>         <!-- 自定义绘制控件 -->
>         <local:ConveyorView x:Name="View" Grid.Row="1" Margin="0,10,0,0"
>                             Background="#161B22"/>
>         <Button Grid.Row="2" Content="重新绘制" Click="OnRedraw" Margin="0,12,0,0"
>                 Padding="8" Background="#21262D" Foreground="White" HorizontalAlignment="Left"/>
>     </Grid>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System.Windows;
> using System.Windows.Media;
>
> namespace HmiDemo
> {
>     // 自定义绘制控件：重写 OnRender 使用 DrawingContext 绘制
>     public class ConveyorView : FrameworkElement
>     {
>         protected override void OnRender(DrawingContext dc)
>         {
>             base.OnRender(dc);
>             // 1. 传送带轨道
>             dc.DrawLine(new Pen(new SolidColorBrush(Color.FromRgb(0x30, 0x36, 0x3D)), 6),
>                         new Point(20, 120), new Point(420, 120));
>             // 2. 三个物料块
>             dc.DrawRoundedRectangle(new SolidColorBrush(Color.FromRgb(0x23, 0x86, 0x36)), null,
>                                     new Rect(50, 95, 40, 30), 4, 4);
>             dc.DrawRoundedRectangle(new SolidColorBrush(Color.FromRgb(0x58, 0xA6, 0xFF)), null,
>                                     new Rect(180, 95, 40, 30), 4, 4);
>             dc.DrawRoundedRectangle(new SolidColorBrush(Color.FromRgb(0xDA, 0x36, 0x33)), null,
>                                     new Rect(310, 95, 40, 30), 4, 4);
>             // 3. 滚筒
>             dc.DrawEllipse(null, new Pen(new SolidColorBrush(Color.FromRgb(0x8B, 0x94, 0x9E)), 2),
>                            new Point(30, 120), 12, 12);
>             dc.DrawEllipse(null, new Pen(new SolidColorBrush(Color.FromRgb(0x8B, 0x94, 0x9E)), 2),
>                            new Point(410, 120), 12, 12);
>             // 4. 文字标注
>             var text = new FormattedText("输送线 2 号段", System.Globalization.CultureInfo.CurrentCulture,
>                 FlowDirection.LeftToRight, new Typeface("Microsoft YaHei"), 14,
>                 new SolidColorBrush(Color.FromRgb(0x8B, 0x94, 0x9E)));
>             dc.DrawText(text, new Point(160, 150));
>         }
>     }
>
>     public partial class MainWindow : Window
>     {
>         public MainWindow()
>         {
>             InitializeComponent();
>         }
>
>         private void OnRedraw(object sender, RoutedEventArgs e)
>         {
>             View.InvalidateVisual();   // 触发重新 OnRender
>         }
>     }
> }
> ```
> 

> [!scene] 适用场景
> ✅ 设备俯视图/工艺流程图：XAML 声明 Shape/Path 静态绘制
> ✅ 动态刷新画面：OnRender 自绘 + InvalidateVisual 数据驱动重绘
> ✅ 高性能批量绘制：DrawingVisual 绘制大量物料点、轨迹点
> ✅ 复杂看板：静态结构 + 动态数据的混合方案
> ❌ 简单静态图形：直接用 XAML 声明即可，不必上自绘
> ❌ 超大/无限画布场景：应分块绘制或改用地图类组件

> [!pitfall] 常见踩坑
> 坑 1：**OnRender 里用 TextBlock 报错/不显示** → 现象：自绘时想放文字，编译错误或画面空白 → 原因：OnRender 只能通过 DrawingContext 绘制，不能放置 UIElement 控件 → 解决：文字用 `FormattedText` + `DrawText`，图片用 `DrawImage`
> 
> 坑 2：**数据变了画面不刷新** → 现象：改了数据调用重绘，画面纹丝不动 → 原因：没有调用 `InvalidateVisual()`，WPF 不会主动重跑 OnRender → 解决：数据变更后显式调用 `InvalidateVisual()` 触发重绘
>
> 坑 3：**自绘内容被截断/不显示** → 现象：OnRender 画的东西超出范围或直接不出现 → 原因：FrameworkElement 没有布局尺寸，绘制区域实际为 0 → 解决：给控件设 Width/Height，或重写 MeasureOverride/ArrangeOverride 提供尺寸

> [!best] 最佳实践
> - 先规划 z 序：背景轨道 → 设备 → 物料 → 文字，按此顺序依次绘制
> - 动态数据与绘制分离：数据字段存控件内，InvalidateVisual 时统一重绘，不零散刷新
> - 画笔/颜色用静态资源（static Brush），避免每次 OnRender new 对象
> - 静态结构用 XAML 声明，动态部分用 OnRender，两者结合各取所长
> - 坐标全部基于控件的 ActualWidth/ActualHeight 归一化，窗口缩放不失真
