# 基础动画类型

> [!plain] 白话理解
> 动画按"值的类型"分家：数值型属性（宽高、透明度、角度）用 DoubleAnimation，颜色（蓝变红）用 ColorAnimation，厚度（边距、边框）用 ThicknessAnimation，还有 PointAnimation、Int32Animation 等。选动画类就像选钥匙：属性是什么类型，就用对应的动画类去开锁。工控里最常见的三类是：进度条宽度（Double）、报警颜色（Color）、按钮边距呼吸效果（Thickness）。

> [!def] 官方定义
> `System.Windows.Media.Animation` 中的基础动画类按目标属性的值类型划分：`DoubleAnimation`（double 型：Width/Opacity/Angle/Scale）、`ColorAnimation`（Color 型：画刷颜色）、`ThicknessAnimation`（Thickness 型：Margin/Padding/BorderThickness）、`PointAnimation`（Point 型）、`Int32Animation`（int 型）。颜色动画的典型用法：`ColorBox.Background = new SolidColorBrush(); ColorBox.Background.BeginAnimation(SolidColorBrush.ColorProperty, anim);`——动画的是画刷的 Color，而非元素自身的 Background。
>
> 官方文档：https://learn.microsoft.com/zh-cn/dotnet/api/system.windows.media.animation.doubleanimation

> [!origin] 由来背景
> 属性动画机制需要对"任意值类型"做插值计算，WPF 为每种常用类型配套了动画类（double/Color/Thickness/Point…），配合类型转换器形成完整的动画类族。设计动机：开发者按属性类型选动画类即可完成九成需求，无需自写插值算法。工控场景中"宽度增长=进度、颜色变化=状态、边距变化=呼吸提醒"正是这几类动画的标准用途。

> [!essentials] 核心要点
> - **类型对照表**：double → DoubleAnimation、Color → ColorAnimation、Thickness → ThicknessAnimation、Point → PointAnimation
> - **颜色动画的坑点**：动画目标必须是 `SolidColorBrush.ColorProperty`，不是元素的 Background 属性
> - **构造简写**：`new DoubleAnimation(To, Duration)` 或对象初始化器完整写 From/To/Duration
> - **属性类型匹配**：动画类与属性值类型不一致会在运行时报错，选型先对照类型表
> - **多动画并存**：同一元素的不同属性可同时被多个动画驱动，互不干扰

> [!example] 完整示例
> **多类型动画演示：集中展示 DoubleAnimation（数值）、ColorAnimation（颜色）、ThicknessAnimation（边距）三类基础动画，点击按钮同时驱动：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         Title="动画类型 - 基础三类" Height="420" Width="460"
>         WindowStartupLocation="CenterScreen" Background="#0D1117">
>     <Grid Margin="15">
>         <Grid.RowDefinitions>
>             <RowDefinition Height="Auto"/>
>             <RowDefinition Height="*"/>
>             <RowDefinition Height="Auto"/>
>         </Grid.RowDefinitions>
>         <TextBlock Text="基础动画类型演示" Foreground="#58A6FF" FontSize="16" FontWeight="Bold"/>
>         <StackPanel Grid.Row="1" VerticalAlignment="Center">
>             <!-- 数值动画：控制宽度 -->
>             <Border x:Name="Bar" Width="120" Height="30" CornerRadius="4" Background="#21262D"
>                     HorizontalAlignment="Left" Margin="10,6"/>
>             <!-- 颜色动画：控制背景 -->
>             <Border x:Name="ColorBox" Height="40" CornerRadius="4" Background="#58A6FF"
>                     Margin="10,6">
>             </Border>
>             <!-- 边距动画：控制内边距 -->
>             <Button x:Name="PadBtn" Content="边距动画" Padding="8,20" Background="#238636"
>                     Foreground="White" HorizontalAlignment="Left" Margin="10,6"/>
>         </StackPanel>
>         <Button Grid.Row="2" Content="播放动画" Click="OnPlay" Margin="0,12,0,0"
>                 Padding="8" Background="#21262D" Foreground="White" HorizontalAlignment="Left"/>
>     </Grid>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System.Windows;
> using System.Windows.Media;
> using System.Windows.Media.Animation;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         public MainWindow()
>         {
>             InitializeComponent();
>         }
>
>         private void OnPlay(object sender, RoutedEventArgs e)
>         {
>             // 1. DoubleAnimation：数值型属性（宽度）
>             var widthAnim = new DoubleAnimation(320, new Duration(System.TimeSpan.FromSeconds(1)));
>             Bar.BeginAnimation(FrameworkElement.WidthProperty, widthAnim);
>
>             // 2. ColorAnimation：颜色型属性（背景）
>             var colorAnim = new ColorAnimation(
>                 Color.FromRgb(0x58, 0xA6, 0xFF),
>                 Color.FromRgb(0xDA, 0x36, 0x33),
>                 new Duration(System.TimeSpan.FromSeconds(1)));
>             ColorBox.Background = new SolidColorBrush();
>             ColorBox.Background.BeginAnimation(SolidColorBrush.ColorProperty, colorAnim);
>
>             // 3. ThicknessAnimation：边距型属性（Padding）
>             var padAnim = new ThicknessAnimation(
>                 new Thickness(8, 20), new Thickness(40, 40),
>                 new Duration(System.TimeSpan.FromSeconds(1)));
>             PadBtn.BeginAnimation(FrameworkElement.MarginProperty, padAnim);
>         }
>     }
> }
> ```
> 

> [!scene] 适用场景
> ✅ 进度条/宽度增长动画：DoubleAnimation 让进度平滑推进
> ✅ 状态颜色变化：ColorAnimation 让设备状态灯正常绿→报警红过渡
> ✅ 边距/内边距呼吸：ThicknessAnimation 做按钮"呼大呼小"的强调效果
> ✅ 控件透明度：DoubleAnimation 淡入淡出
> ❌ 多段变速动作序列：用关键帧动画
> ❌ 3D 旋转动画：用 Rotation3DAnimation 而非基础动画类

> [!pitfall] 常见踩坑
> 坑 1：**颜色动画没效果** → 现象：`BeginAnimation(Background, anim)` 写了但颜色不变 → 原因：Background 是 Brush 类型，不能直接动画；要动画的是 `SolidColorBrush.ColorProperty` → 解决：先 `Background = new SolidColorBrush()`，再动画 `SolidColorBrush.ColorProperty`
> 
> 坑 2：**动画类型与属性不匹配** → 现象：运行时报 InvalidOperationException → 原因：DoubleAnimation 赋给了非 double 属性（如 Background） → 解决：对照类型表选动画类，颜色用 ColorAnimation、厚度用 ThicknessAnimation
>
> 坑 3：**布局属性动画卡顿/抖动** → 现象：Width/Margin 动画时界面明显抖动、CPU 高 → 原因：布局属性动画每帧触发 Measure/Arrange 重排 → 解决：动画 RenderTransform/Opacity 等渲染阶段属性

> [!best] 最佳实践
> - 把"属性类型 → 动画类"对照表写在注释里，团队统一选型
> - 颜色动画用于状态变化：正常绿、报警红，配 AutoReverse 做闪烁
> - Thickness 动画只做小范围呼吸效果，避免大范围布局重排
> - 时长用统一常量（如 300ms），多动画节奏一致
> - 动画结束要保留终值就设 FillBehavior=HoldEnd，否则默认回原值

> **Lv.2 动手改造**：新增第四个动画：DoubleAnimation 让控件 Opacity 0.3→1 淡入
