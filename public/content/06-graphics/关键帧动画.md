# 关键帧动画

> [!plain] 白话理解
> 普通动画只走"起点→终点"一条直线，关键帧动画能设置"中途站"：把机械臂抓取拆成"到位→抬起→放下"，每个阶段是一个关键帧（时间点 + 目标值），动画沿多段路径走。类比：只给起点终点会瞎走，有了途经点才知道按工位顺序走。工控里机械臂、物料转运这类"到点—停留—再走"的动作序列，正是关键帧动画的用武之地。

> [!def] 官方定义
> `DoubleAnimationUsingKeyFrames` 等 KeyFrames 动画类型通过 `KeyFrames` 集合定义多个"时间点 + 目标值"（`KeyTime` + 关键帧类）。关键帧派生类决定段间插值方式：`LinearDoubleKeyFrame`（匀速）、`SplineDoubleKeyFrame`（KeySpline 贝塞尔曲线变速）、`EasingDoubleKeyFrame`（缓动函数变速）。`KeyTime` 可指定为绝对时间或总时长的百分比；动画总时长由 `Duration` 决定。
>
> 官方文档：https://learn.microsoft.com/zh-cn/dotnet/api/system.windows.media.animation.doubleanimationusingkeyframes

> [!origin] 由来背景
> 属性动画"从 A 到 B"无法表达"中途停顿、多段变速"的动作序列，关键帧动画把 Flash 的"关键帧"思想引入属性动画：若干"时间点 + 值"组合成一条多段路径。机械臂、物料转运这类"到位—停留—再走"的工控动作天然适合关键帧表达；Spline 关键帧还能用贝塞尔曲线模拟接近目标时减速的真实机械特性，是动画系统能力的自然扩展。

> [!essentials] 核心要点
> - **关键帧 = 时间点 + 值**：每个 `KeyFrames` 条目由 `KeyTime`（何时）和 `Value`（多少）组成
> - **三种插值帧**：`LinearDoubleKeyFrame` 匀速、`SplineDoubleKeyFrame` 贝塞尔变速、`EasingDoubleKeyFrame` 缓动变速
> - **动作序列**：同一条时间线多个关键帧拼出"到位→停留→返回"多段动作
> - **时长控制**：`Duration` 定总长，`KeyTime` 按时长或百分比分布各段
> - **与缓动函数的区别**：关键帧管"走哪些点"，缓动管"点之间怎么变速"，二者可组合

> [!example] 完整示例
> **机械臂抓取演示：用 DoubleAnimationUsingKeyFrames 定义多段关键帧（Spline/Linear/Easing 各型），实现取件-抬起-移动-放下的多段动作序列：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         Title="机械臂 - 关键帧动画" Height="440" Width="500"
>         WindowStartupLocation="CenterScreen" Background="#0D1117">
>     <Grid Margin="15">
>         <Grid.RowDefinitions>
>             <RowDefinition Height="Auto"/>
>             <RowDefinition Height="*"/>
>             <RowDefinition Height="Auto"/>
>         </Grid.RowDefinitions>
>         <TextBlock Text="机械臂抓取动作（关键帧）" Foreground="#58A6FF" FontSize="16" FontWeight="Bold"/>
>         <!-- 关键帧动画作用于水平位移 -->
>         <Canvas Grid.Row="1" Background="#161B22" Margin="0,10,0,0" ClipToBounds="True">
>             <!-- 目标点 -->
>             <Ellipse Width="20" Height="20" Canvas.Left="380" Canvas.Top="60" Fill="#DA3633"/>
>             <!-- 机械臂抓爪 -->
>             <Rectangle x:Name="Gripper" Width="34" Height="34" Fill="#58A6FF" RadiusX="6" RadiusY="6"
>                        Canvas.Left="30" Canvas.Top="140">
>                 <Rectangle.RenderTransform>
>                     <TranslateTransform x:Name="GripperMove" X="0" Y="0"/>
>                 </Rectangle.RenderTransform>
>             </Rectangle>
>         </Canvas>
>         <Button Grid.Row="2" Content="执行抓取" Click="OnPick" Margin="0,12,0,0"
>                 Padding="8" Background="#21262D" Foreground="White" HorizontalAlignment="Left"/>
>     </Grid>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System.Windows;
> using System.Windows.Media.Animation;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         public MainWindow()
>         {
>             InitializeComponent();
>         }
>
>         private void OnPick(object sender, RoutedEventArgs e)
>         {
>             // 多段关键帧：先平移到位，再抬起（Y 负向），形成抓取序列
>             var timeline = new DoubleAnimationUsingKeyFrames
>             {
>                 Duration = new Duration(System.TimeSpan.FromSeconds(2.4))
>             };
>             // Spline 关键帧：先快后慢（接近目标减速）
>             timeline.KeyFrames.Add(new SplineDoubleKeyFrame(0, KeyTime.FromTimeSpan(System.TimeSpan.Zero)));
>             timeline.KeyFrames.Add(new SplineDoubleKeyFrame(350, KeyTime.FromTimeSpan(System.TimeSpan.FromSeconds(1.2))));
>             timeline.KeyFrames.Add(new SplineDoubleKeyFrame(350, KeyTime.FromTimeSpan(System.TimeSpan.FromSeconds(2.0))));
>             // Linear 关键帧：匀速回到起点
>             timeline.KeyFrames.Add(new LinearDoubleKeyFrame(0, KeyTime.FromTimeSpan(System.TimeSpan.FromSeconds(2.4))));
>             GripperMove.BeginAnimation(System.Windows.Media.TranslateTransform.XProperty, timeline);
>         }
>     }
> }
> ```
> 

> [!scene] 适用场景
> ✅ 机械臂/物料转运动作序列：取料→到位→停留→返回，一段动画演完
> ✅ 多段位移路径：物料在输送线上按"直线—转角—直线"移动
> ✅ 渐进式进度展示：进度分阶段推进（如自检 3 步）
> ✅ 向导步骤动画：多步骤流程每步独立动效
> ❌ 简单单段动画：起点到终点一条直线，用基础动画类型 更简洁
> ❌ 需要物理交互反馈：碰撞、惯性等交给物理引擎/算法

> [!pitfall] 常见踩坑
> 坑 1：**关键帧之间"跳变"** → 现象：动画在某两个关键帧间瞬间跳位 → 原因：首帧 KeyTime 没从 0 开始，或段间关键帧类型不匹配 → 解决：首帧 KeyTime=0 设初始值，段间用同一派生关键帧类型
> 
> 坑 2：**动画整体时长不对** → 现象：动画比预期快很多或慢很多 → 原因：Duration 总长与各 KeyTime 分布不协调 → 解决：先定 Duration 总长，KeyTime 按比例/时间精确分配
>
> 坑 3：**Spline 关键帧"过冲"抖动** → 现象：机械臂接近目标时晃一下才停 → 原因：KeySpline 控制点设置导致速度过冲 → 解决：改用 EasingDoubleKeyFrame（缓动函数 控制节奏）或调整 KeySpline 控制点

> [!best] 最佳实践
> - 按真实机械节拍设关键帧：取料(0s)→到位(1.2s)→停留(2.0s)→返回(2.4s)，先写动作表再编码
> - 段间平滑用 Spline/Easing 关键帧；"停留"阶段用连续相同值的两个关键帧实现
> - 关键帧的时间参数集中成常量，便于调试时微调节拍
> - 位移动画作用于 TranslateTransform（translatetransform-平移），避免布局重排
> - 与 storyboard-故事板 组合：多个动作序列并行推进（手臂 + 抓手同时动）

> [!practice] 上手练习
> **Lv.1 运行体验**：运行示例，观察机械臂"到位—停留—返回"的三段动作
> **Lv.2 动手改造**：调整关键帧的 KeyTime 与位移量，感受动作节拍变化
> **Lv.3 综合实战**：给机械臂加 Y 方向关键帧，实现"取件→抬起→放下"完整抓取动作
> **Lv.4 挑战进阶**：把 Spline 关键帧替换为 EasingDoubleKeyFrame，对比两种"接近目标减速"的手感差异
