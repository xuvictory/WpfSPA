# 仪表盘控件

> [!plain] 白话理解
> 仪表盘就是**汽车仪表盘搬到工控屏幕上**：一个圆盘、一圈刻度、一根指针，指针扫到哪，操作员扫一眼就知道"当前值在哪、离危险区多远"。温度表指针快顶到红色区了，比读"87.3℃"的数字更快触发直觉反应——**位置信息比数字更直观**。
>
> 它的原理一点都不神秘：**刻度是一圈 `Ellipse` 画出来的，指针是一个旋转的 `Rectangle`，把"数值"按比例映射成"角度"**——0 值指向 -120°，满量程指向 +120°，中间线性插值。值变了，指针转；转动靠 WPF 的 `RotateTransform`，一行代码的事。
>
> 一句话：**仪表盘 = 圆盘刻度 + 一根会旋转的指针，把"数值大小"翻译成"指针位置"**，特别适合压力、温度、液位、电流这类"需要快速判断是否越界"的模拟量。

> [!def] 官方定义
> - **仪表盘控件（Gauge）**：一种以"圆形刻度 + 指针"形式显示**模拟量数值相对于量程位置**的指示型控件。**WPF 没有官方内置 Gauge 控件**，业界实现方式为：用 `System.Windows.Shapes.Ellipse` 画表盘 + `System.Windows.Controls.Canvas` 布局 + `System.Windows.Media.RotateTransform` 旋转指针。
> - 核心概念：**指针旋转** `RenderTransformOrigin`（旋转中心相对元素自身的位置，示例 `0.5,0.9` 即以指针底部 90% 处为轴）配合 `RotateTransform.Angle`；**值→角度映射**：`angle = minAngle + (value - minValue) / (maxValue - minValue) * (maxAngle - minAngle)`。
> - 量程与分区：量程即 `[minValue, maxValue]`，常按比例分**绿（正常）/黄（注意）/红（危险）**三个视觉区域。
> - 📖 官方文档：[RotateTransform 类](https://learn.microsoft.com/zh-cn/dotnet/api/system.windows.media.rotatetransform)、[Canvas 类](https://learn.microsoft.com/zh-cn/dotnet/api/system.windows.controls.canvas)

> [!origin] 由来背景
> 仪表盘的形态直接继承自**机械式指针仪表**——压力表、电流表、温度计从工业革命起就用"指针 + 刻度盘"呈现读数，因为人脑对"指针角度"的判断速度远快于"读出数字"。工控界面早期（CRT 组态软件，如 1990 年代的 InTouch、组态王）就把指针仪表搬上屏幕，用 GDI 位图/线条模拟指针转动；WPF（2006）的矢量图形（`Ellipse`、`RotateTransform`）让仪表盘实现从"贴图 + 数学计算"简化为"几行 XAML"。
> 如今仪表盘仍是控制室大屏、单点模拟量监控的常见表达——它的价值不在"好看"，而在**让操作员用最少的认知成本判断"现在安不安全"**，这也是它至今没有被数字完全取代的原因。

> [!essentials] 核心要点
> - **指针旋转核心是 `RenderTransformOrigin`**：不设它就绕左上角转，设 `0.5,0.9` 才绕指针底部（接近圆心）转——90% 的上位机仪表盘 bug 出在这
> - **值→角度映射必须归一化**：`value / 100.0 * 240 - 120` 这类线性映射，别把原始值直接当角度（`RawText` 与指针角度两套体系别混）
> - **表盘刻度要有语义分区**：0~70% 绿、70~90% 黄、90~100% 红，指针进红区 = 报警（颜色与 `状态指示灯`/`报警系统` 呼应）
> - **指针根部要配轴心圆点**：一个 `Ellipse` 盖在指针旋转中心，视觉上指针"插在轴上"才不飘
> - **数字显示与指针并存**：仪表盘适合"看趋势"，精确读数还是靠 `TextBlock` 数字，两者配合（示例 `ValueText`）
> - **封装成可复用控件**：真正的工程里把"表盘+指针+值"封装成 `GaugeControl`（依赖属性 `Value/Min/Max`），一处实现处处用

> [!example] 完整示例
> **仪表盘演示：XAML 自绘圆形仪表盘，指针随 Slider 输入旋转，实时显示工程值：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         Title="仪表盘控件" Height="420" Width="420"
>         WindowStartupLocation="CenterScreen" Background="#0D1117">
>     <Grid Background="#161B22" Margin="10">
>         <Grid.RowDefinitions>
>             <RowDefinition Height="*"/>
>             <RowDefinition Height="Auto"/>
>             <RowDefinition Height="Auto"/>
>         </Grid.RowDefinitions>
>
>         <!-- 仪表盘：Canvas 上叠加刻度底盘与指针 -->
>         <Canvas Grid.Row="0" Width="260" Height="260" HorizontalAlignment="Center">
>             <!-- 表盘底 -->
>             <Ellipse Canvas.Left="20" Canvas.Top="20" Width="220" Height="220"
>                      Stroke="#21262D" StrokeThickness="10"/>
>             <!-- 表盘内衬 -->
>             <Ellipse Canvas.Left="32" Canvas.Top="32" Width="196" Height="196"
>                      Fill="#0D1117"/>
>             <!-- 指针：以底部中心为轴旋转 -->
>             <Rectangle x:Name="Needle" Canvas.Left="127" Canvas.Top="36" Width="6" Height="92"
>                        Fill="#58A6FF" RadiusX="3" RadiusY="3"
>                        RenderTransformOrigin="0.5,0.9">
>                 <Rectangle.RenderTransform>
>                     <RotateTransform x:Name="NeedleRotate" Angle="-120"/>
>                 </Rectangle.RenderTransform>
>             </Rectangle>
>             <!-- 轴心 -->
>             <Ellipse Canvas.Left="122" Canvas.Top="121" Width="16" Height="16" Fill="#58A6FF"/>
>             <!-- 数值显示 -->
>             <TextBlock x:Name="ValueText" Canvas.Left="80" Canvas.Top="160" Width="100"
>                        Text="50.0" FontSize="28" Foreground="White" TextAlignment="Center"/>
>             <TextBlock Canvas.Left="95" Canvas.Top="196" Text="℃" Foreground="#8B949E"/>
>         </Canvas>
>
>         <!-- 模拟量输入 -->
>         <Slider x:Name="ValueSlider" Grid.Row="1" Minimum="0" Maximum="100" Value="50"
>                 Margin="20,0" ValueChanged="OnValueChanged"/>
>         <TextBlock x:Name="RawText" Grid.Row="2" Margin="5" Foreground="#8B949E"
>                    Text="模拟量：50.0 (0~100)"/>
>     </Grid>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System;
> using System.Windows;
> using System.Windows.Controls;
> using System.Windows.Media;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         // 仪表盘跨度：-120°(0值) 到 +120°(满量程)，共 240°
>         private const double MinAngle = -120;
>         private const double MaxAngle = 120;
>
>         public MainWindow() => InitializeComponent();
>
>         private void OnValueChanged(object sender, RoutedPropertyChangedEventArgs<double> e)
>         {
>             double value = ValueSlider.Value;
>             // 把 0~100 映射为 -120°~+120°
>             double angle = MinAngle + value / 100.0 * (MaxAngle - MinAngle);
>             NeedleRotate.Angle = angle;
>             ValueText.Text = value.ToString("F1");
>             RawText.Text = $"模拟量：{value:F1} (0~100)";
>         }
>     }
> }
> ```

> [!scene] 适用场景
> ✅ **模拟量单点监控**：温度、压力、液位、电流、转速的"当前值 + 安全区间"展示
> ✅ **控制室大屏/操作员画面**：操作员需"扫一眼"判断是否越界的场合，仪表盘比数字高效
> ✅ **设备健康状态总览**：每台设备一个仪表盘排成矩阵，异常仪表指针进红区一眼可见
> ❌ **需要精确读数**（如工艺参数报表录入）：数字控件（`TextBlock`/`DataGrid`）更合适，仪表盘只给"大概位置"
> ❌ **海量点位列表**：几十上百个点位用表格+状态色（`状态指示灯`）更清晰，一排仪表盘反而拥挤

> [!pitfall] 常见踩坑
> 坑 1：**`RenderTransformOrigin` 设错/漏设，指针乱转** → 现象：指针绕左上角转、偏移中心旋转 → 原因：旋转中心默认是元素左上角（0,0）→ 解决：`RenderTransformOrigin="0.5,0.9"`（以指针自身中心横轴、90% 纵轴为旋转轴心），并注意它是相对值（0~1），不是像素
>
> 坑 2：**把原始值直接当角度** → 现象：Slider 拖到 50，指针转 50°，完全不对 → 原因：没做"量程→角度"归一化映射 → 解决：统一 `angle = minAngle + (value - min) / (max - min) * (maxAngle - minAngle)`，量程两端对齐
>
> 坑 3：**Canvas 固定像素尺寸，窗口缩放就错位** → 现象：拉大窗口指针和刻度脱节 → 原因：`Canvas` 布局不参与缩放 → 解决：把仪表盘封装成 `UserControl`，用 `Viewbox` 包裹实现等比缩放，或接受固定尺寸
>
> 坑 4：**指针角度越界（超出量程）** → 现象：指针转到 240° 冲出表盘 → 原因：输入值超出量程没钳制 → 解决：映射前 `Math.Clamp(value, min, max)`；越界值本应触发 `报警系统`，而不是让指针乱飞

> [!best] 最佳实践
> - **封装 `GaugeControl`**：把表盘/指针/数字封装成 UserControl，暴露 `Value`、`MinValue`、`MaxValue` 依赖属性，一处实现、全项目复用（配合第 5 章自定义控件）
> - **角度映射放后台统一算**：前端只做 `Render`，`Value→Angle` 的换算收敛到一个方法（如示例），方便加 `Math.Clamp` 与非线性刻度
> - **颜色分区做"危险值变色"**：值 > 90% 量程时指针/数字变红、> 70% 变黄，与 `状态指示灯` 的颜色语义统一（红=危险、黄=注意、绿=正常）
> - **数值来自工程值而非原始值**：仪表盘显示 `数据转换与工程值计算` 的换算结果，量程也取自点位配置，别手写 0~100
> - **指针动画可加 `DoubleAnimation`**：值突变时指针"甩过去"更符合仪表盘质感，但高频更新时关掉动画保性能

> [!practice] 上手练习
> **Lv.1 运行改参数**：运行示例拖动 Slider，观察指针在 -120°~+120° 间摆动；把 `MaxAngle` 改成 180，观察指针满量程位置变化
> **Lv.2 加属性**：加"危险区变色"：值 > 90 时 `Needle.Fill` 变红、> 70 时变黄、其余保持蓝——把仪表盘与报警语义接起来
> **Lv.3 改造**：给表盘加"刻度线"：用 9 根 `Rectangle`（每 30° 一根，围绕圆心旋转）做 0~100 分度，再加大刻度对应的数字标注
> **Lv.4 挑战**：封装 `GaugeControl` 用户控件（依赖属性 `Value`/`MinValue`/`MaxValue`/`Unit`），在主窗口放 3 个仪表盘（温度/压力/液位），分别接 `数据转换与工程值计算` 的三个点位——可复用仪表盘控件的第一版
