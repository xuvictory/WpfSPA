# 一维数组与多维数组

> [!plain] 白话理解
> 数组就是"一排盒子"，编号从 0 开始。`int[5]` 就是 5 个 int 盒子排成一排，盒号 0、1、2、3、4。你不可能去访问"第5号盒子"——它会炸，因为这个编号叫**索引**，范围是 0 ~ 长度-1。二维数组就是"棋盘格"——`int[3,4]` 是 3 行 4 列的表格。在上位机中，数组几乎是一切数据结构的根基：传感器采样缓冲区、Modbus 寄存器映射表、图像像素矩阵——都是数组。

> [!def] 官方定义
> 数组（Array）是包含相同类型元素的固定长度连续内存块，继承自 `System.Array`。C# 支持：
> - **一维数组** `T[]`：最常用，如 `int[] numbers = new int[10];`
> - **多维数组** `T[,]`：如 `double[,] matrix = new double[3, 4];`（3行4列）
> - **交错数组** `T[][]`：数组的数组，如 `int[][] jagged = new int[3][];`（每行长度可不同）
> - 长度固定：创建后 `Length` 不可变（要扩容用 `List<T>`）
> - 索引从 0 开始，使用 `[index]` 访问

> [!origin] 由来背景
> 数组是计算机科学中最古老的数据结构——甚至可以说是唯一的"原生"数据结构。在 C# 中，数组在 CLR 层面有特殊待遇：JIT 编译器能对数组访问做边界检查消除（Bound Check Elimination），使得性能极度接近裸指针。SO 上有句话："需要最高性能就用数组，需要灵活性就用 List"。上位机中，高速数据采集用 `byte[]` 缓冲区、固定点数运算用 `double[]`——数组是性能敏感的底层代码中不可替代的存在。

> [!essentials] 核心要点
> - 声明：`int[] arr = new int[10];`（10 个元素，索引 0~9）
> - 初始化器：`int[] arr = { 1, 2, 3 };` 或 `int[] arr = [1, 2, 3];`（C# 12 集合表达式）
> - 获取长度：`arr.Length`（一维）、`matrix.GetLength(0)`（第0维长度）
> - 数组是引用类型：赋值为引用拷贝，两个变量指向同一块内存
> - 多维数组：`int[,]` 是 CLR 原生支持的矩形数组，内存连续
> - 交错数组：`int[][]` 是"数组的数组"，每行独立分配，内存不连续
> - `Array.Resize(ref arr, newSize)` 是新建数组+拷贝，不是原地扩容

> [!example] 完整示例
> ```csharp
> // ========== 一维数组 ==========
> int[] sensorValues = new int[5];  // 5个元素的数组
> sensorValues[0] = 1023;           // ADC 原始值
> sensorValues[1] = 512;
> sensorValues[2] = 768;
> sensorValues[3] = 256;
> sensorValues[4] = 0;

> // 遍历
> for (int i = 0; i < sensorValues.Length; i++)
>     Console.WriteLine($"传感器[{i}] = {sensorValues[i]}");

> // ========== 二维数组（上位机：传感器矩阵）==========
> double[,] temperatureGrid = new double[3, 4]  // 3行4列
> {
>     { 85.5, 78.2, 92.1, 65.0 },   // 区域1
>     { 72.3, 68.9, 88.8, 70.1 },   // 区域2
>     { 60.0, 55.5, 62.4, 58.8 }    // 区域3
> };

> Console.WriteLine($"\n温度网格 ({temperatureGrid.GetLength(0)}×{temperatureGrid.GetLength(1)}):");
> for (int row = 0; row < temperatureGrid.GetLength(0); row++)
> {
>     Console.Write($"  区域{row + 1}: ");
>     for (int col = 0; col < temperatureGrid.GetLength(1); col++)
>     {
>         double t = temperatureGrid[row, col];
>         string marker = t > 80 ? "🔴" : t > 70 ? "🟡" : "🟢";
>         Console.Write($"{marker}{t,5:F1}℃ ");
>     }
>     Console.WriteLine();
> }

> // ========== 交错数组：不规则设备拓扑 ==========
> // 生产线：工位1有3个传感器，工位2有5个，工位3有2个
> string[][] stationSensors = new string[3][];
> stationSensors[0] = new[] { "温度1", "压力1", "流量1" };
> stationSensors[1] = new[] { "温度2", "压力2", "流量2", "振动2", "噪声2" };
> stationSensors[2] = new[] { "温度3", "压力3" };

> Console.WriteLine($"\n生产线传感器拓扑:");
> for (int station = 0; station < stationSensors.Length; station++)
> {
>     Console.Write($"  工位{station + 1}({stationSensors[station].Length}个): ");
>     Console.WriteLine(string.Join(", ", stationSensors[station]));
> }

> // ========== 上位机实战：环形缓冲区（用 Modbus 寄存器数组模拟）==========
> ushort[] registerBuffer = new ushort[10];
> int writeIndex = 0;

> // 连续写入15次，自动覆盖
> for (int i = 1; i <= 15; i++)
> {
>     registerBuffer[writeIndex % registerBuffer.Length] = (ushort)(i * 100);
>     writeIndex++;
> }

> Console.WriteLine($"\n环形缓冲区内容: [{string.Join(", ", registerBuffer)}]");

> // ========== 数组复制与切片 ==========
> int[] source = { 1, 2, 3, 4, 5, 6, 7, 8 };
> int[] subset = new int[3];
> Array.Copy(source, 2, subset, 0, 3);  // 从索引2开始复制3个元素
> Console.WriteLine($"\n切片 [2..5): [{string.Join(", ", subset)}]");  // 3,4,5
> ```

> [!scene] 适用场景
> ✅ 固定长度数据：Modbus 寄存器映射（地址 0~999）
> ✅ 高速数值计算：FFT 频谱分析、数字滤波器
> ✅ 多维数据：图像像素、传感器矩阵、标定表
> ✅ 字节缓冲区：串口/网络的 `byte[]`
> ❌ 元素数量动态变化 → `List<T>`
> ❌ 键值对查询 → `Dictionary<K,V>`

> [!pitfall] 常见踩坑
> 坑 1：**索引越界** → `int[] arr = new int[5]; arr[5] = 1;` ❌ 最大索引是 4！`IndexOutOfRangeException` 是上位机代码中最常见的运行时异常之一。
>
> 坑 2：**数组是引用类型，`=` 复制的是引用** → 
> ```csharp
> int[] a = { 1, 2, 3 };
> int[] b = a;
> b[0] = 999;
> Console.WriteLine(a[0]); // 999！a被改了
> ```
> 要真复制用 `Array.Copy` 或 `.ToArray()` 或 `.Clone()`。
>
> 坑 3：**多维数组和交错数组混用** → `int[,]` 和 `int[][]` 在内存布局和访问方式上都不同。多维数组用 `array[row, col]`，交错用 `array[row][col]`。性能上 `int[,]` 在 .NET 中的访问略慢于 `int[][]`（需要两次乘法计算偏移）。

> [!best] 最佳实践
> - 固定大小数据用数组，动态大小用 `List<T>`
> - 数组初始化用集合表达式：`int[] arr = [1, 2, 3];`（C# 12）
> - 复制数组用 `Array.Copy`（最快）、`Buffer.BlockCopy`（值类型数组更快）
> - 上位机的 `byte[]` 缓冲区预分配到最大可能长度，避免反复创建
> - 大数组（>85KB）会被分配到大对象堆（LOH），注意控制生命周期
> - 用 `ArrayPool<T>` 租用临时大数组，避免 GC 压力

> [!practice] 上手练习
> **Lv.1 照猫画虎**：创建长度为 10 的 `double` 数组，初始化为 20.0~29.0 的十个值，打印并计算平均值
> **Lv.2 小试牛刀**：创建一个 4×4 的 `double[,]` 矩阵（对角线为 1.0，其他为 0），用双层 for 循环打印
> **Lv.3 融会贯通**：实现一个滑动平均滤波器：输入 `double[]` 原始数据和窗口大小，用新数组存储滤波后结果（每个点=窗口内平均值），处理边界（两端用最近的有效值填充）
