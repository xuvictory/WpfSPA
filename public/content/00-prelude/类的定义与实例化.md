# 类的定义与实例化

> [!plain] 白话理解
> 类就像一张**建筑蓝图**，对象就是用这张蓝图**盖出来的房子**。蓝图只有一份，但房子可以盖很多栋，每栋房子的内部配置可以不同。类定义了你想要的数据结构和行为，实例化（new）就是按照蓝图造一个具体的东西出来。

> [!def] 官方定义
> 类（Class）是 C# 中最基本的用户自定义类型，它是一种将状态（字段）和行为（方法）封装在一起的引用类型。使用 `new` 关键字在托管堆上创建类的实例（对象），变量存储的是对该实例的引用（地址），而非数据本身。

> [!origin] 由来背景
> 早期的编程语言（如 C）使用结构体（struct）存放数据，用独立的函数操作数据——数据和行为是分离的。随着软件越来越复杂，这种"分离式"写法导致数据和操作它的代码散落在各处，难以维护。面向对象编程（OOP）的核心创新就是把数据和行为封装在一起，这就是"类"的由来。

> [!essentials] 核心要点
> - 定义：`class MyClass { }`
> - 实例化：`MyClass obj = new MyClass();`
> - 类是**引用类型**，赋值只是复制引用（地址），不复制数据本身
> - `this` 关键字指向当前实例本身
> - 类可以包含：字段、属性、方法、构造函数、事件、内部类
> - 不写访问修饰符时，成员默认为 `private`

> [!example] 完整示例
> ```csharp
> // 定义类（蓝图）
> public class SensorDevice
> {
>     // 字段（私有数据）
>     private string _deviceId;
>     private double _lastValue;
>     
>     // 属性（对外暴露的访问接口）
>     public string DeviceId 
>     { 
>         get => _deviceId; 
>         set => _deviceId = value; 
>     }
>     
>     // 自动属性（快速版）
>     public double LastValue { get; set; }
>     public bool IsOnline { get; private set; }
>     
>     // 构造函数（创建时执行的初始化逻辑）
>     public SensorDevice(string deviceId)
>     {
>         _deviceId = deviceId;
>         IsOnline = false;
>         Console.WriteLine($"传感器 {deviceId} 已创建");
>     }
>     
>     // 方法（行为）
>     public void UpdateValue(double newValue)
>     {
>         _lastValue = newValue;
>         LastValue = newValue;
>         IsOnline = true;
>     }
> }
> 
> // 实例化（盖房子）
> SensorDevice sensor1 = new SensorDevice("TEMP-001");
> SensorDevice sensor2 = new SensorDevice("TEMP-002");
> 
> sensor1.UpdateValue(36.5);
> Console.WriteLine(sensor1.LastValue); // 36.5
> Console.WriteLine(sensor2.LastValue); // 0（独立的对象，互不影响）
> ```

> [!scene] 适用场景
> ✅ 上位机中：设备类（PLC、传感器、仪表）、配置类、数据传输对象、ViewModel 类
> ✅ 需要封装数据+行为的任何地方
> ❌ 纯数据容器（无行为），只存不操作 → 用 `struct` 或 `record` 可能更轻量

> [!pitfall] 常见踩坑
> 坑 1：**引用类型赋值陷阱** → `SensorDevice s2 = s1;` 后 s2 和 s1 指向**同一个对象**，改了 s2 的数据 s1 也会变！
> 
> 坑 2：**忘写构造函数** → 类有默认无参构造，但一写了带参构造，默认无参就消失了——若还需无参构造，要手动写
> 
> 坑 3：**字段应该 private** → 新手常把字段写成 public，破坏了封装性，应该通过属性暴露

> [!best] 最佳实践
> - 字段一律用 `_camelCase` 命名（private），属性用 `PascalCase`（public）
> - 善用自动属性 `{ get; set; }` 减少样板代码
> - 构造函数职责单一：只做初始化，不做复杂业务逻辑
> - 上位机中，建议用 `record` 类型做纯数据传递对象（DTO）

> [!practice] 上手练习
> **Lv.1 照猫画乌**：定义一个 `Motor` 类，包含 Speed、IsRunning 两个属性，一个 Start() 方法和 Stop() 方法，创建实例并调用
> **Lv.2 小试牛刀**：给 Motor 类添加构造函数，创建时自动设置最大速度 MaxSpeed，运行时判断速度是否超限
> **Lv.3 融会贯通**：创建多个 Motor 实例存入 List，用 foreach 遍历启动所有电机，模拟产线启动流程
