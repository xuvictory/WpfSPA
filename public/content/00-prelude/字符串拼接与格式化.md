# 字符串拼接与格式化

> [!plain] 白话理解
> 字符串拼接就是你用胶水把一段段文字粘在一起。最简单的胶水是 `+`：`"设备" + name + "温度" + temp + "℃"`，但如果要粘的东西多了，`+` 就像用透明胶粘家具——晃晃悠悠看着难受。格式化方法 `string.Format` 像是先画好蓝图再填数字，比 `+` 好,但还不够。字符串插值 `$"设备{name}温度{temp}℃"` 才是现代 C# 的"工业胶水"——直观、安全、IDE 还能帮你高亮。

> [!def] 官方定义
> 字符串拼接是将多个字符串或多个对象合并为一个新字符串的操作。C# 提供了三种主要方式：
> - `+` 运算符：最基础的拼接方式，每次拼接都创建新 `string` 对象
> - `string.Format()` / `string.Concat()` / `string.Join()`：结构化格式化
> - `$""` 字符串插值（C# 6.0）：在字符串中直接嵌入表达式
> - `string` 是不可变类型，任何拼接都生成新对象，而不是修改原对象

> [!origin] 由来背景
> 早期的 C#（1.0/2.0）只有 `+` 和 `string.Format`。`string.Format` 用 `{0} {1}` 这样的占位符，来自 C 语言的 `printf` 传统但更安全。但它有个讨厌的问题：占位符和参数在物理上分离——你加一个参数，所有 `{N}` 索引都得检查有没有错位。C# 6.0（2015年）的 `$""` 字符串插值彻底解决了这个问题，表达式直接写在字符串里，同时编译器把它翻译成和 `string.Format` 同样的高效代码。在上位机中，构造 Modbus 命令帧、拼接日志消息、生成数据报告——这些都是插值的最强主场。

> [!essentials] 核心要点
> - `+` 拼接：最简单，但循环中使用有性能问题
> - `string.Format("温度:{0:F1}℃", temp)`：传统格式化，占位符必须与参数一一对应
> - `$"温度:{temp:F1}℃"`：插值，变量直接嵌入，编译器翻译为 `string.Format`
> - 格式说明符：`{value:F1}`一位小数、`{value:D5}`五位补零、`{value:P0}`百分比
> - `string.Join(", ", array)`：用分隔符连接数组元素
> - `string.Concat(a, b, c)`：纯拼接，无分隔符

> [!example] 完整示例
> ```csharp
> // ========== 三种拼接方式对比 ==========
> string deviceName = "PLC-001";
> double temperature = 85.5;

> // 方式一：+ 拼接（刚入门时会用，但可读性最差）
> string msg1 = "设备 " + deviceName + " 温度: " + temperature + "℃";
> Console.WriteLine(msg1);

> // 方式二：string.Format（传统方式，占位符与参数分离）
> string msg2 = string.Format("设备 {0} 温度: {1:F1}℃", deviceName, temperature);
> Console.WriteLine(msg2);

> // 方式三：$插值（现代 C# 推荐，最直观）
> string msg3 = $"设备 {deviceName} 温度: {temperature:F1}℃";
> Console.WriteLine(msg3);

> // ========== 格式说明符速查 ==========
> int value = 255;
> double pi = Math.PI;

> Console.WriteLine($"十六进制: 0x{value:X4}");      // 0x00FF
> Console.WriteLine($"补零: {value:D5}");               // 00255
> Console.WriteLine($"货币: {value:C}");                // ¥255.00
> Console.WriteLine($"百分比: {0.855:P1}");              // 85.5%
> Console.WriteLine($"科学计数: {1234567:E2}");          // 1.23E+006
> Console.WriteLine($"π保留4位: {pi:F4}");               // 3.1416

> // ========== 对齐与宽度 ==========
> Console.WriteLine($"右对齐10位: [{value,10}]");   // [       255]
> Console.WriteLine($"左对齐10位: [{value,-10}]");  // [255       ]

> // ========== 上位机实战：生成设备状态报告 ==========
> string[] deviceNames = { "PLC-001", "温度变送器", "压力传感器" };
> double[] temps = { 85.5, 62.0, 23.1 };
> double[] pressures = { 2.1, 1.5, 0.8 };
> bool[] statuses = { true, true, false };

> // 用 string.Format 生成对齐的表格头
> string header = $"{"设备名称",-12} {"温度",8} {"压力",8} {"状态",6}";
> string separator = new string('-', 40);
> Console.WriteLine(separator);
> Console.WriteLine(header);
> Console.WriteLine(separator);

> for (int i = 0; i < deviceNames.Length; i++)
> {
>     string status = statuses[i] ? "●在线" : "○离线";
>     string line = $"{deviceNames[i],-12} {temps[i],6:F1}℃ {pressures[i],6:F2}MPa {status,6}";
>     Console.WriteLine(line);
> }
> Console.WriteLine(separator);

> // ========== string.Join：把数组变成一句话 ==========
> string deviceList = string.Join(", ", deviceNames);
> Console.WriteLine($"\n监控设备: [{deviceList}]");

> // 上位机日志格式：时间+等级+消息
> string timestamp = DateTime.Now.ToString("yyyy-MM-dd HH:mm:ss.fff");
> string logLevel = "WARNING";
> string logMessage = $"通信超时，设备{deviceName}未响应";

> string log = $"[{timestamp}] [{logLevel}] {logMessage}";
> Console.WriteLine($"\n{log}");

> // ========== 复合格式：插值里嵌条件 ==========
> foreach (var t in temps)
> {
>     Console.WriteLine($"温度 {t,5:F1}℃ → {(t > 80 ? "🔴告警" : t > 60 ? "🟡注意" : "🟢正常")}");
> }
> ```

> [!scene] 适用场景
> ✅ `$""` 插值：日常字符串拼接的默认选择（日志、消息、数据展示）
> ✅ `string.Format`：需要动态生成格式模板的场景
> ✅ `string.Join`：数组/列表转逗号分隔字符串
> ✅ `+`：只拼 2~3 个简单字符串时可以接受
> ❌ `+` 在循环中大量拼接 → 性能灾难，用 `StringBuilder`

> [!pitfall] 常见踩坑
> 坑 1： **`$` 插值中放 `{` 和 `}` 需要转义** → `$"{{ {value} }}"` 输出 `{ 255 }`，`{{` 转义为单个 `{`，`}}` 转义为单个 `}`。
>
> 坑 2： **三元表达式在插值中要加括号** → `$"{(condition ? "是" : "否")}"` ✅ 加了括号编译器才认，否则 `$"{condition ? "是" : "否"}"` ❌ 会报错。
>
> 坑 3： **`ToString("D")` vs `string.Format("{0:D}")` 的不一致性** → `5.ToString("D2")` 返回 `"05"`（补零），但 `string.Format("{0:D}", 5)` 返回 `"5"`（没有指明宽度）。插值中 `$"{5:D2}"` 正确，`$"{5:D}"` 不补零。

> [!best] 最佳实践
> - **拼接文本优先使用 `$""` 插值**——它是现代 C# 的事实标准
> - 循环中拼接大量字符串 → 用 `StringBuilder`，不要 `+=`
> - 数组元素合并 → `string.Join` 一行搞定
> - 固定格式的对齐表格 → 用 `$"{value,width}"` 负号左对齐
> - 上位机日志格式保持一致：`$"[{时间}] [{等级}] {消息}"` 

> [!practice] 上手练习
> **Lv.1 照猫画虎**：用自己的名字和年龄，用三种方式（`+`、`Format`、`$""`）分别输出带格式的自我介绍
> **Lv.2 小试牛刀**：模拟5台设备的温湿度数据（数组），用 `string.Format` 输出对齐的表格，包含设备名、温度（1位小数）、湿度（百分比）、状态（在线/离线）
> **Lv.3 融会贯通**：用 `$""` 插值生成一个完整的 Modbus 读取命令帧字符串（`"010300000004"`格式），帧的各字段用变量替换，字节数补齐，打印构造过程
