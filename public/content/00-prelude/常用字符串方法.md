# 常用字符串方法

> [!plain] 白话理解
> 如果你把 `string` 比作一个工具箱，那 `Substring` 是剪刀（剪一段下来）、`Split` 是铡刀（按标记切开）、`Replace` 是修正液（涂抹替换）、`Trim` 是橡皮擦（清理多余空白）、`Contains` 是放大镜（找找看有没有）、`IndexOf` 是尺子（量一量它在哪）。这些方法的上位机使用频率极高——解析串口数据靠 `Split` 和 `Substring`，清洗用户输入靠 `Trim`，协议匹配靠 `Contains` 和 `StartsWith`。

> [!def] 官方定义
> `string` 类型（`System.String`）提供了大量实例方法和静态方法用于字符串操作。所有方法都不会修改原字符串（string 是不可变的），而是返回新的字符串。以下是上位机开发中最常用的方法：
> - **截取/拆分/合并**：`Substring`、`Split`、`Join`、`Concat`
> - **查找/判断**：`Contains`、`StartsWith`、`EndsWith`、`IndexOf`、`LastIndexOf`
> - **修改/替换**：`Replace`、`Remove`、`Insert`
> - **修剪/格式化**：`Trim`、`TrimStart`、`TrimEnd`、`ToUpper`、`ToLower`
> - **判空/判等**：`IsNullOrEmpty`、`IsNullOrWhiteSpace`、`Equals`

> [!origin] 由来背景
> `System.String` 是 .NET 中最老牌、最成熟的类之一。它的不可变性设计（Immutable Pattern）是 .NET 框架的基石思想——虽然每次操作都产生新对象（有 GC 压力），但换取的是线程安全和可预测性。你永远不会担心"别的线程改了你的字符串"。微软在 .NET 2.0 后逐步添加了 `IsNullOrEmpty`（避免 null 检查地狱）、.NET 4.0 添加 `IsNullOrWhiteSpace`（连空白字符一起过滤）、.NET Core 中加入了 `Contains(char, StringComparison)` 等现代化重载。上位机协议解析里 80% 的代码都在调这些方法。

> [!essentials] 核心要点速查表

> | 方法 | 作用 | 示例 |
> |------|------|------|
> | `Substring(start, len)` | 截取子串 | `"Hello".Substring(1,3)` → `"ell"` |
> | `Split(' ')` | 按分隔符拆分 | `"a,b,c".Split(',')` → `["a","b","c"]` |
> | `Replace(old, new)` | 替换文本 | `"1.5".Replace(".",",")` → `"1,5"` |
> | `Trim()` | 去首尾空白 | `" abc ".Trim()` → `"abc"` |
> | `Contains("abc")` | 是否包含 | `"abcde".Contains("cd")` → `true` |
> | `IndexOf("c")` | 首次出现位置 | `"abcabc".IndexOf("a")` → `0` |
> | `LastIndexOf("c")` | 最后出现位置 | `"abcabc".LastIndexOf("a")` → `3` |
> | `StartsWith("a")` | 是否以...开头 | `"abc".StartsWith("ab")` → `true` |
> | `EndsWith(".txt")` | 是否以...结尾 | `"log.txt".EndsWith(".txt")` → `true` |
> | `ToUpper()/ToLower()` | 大小写转换 | `"PLC".ToLower()` → `"plc"` |
> | `IsNullOrEmpty(s)` | 判空 static | `string.IsNullOrEmpty(null)` → `true` |
> | `IsNullOrWhiteSpace(s)` | 判空白 static | `string.IsNullOrWhiteSpace(" ")` → `true` |

> [!example] 完整示例
> ```csharp
> // ========== 上位机实战：解析串口数据 ==========
> string rawData = "TEMP:85.5;HUM:62.3;PRES:2.1"; // 模拟串口返回

> // Split 拆分 → 逐个解析
> string[] parts = rawData.Split(';');
> foreach (string part in parts)
> {
>     if (string.IsNullOrWhiteSpace(part)) continue;  // 跳过空段
    
>     string[] kv = part.Split(':');
>     if (kv.Length != 2) continue;  // 格式不对，跳过
    
>     string key = kv[0].Trim();
>     string valueStr = kv[1].Trim();
    
>     if (double.TryParse(valueStr, out double value))
>     {
>         Console.WriteLine($"{key}: {value}");
>     }
> }

> // ========== Substring + IndexOf：精确截取 ==========
> string protocolFrame = "STX:0103000000044409:ETX"; // 协议帧
> int startIdx = protocolFrame.IndexOf(":") + 1;     // 第一个冒号后
> int endIdx = protocolFrame.LastIndexOf(":");         // 最后一个冒号前
> string payload = protocolFrame.Substring(startIdx, endIdx - startIdx);
> Console.WriteLine($"\n协议载荷: {payload}");

> // 截取固定位置的字段
> string slaveAddr = payload.Substring(0, 2);      // 前2个字符：从站地址
> string funcCode = payload.Substring(2, 2);        // 功能码
> string startReg = payload.Substring(4, 4);        // 起始寄存器
> string count = payload.Substring(8, 4);            // 数量
> Console.WriteLine($"从站:{slaveAddr} 功能:{funcCode} 起始:{startReg} 数量:{count}");

> // ========== Contains + StartsWith：协议识别 ==========
> string[] responses = 
> {
>     "MODBUS:01030200FF",    // Modbus 响应
>     "S7:STATUS=OK",         // Siemens S7 响应
>     "UNKNOWN_MESSAGE",      // 未知协议
>     "MODBUS:01060600A0"     // Modbus 写响应
> };

> Console.WriteLine("\n协议分类：");
> foreach (string resp in responses)
> {
>     if (resp.StartsWith("MODBUS:"))
>         Console.WriteLine($"  Modbus 协议: {resp}");
>     else if (resp.StartsWith("S7:"))
>         Console.WriteLine($"  Siemens S7: {resp}");
>     else
>         Console.WriteLine($"  未知协议: {resp}");
> }

> // ========== Replace + Trim：数据清洗 ==========
> string rawInput = "  1023\r\n";    // 带空格和换行的原始数据
> string clean = rawInput.Trim().Replace("\r", "").Replace("\n", "");
> if (int.TryParse(clean, out int adcValue))
>     Console.WriteLine($"\n清洗后的 ADC 值: {adcValue}");

> // ========== 批量替换：数值格式化 ==========
> string logEntry = "设备[NAME]在[TIME]发出告警：温度[TEMP]℃";
> string formatted = logEntry
>     .Replace("[NAME]", "PLC-001")
>     .Replace("[TIME]", DateTime.Now.ToString("HH:mm:ss"))
>     .Replace("[TEMP]", "85.5");
> Console.WriteLine($"\n{formatted}");

> // ========== 链式调用：清洗并提取 ==========
> string dirtyConfig = "  IP=192.168.1.100; PORT=502;  "; // 配置字符串，多余空格
> string cleanConfig = dirtyConfig.Trim();
> string ipPart = cleanConfig.Substring(
>     cleanConfig.IndexOf("IP=") + 3,
>     cleanConfig.IndexOf(";") - cleanConfig.IndexOf("IP=") - 3);
> Console.WriteLine($"\n提取的IP: [{ipPart}]");
> ```

> [!scene] 适用场景
> ✅ `Split`：解析键值对、CSV数据、协议分隔符数据（上位机最强解析工具）
> ✅ `Substring`+`IndexOf`：解析定长/分隔协议的二进制帧转十六进制字符串
> ✅ `Trim`：清洗用户输入、串口读取的脏数据（各种控制字符）
> ✅ `Contains`/`StartsWith`：协议识别、命令路由
> ✅ `Replace`：标准化分隔符、模板字符串填充
> ✅ `ToUpper`/`ToLower`：大小写不敏感的字符串匹配前预处理

> [!pitfall] 常见踩坑
> 坑 1：**`Substring` 越界** → `"abc".Substring(1, 5)` ❌ `ArgumentOutOfRangeException`。调用前先检查长度：`if (str.Length >= start + length)`
>
> 坑 2：**`Split` 空元素** → `"a,,b".Split(',')` 返回 `["a","","b"]`，中间的 `""` 容易漏掉。用 `Split(',', StringSplitOptions.RemoveEmptyEntries)` 自动去掉空元素。
>
> 坑 3：**`Replace` 不能替换不可见字符** → `"\r\n"` 是一个整体，`Replace("\n", "")` 不能直接去掉换行，要先 `Replace("\r\n", "\n")` 统一成 `\n` 再替换。

> [!best] 最佳实践
> - 输入永远先 `Trim()` 再处理——用户输入和串口数据的规则
> - `Split` 用 `StringSplitOptions.RemoveEmptyEntries` 避免空字符串元素
> - 多次 `Replace` 链式调用代替嵌套
> - 大小写不敏感匹配用 `StringComparison.OrdinalIgnoreCase`：
>   `s.StartsWith("plc", StringComparison.OrdinalIgnoreCase)`
> - 提取子串前先确保 `IndexOf` 返回值不是 `-1`
> - 复杂的协议解析不要裸调 `Substring` 和 `Split`，封装成 Parser 类

> [!practice] 上手练习
> **Lv.1 照猫画虎**：定义 `string data = "  Hello World  ";` 依次调用 `Trim`、`ToUpper`、`Substring(0,5)`、`Replace("O","0")`，打印每一步结果
> **Lv.2 小试牛刀**：模拟解析一条完整的 Modbus 响应 `"01 03 08 00 FF 00 00 00 01 00 02 CRCH CRCL"`，用 `Split` 拆分空格，`Substring` 提取每个字段，过滤掉 CRC，打印解析结果
> **Lv.3 融会贯通**：实现一个 `ProtocolFrameParser` 类，方法 `Parse(string rawFrame)` 输入任意格式的协议帧字符串，用 `Trim`+`Split`+`Substring` 递归解析（支持嵌套分隔符），返回结构化数据
