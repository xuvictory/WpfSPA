# 泛型类

> [!plain] 白话理解
> 泛型类就是一个"类型参数化的模板"。你写了一个 `DataStore<T>`，这个 `T` 就是一个占位符——实际使用时 `T` 可以是 `int`、`string`、`DeviceInfo` 等任何类型。一个 `DataStore<int>` 存整数，`DataStore<string>` 存字符串，编译器自动为每种用法生成对应的强类型代码。泛型消灭了两样东西：装箱拆箱的性能开销、`object` 类型转换的 ClassCastException。`List<T>`、`Dictionary<K,V>` 你天天用，它们都是泛型类。

> [!def] 官方定义
> 泛型类（Generic Class）是有一个或多个**类型参数**（Type Parameter）的类。在实例化时，用具体类型替换参数，编译器生成强类型的类。泛型提供**类型安全**、**代码复用**和**性能优化**（避免装箱拆箱）。

> [!origin] 由来背景
> C# 1.0 只有 `ArrayList`（存 `object`），每次取值都要强制转换，存值类型就装箱。C# 2.0（2005年）引入泛型，彻底改变了 .NET 的编程方式。`List<T>` 替代了 `ArrayList`，`Dictionary<K,V>` 替代了 `Hashtable`——泛型是 C# 历史上最重要的语言进化之一。

> [!essentials] 核心要点
> - `class MyClass<T> { public T Value { get; set; } }`
> - 使用：`var obj = new MyClass<int>();`
> - 可以多个类型参数：`class Pair<T1, T2> { }`
> - 类型参数命名约定：单个字母 `T`，多个用 `TKey`/`TValue`

> [!example] 完整示例
> ```csharp
> // ====== 泛型数据存储区 ======
> public class DataBuffer<T>
> {
>     private readonly T[] _buffer;
>     private int _index;
    
>     public DataBuffer(int size) => _buffer = new T[size];
    
>     public void Add(T item)
>     {
>         if (_index >= _buffer.Length)
>             throw new InvalidOperationException("缓冲区已满");
>         _buffer[_index++] = item;
>     }
    
>     public T this[int index] => _buffer[index];
>     public int Count => _index;
> }

> // 同一个类，多种用法
> var intBuffer = new DataBuffer<int>(5);
> intBuffer.Add(1023);

> var strBuffer = new DataBuffer<string>(5);
> strBuffer.Add("PLC-001");

> // ====== 上位机实战：泛型寄存器 ======
> public class Register<T>
> {
>     public ushort Address { get; }
>     public T Value { get; set; }
>     public DateTime UpdatedAt { get; private set; }
    
>     public Register(ushort address, T initialValue)
>     {
>         Address = address;
>         Value = initialValue;
>     }
    
>     public void Update(T newValue)
>     {
>         Value = newValue;
>         UpdatedAt = DateTime.Now;
>     }
> }

> var tempReg = new Register<double>(40001, 25.0);
> tempReg.Update(85.5);
> Console.WriteLine($"地址{tempReg.Address}: {tempReg.Value}℃  更新时间{tempReg.UpdatedAt:HH:mm:ss}");
> ```

> [!scene] 适用场景
> ✅ 需要代码复用但类型不同
> ✅ 数据结构（仓库类/缓存/缓冲区）
> ❌ 类型之间毫无共同点 → 不要硬套泛型

> [!best] 最佳实践
> - 命名：单参数 `T`、多参数 `TKey`/`TValue`/`TResult`
> - 泛型可放在接口：`IRepository<T>`
> - 合理利用类型推断：`var repo = new Repository<Device>();`
