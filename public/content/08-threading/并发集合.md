# 并发集合

> [!plain] 白话理解
> "并发集合"是 WPF 上位机开发中的一项重要知识。在学习 WPF 上位机开发的过程中，"并发集合"是一个重要的知识点。上位机最大的噩梦：界面卡死。线程与异步就是解决这个问题的钥匙。掌握了它，你就能更好地构建工业级上位机应用程序。

> [!example] 完整示例
> **并发集合演示：BlockingCollection 实现线程安全的采集队列：**
>
> **MainWindow.xaml：**
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         Title="并发集合" Height="420" Width="460"
>         WindowStartupLocation="CenterScreen" Background="#0D1117">
>     <StackPanel Margin="15" Background="#161B22" Padding="15">
>         <TextBlock Text="并发集合演示" FontSize="16" FontWeight="Bold"
>                    Foreground="#58A6FF" Margin="0,0,0,10"/>
>         <!-- 生产 100 条数据，消费线程边取边显示 -->
>         <Button Content="启动 生产/消费（BlockingCollection）" Click="OnRunClick"
>                 Margin="0,5" Padding="8" Background="#238636" Foreground="White"/>
>         <TextBlock x:Name="LogText" Foreground="#8B949E" TextWrapping="Wrap"
>                    MinHeight="200" Margin="0,10,0,0"/>
>     </StackPanel>
> </Window>
> ```
>
> **MainWindow.xaml.cs —— 后台代码：**
> ```csharp
> using System;
> using System.Collections.Concurrent;
> using System.Threading;
> using System.Threading.Tasks;
> using System.Windows;
>
> namespace HmiDemo
> {
>     public partial class MainWindow : Window
>     {
>         // BlockingCollection 内部线程安全，支持阻塞式取数据
>         private readonly BlockingCollection<string> _queue =
>             new BlockingCollection<string>(new ConcurrentQueue<string>());
>
>         public MainWindow() => InitializeComponent();
>
>         private void OnRunClick(object sender, RoutedEventArgs e)
>         {
>             LogText.Text = "";
>
>             // 消费者线程：循环取数据，直到集合标记完成
>             var consumer = Task.Run(() =>
>             {
>                 while (!_queue.IsCompleted)
>                 {
>                     if (_queue.TryTake(out string item, 300)) // 阻塞等待最多 300ms
>                     {
>                         AppendLog($"[消费] {item}");
>                     }
>                 }
>                 AppendLog("[消费] 队列已空，消费结束");
>             });
>
>             // 生产者：向集合写入 100 条模拟数据
>             Task.Run(() =>
>             {
>                 for (int i = 1; i <= 100; i++)
>                 {
>                     _queue.Add($"数据点 {i}");
>                     Thread.Sleep(10); // 模拟采样间隔
>                 }
>                 _queue.CompleteAdding(); // 标记不再添加，消费者可结束
>                 AppendLog("[生产] 已写入 100 条数据并标记完成");
>             });
>
>             consumer.Wait(); // 等待消费者跑完再返回
>             AppendLog("生产/消费演示结束");
>         }
>
>         private void AppendLog(string line) =>
>             Dispatcher.Invoke(() => LogText.Text += line + Environment.NewLine);
>     }
> }
> ```
>

> [!best] 最佳实践
> - 编写代码时保持一致的命名规范（PascalCase 用于公共成员，_camelCase 用于私有字段）
> - 善用 Visual Studio 的智能提示和代码片段，提高开发效率
> - 每个关键代码块加上注释，解释"为什么这样写"而不仅仅是"写的是什么"
> - 遵循 SOLID 原则，尤其是单一职责原则：一个类只做一件事
> - 经常重构：写完功能后回头看看有没有更简洁的写法
