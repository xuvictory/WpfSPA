# 资源字典

> [!plain] 白话理解
> 如果所有资源都写在 App.xaml 或 MainWindow.xaml 里，当项目超过 10 个页面时，这些 XAML 文件就会变得又长又难维护——翻来翻去找一个颜色定义就像大海捞针。**资源字典（ResourceDictionary）**就是把这些分散的资源"抽"出来，放进独立的 `.xaml` 文件里，然后在需要的地方通过 `MergedDictionaries`（合并字典）引入。就像把代码从一个大文件拆成多个 class 一样——一个 xaml 文件管颜色，一个管样式，一个管模板，各自独立、各司其职。

> [!def] 官方定义
> `ResourceDictionary` 是 WPF 中存储资源的键值对容器，继承自 `IDictionary` 和 `ISupportInitialize`。它是一个独立的 XAML 根元素（无需依附于 FrameworkElement），可以放在单独的 `.xaml` 文件中。通过 `ResourceDictionary.MergedDictionaries` 属性，可以将多个 ResourceDictionary 按顺序合并到一个逻辑字典中。合并时按照添加顺序查找，后添加的字典中相同 key 的资源会遮蔽先添加的。

> [!origin] 由来背景
> WPF 项目变大后，App.xaml 和 Window 的 `<Resources>` 块会迅速膨胀到几百行。微软设计了 `MergedDictionaries` 机制——它本质上是资源字典的"组合模式"（Composite Pattern）。你可以把颜色定义放在 `Colors.xaml`，把按钮样式放在 `ButtonStyles.xaml`，把数据模板放在 `DataTemplates.xaml`，然后在 App.xaml 中一次性引入。当需要给某个模块换皮肤时，只需要替换对应的字典文件。

> [!essentials] 核心要点
> - **独立 XAML 文件**：根元素是 `<ResourceDictionary>`，无需依附 FrameworkElement
> - **通过 MergedDictionaries 合并**：`<ResourceDictionary.MergedDictionaries>` 内按顺序添加，后添加的优先级更高
> - **合并顺序决定优先级**：如果多个字典有相同 key，最后合并的字典中的值生效
> - **支持代码加载**：`ResourceDictionary` 可从文件路径、Pack URI、流等来源加载
> - **Application 的合并入口**：通常在 `App.xaml` 的 `Application.Resources` 中合并所有子字典
> - **页面级合并也可用**：Window/UserControl 内也可通过 MergedDictionaries 引入局部字典

> [!example] 完整示例
>
> 下面展示一个上位机项目中资源字典的典型组织方式。

> **项目文件结构**
> ```
> HmiDemo/
> ├── App.xaml
> ├── MainWindow.xaml
> └── Themes/
>     ├── Colors.xaml           ← 颜色定义
>     ├── Brushes.xaml          ← 画刷定义（引用 Colors）
>     ├── Typography.xaml       ← 字体大小定义
>     ├── DeviceCardTemplates.xaml  ← 设备卡片 DataTemplate
>     └── IndustrialTheme.xaml  ← 汇总字典（合并以上所有）
> ```
>
> **Themes/Colors.xaml** — 颜色常量
> ```xml
> <ResourceDictionary xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>                     xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml">
>     
>     <Color x:Key="ColorPageBg">#0D1117</Color>
>     <Color x:Key="ColorCardBg">#161B22</Color>
>     <Color x:Key="ColorAccent">#FF6B35</Color>
>     <Color x:Key="ColorSuccess">#3FB950</Color>
>     <Color x:Key="ColorWarning">#FFA726</Color>
>     <Color x:Key="ColorDanger">#CC2222</Color>
>     <Color x:Key="ColorTextPrimary">#E6EDF3</Color>
>     <Color x:Key="ColorTextSecondary">#999999</Color>
>     <Color x:Key="ColorBorderNormal">#2A4A6C</Color>
>     
> </ResourceDictionary>
> ```
>
> **Themes/Brushes.xaml** — 画刷定义（用 Color 资源构造画刷）
> ```xml
> <ResourceDictionary xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>                     xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml">
>     
>     <SolidColorBrush x:Key="PageBackgroundBrush"
>                      Color="{StaticResource ColorPageBg}"/>
>     <SolidColorBrush x:Key="CardBackgroundBrush"
>                      Color="{StaticResource ColorCardBg}"/>
>     <SolidColorBrush x:Key="AccentBrush"
>                      Color="{StaticResource ColorAccent}"/>
>     <SolidColorBrush x:Key="SuccessBrush"
>                      Color="{StaticResource ColorSuccess}"/>
>     <SolidColorBrush x:Key="WarningBrush"
>                      Color="{StaticResource ColorWarning}"/>
>     <SolidColorBrush x:Key="DangerBrush"
>                      Color="{StaticResource ColorDanger}"/>
>     <SolidColorBrush x:Key="TextPrimaryBrush"
>                      Color="{StaticResource ColorTextPrimary}"/>
>     <SolidColorBrush x:Key="TextSecondaryBrush"
>                      Color="{StaticResource ColorTextSecondary}"/>
>     
> </ResourceDictionary>
> ```
>
> **Themes/Typography.xaml** — 字体与尺寸
> ```xml
> <ResourceDictionary xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>                     xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>                     xmlns:sys="clr-namespace:System;assembly=mscorlib">
>     
>     <sys:Double x:Key="FontSizeXs">10</sys:Double>
>     <sys:Double x:Key="FontSizeSm">12</sys:Double>
>     <sys:Double x:Key="FontSizeMd">13</sys:Double>
>     <sys:Double x:Key="FontSizeLg">16</sys:Double>
>     <sys:Double x:Key="FontSizeXl">20</sys:Double>
>     
>     <FontFamily x:Key="MonoFont">Consolas</FontFamily>
>     <Thickness x:Key="CardInnerPadding">12,10,12,10</Thickness>
>     <CornerRadius x:Key="CardRadius">6</CornerRadius>
>     
> </ResourceDictionary>
> ```
>
> **Themes/DeviceCardTemplates.xaml** — 设备卡片模板
> ```xml
> <ResourceDictionary xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>                     xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>                     xmlns:local="clr-namespace:HmiDemo">
>     
>     <DataTemplate x:Key="DeviceCardTemplate">
>         <Border Background="{StaticResource CardBackgroundBrush}"
>                 CornerRadius="{StaticResource CardRadius}"
>                 Padding="{StaticResource CardInnerPadding}"
>                 BorderBrush="{Binding StatusColor}"
>                 BorderThickness="1"
>                 Margin="5">
>             <StackPanel>
>                 <StackPanel Orientation="Horizontal">
>                     <Ellipse Width="8" Height="8" Fill="{Binding StatusColor}"/>
>                     <TextBlock Text="{Binding Name}"
>                                Foreground="{StaticResource TextPrimaryBrush}"
>                                FontWeight="Bold" Margin="6,0,0,0"
>                                FontSize="{StaticResource FontSizeMd}"/>
>                 </StackPanel>
>                 <TextBlock Margin="0,6,0,0"
>                            FontSize="{StaticResource FontSizeSm}">
>                     <Run Text="{Binding ParamName}" Foreground="{StaticResource TextSecondaryBrush}"/>
>                     <Run Text=": " Foreground="{StaticResource TextSecondaryBrush}"/>
>                     <Run Text="{Binding ValueDisplay}" Foreground="{StaticResource SuccessBrush}"/>
>                     <Run Text=" " Foreground="{StaticResource TextSecondaryBrush}"/>
>                     <Run Text="{Binding Unit}" Foreground="{StaticResource TextSecondaryBrush}"/>
>                 </TextBlock>
>             </StackPanel>
>         </Border>
>     </DataTemplate>
>     
> </ResourceDictionary>
> ```
>
> **Themes/IndustrialTheme.xaml** — 汇总字典
> ```xml
> <ResourceDictionary xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>                     xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml">
>     <ResourceDictionary.MergedDictionaries>
>         <!-- 注意合并顺序：先合并被依赖的（Colors），再合并依赖者（Brushes） -->
>         <ResourceDictionary Source="Colors.xaml"/>
>         <ResourceDictionary Source="Brushes.xaml"/>
>         <ResourceDictionary Source="Typography.xaml"/>
>         <ResourceDictionary Source="DeviceCardTemplates.xaml"/>
>     </ResourceDictionary.MergedDictionaries>
> </ResourceDictionary>
> ```
>
> **App.xaml** — 应用入口，引入汇总字典
> ```xml
> <Application x:Class="HmiDemo.App"
>              xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>              xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>              StartupUri="MainWindow.xaml">
>     <Application.Resources>
>         <ResourceDictionary>
>             <ResourceDictionary.MergedDictionaries>
>                 <ResourceDictionary Source="Themes/IndustrialTheme.xaml"/>
>             </ResourceDictionary.MergedDictionaries>
>         </ResourceDictionary>
>     </Application.Resources>
> </Application>
> ```
>
> **MainWindow.xaml** — 使用字典中的资源和模板
> ```xml
> <Window x:Class="HmiDemo.MainWindow"
>         xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
>         xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
>         Title="设备监控面板" Height="450" Width="650"
>         WindowStartupLocation="CenterScreen">
>     
>     <Grid Background="{StaticResource PageBackgroundBrush}">
>         <Grid.RowDefinitions>
>             <RowDefinition Height="Auto"/>
>             <RowDefinition Height="*"/>
>         </Grid.RowDefinitions>
>         
>         <Border Grid.Row="0" Background="{StaticResource CardBackgroundBrush}"
>                 Padding="12,8" BorderBrush="{StaticResource WarningBrush}"
>                 BorderThickness="0,0,0,1">
>             <StackPanel Orientation="Horizontal">
>                 <TextBlock Text="📊 设备监控面板"
>                            Foreground="{StaticResource AccentBrush}"
>                            FontSize="{StaticResource FontSizeLg}"
>                            FontWeight="Bold"/>
>             </StackPanel>
>         </Border>
>         
>         <ItemsControl Grid.Row="1" Margin="15"
>                       ItemsSource="{Binding Devices}"
>                       ItemTemplate="{StaticResource DeviceCardTemplate}"/>
>     </Grid>
> </Window>
> ```
>
> **MainWindow.xaml.cs**
> ```csharp
> using System.Collections.ObjectModel;
> using System.Windows;
> 
> namespace HmiDemo;
> 
> public partial class MainWindow : Window
> {
>     public MainWindow()
>     {
>         InitializeComponent();
>         DataContext = new DeviceViewModel();
>     }
> }
> 
> public class DeviceViewModel
> {
>     public ObservableCollection<DeviceItem> Devices { get; } = new()
>     {
>         new() { Name="电机 M-101", ParamName="转速", ValueDisplay="1480",
>                 Unit="rpm", StatusColor="#3FB950" },
>         new() { Name="变频器 VFD-01", ParamName="电流", ValueDisplay="48.5",
>                 Unit="A", StatusColor="#CC2222" },
>         new() { Name="传感器 S-12", ParamName="温度", ValueDisplay="23.5",
>                 Unit="°C", StatusColor="#3FB950" },
>     };
> }
> 
> public class DeviceItem
> {
>     public string Name { get; set; } = "";
>     public string ParamName { get; set; } = "";
>     public string ValueDisplay { get; set; } = "";
>     public string Unit { get; set; } = "";
>     public string StatusColor { get; set; } = "#999";
> }
> ```
>
> 文件层级关系：
> - `Colors.xaml`→`Brushes.xaml`→`Typography.xaml`→`DeviceCardTemplates.xaml`
> - `IndustrialTheme.xaml` 一次性合并以上 4 个
> - `App.xaml` 只引入 `IndustrialTheme.xaml` 一个文件
> - 添加新主题时，只需创建 `CyberGreenTheme.xaml`，合并不同的颜色/画刷文件

> [!scene] 适用场景
> - ✅ 大型上位机项目——页面超过 5 个就应该拆分资源字典
> - ✅ 多主题/换肤系统——每种主题一个 Master.xaml，合并不同的子字典
> - ✅ 团队协作——设计师负责 Colors/Brushes，前端负责 Templates，各改各的文件互不影响
> - ✅ 不同模块引用不同的字典子集——报表模块引"报表字典"、监控页引"监控字典"
> - ❌ 只有一两个页面的小工具——拆分过度，一个 App.xaml 就够

> [!pitfall] 常见踩坑
> - **坑1：MergedDictionaries 中引用的字典文件路径错误**。`Source` 属性使用相对 URI，相对于当前 XAML 文件的位置。如果文件移动了，URI 不会自动更正。解决方案：尽量将字典文件集中放在 `Themes/` 目录下，用 `Source="/Themes/Colors.xaml"`（以应用根为基准）。
> - **坑2：合并顺序导致资源被错误覆盖**。后合并的字典中相同 key 会覆盖前面的。如果意外定义了两个同 key 的颜色，可能很难排查。解决方案：颜色 key 用前缀区分模块（如 `MonitorCardBg`、`ConfigPanelBg`），而非泛化的 `CardBg`。
> - **坑3：在 MergedDictionaries 字典内的字典中引用了其他字典的资源但顺序不对**。`Brushes.xaml` 引用 `{StaticResource ColorAccent}`，但 `Brushes.xaml` 内部的 `MergedDictionaries` 没有先合并 `Colors.xaml`。解决方案：在同一 `ResourceDictionary` 中先用 `<MergedDictionaries>` 引入被依赖的字典，再写自身资源。

> [!best] 最佳实践
> - 按"原子性"分层：Color → Brush → Style → Template，后层引用前层，形成清晰的依赖链
> - 用语义化 key 命名：`PageBackgroundBrush` 而非 `DarkGray`，未来改成别的颜色不用改 key
> - 为上位机的不同页面建立专属模板字典：`MonitorTemplates.xaml`、`ConfigTemplates.xaml`、`AlarmTemplates.xaml`
> - 用 `打包 URI` 引用字典：`Source="pack://application:,,,/Themes/Colors.xaml"` 确保路径无误

> [!practice] 上手练习
> - **Lv.1 照猫画虎**：创建一个 `MyColors.xaml` 字典文件（5 个颜色）和一个 `MyStyles.xaml`（引用 MyColors 中的颜色做 3 个样式），在 App.xaml 中合并并在页面中使用
> - **Lv.2 小试牛刀**：实现双主题切换——创建 `LightTheme.xaml` 和 `DarkTheme.xaml` 两个汇总字典，在代码中通过替换 `Application.Current.Resources.MergedDictionaries` 来切换
> - **Lv.3 融会贯通**：搭建一个模块化的资源管理系统——每个功能模块（监控、配置、报警、报表）都有自己的资源字典，App 启动时按需加载（而不是全量合并），避免内存浪费
