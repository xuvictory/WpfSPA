# 什么是数据绑定

> [!plain] 白话理解
> 数据绑定是 WPF 最"神奇"的特性——你不需要写一行 `txtName.Text = user.Name` 这样的赋值代码，只要在 XAML 里写 `{Binding Name}`，UI 就自动和数据联动了。数据变了，UI 自动刷新；UI 被用户修改了，数据自动更新。就像 Excel 中的公式单元格——=A1+B1——当 A1 变时结果自动变。WPF 的数据绑定就是 UI 和代码之间的"公式管道"，它把"手动同步数据和界面"这件费时费力的事彻底自动化了。

> [!def] 官方定义
> 数据绑定（Data Binding）是 WPF 中连接 UI 元素与数据源的核心机制。它由四个要素构成：绑定目标（Binding Target，必须是依赖属性）、绑定源（Binding Source，可以是任何 CLR 对象）、绑定路径（Path，源对象上的属性名）和绑定模式（Mode，控制数据流向）。绑定模式有五种：OneWay（源→目标）、TwoWay（双向）、OneTime（仅初始化一次）、OneWayToSource（反向）、Default（由目标依赖属性的元数据决定）。数据绑定通过 `Binding` 标记扩展在 XAML 中声明，或通过代码创建 `Binding` 对象。

> [!origin] 由来背景
> 在 WinForms 时代，数据绑定几乎不可用——`DataBindings.Add("Text", dataSource, "Name")` 这种写法又脆弱又难调试。WPF 团队认识到，要让声明式 UI（XAML）真正有价值，必须重新设计数据绑定系统。
>
> 于是他们打造了三层架构：
>
> (1) `Binding` 类负责声明绑定关系；
>
> (2) `BindingExpression` 负责运行时评估绑定；
>
> (3) `DependencyProperty` 负责值存储和变化通知。
>
> 这个设计使数据绑定精度从 WinForms 的"属性名字符串"提升到了"编译时可检查的强类型路径"（配合 LINQ 表达式树）。后来的 UWP、WinUI、MAUI 完全沿用了这套机制。

> [!essentials] 核心要点
> - **四大要素**：Target（提示依赖属性）、Source（数据来源）、Path（哪个属性）、Mode（数据方向）
> - **自动同步**：双向绑定下，UI 修改 → 数据更新；数据变化 → UI 刷新
> - **需通知机制**：数据源实现 `INotifyPropertyChanged`，否则单向绑定只获取初始值
> - **五大模式**：OneWay、TwoWay、OneTime、OneWayToSource、Default
> - **Binding 是标记扩展**：XAML 中 `{Binding Path=Name}` 或简写 `{Binding Name}`

> [!example] 完整示例
>
> 一个上位机设备数据监视面板——数据绑定 + INotifyPropertyChanged 实时刷新：
>
> **DeviceDataViewModel.cs**
 ```csharp
using System;
using System.ComponentModel;
using System.Runtime.CompilerServices;
using System.Threading.Tasks;

namespace HmiDemo;

public class DeviceDataViewModel : INotifyPropertyChanged
{
    private string _deviceName = "电机 M-101";
    public string DeviceName
    {
        get => _deviceName;
        set { _deviceName = value; OnPropertyChanged(); }
    }

    private double _temperature;
    public double Temperature
    {
        get => _temperature;
        set { _temperature = value; OnPropertyChanged(); }
    }

    private double _pressure;
    public double Pressure
    {
        get => _pressure;
        set { _pressure = value; OnPropertyChanged(); }
    }

    private double _speed;
    public double Speed
    {
        get => _speed;
        set { _speed = value; OnPropertyChanged(); OnPropertyChanged(nameof(Status)); }
    }

    public string Status => Speed switch
    {
        0   => "🟢 待机",
        < 800 => "🟡 低速运行",
        < 1500 => "🟠 正常运行",
        _   => "🔴 全速运行"
    };

    public DeviceDataViewModel()
    {
        // 模拟实时数据推送
        _ = SimulateData();
    }

    private async Task SimulateData()
    {
        var rng = new Random();
        while (true)
        {
            Temperature = 35 + rng.NextDouble() * 25;
            Pressure = 80 + rng.NextDouble() * 30;
            Speed = rng.Next(0, 2000);
            // ↑ 修改属性 → PropertyChanged → UI 自动刷新
            await Task.Delay(1000);
        }
    }

    public event PropertyChangedEventHandler? PropertyChanged;
    protected void OnPropertyChanged([CallerMemberName] string? n = null)
        => PropertyChanged?.Invoke(this, new PropertyChangedEventArgs(n));
}
 ```
>
> **MainWindow.xaml**
 ```xml
<Window x:Class="HmiDemo.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:local="clr-namespace:HmiDemo"
        Title="数据绑定 — 设备监视" Height="450" Width="650"
        WindowStartupLocation="CenterScreen">

    <Window.DataContext>
        <local:DeviceDataViewModel/>
    </Window.DataContext>

    <Grid Background="#0D1117" Margin="15">
        <Grid.RowDefinitions>
            <RowDefinition Height="Auto"/>
            <RowDefinition Height="*"/>
        </Grid.RowDefinitions>

        <StackPanel Grid.Row="0">
            <!-- 绑定设备名称（OneWay） -->
            <TextBlock Text="{Binding DeviceName}"
                       Foreground="#FF6B35" FontSize="18"
                       FontWeight="Bold" Margin="0,0,0,8"/>
            <!-- 绑定状态（OneWay） -->
            <TextBlock Text="{Binding Status}"
                       Foreground="White" FontSize="14"
                       Margin="0,0,0,12"/>
        </StackPanel>

        <Grid Grid.Row="1">
            <Grid.ColumnDefinitions>
                <ColumnDefinition Width="*"/>
                <ColumnDefinition Width="10"/>
                <ColumnDefinition Width="*"/>
            </Grid.ColumnDefinitions>

            <!-- 方式1：纯 TextBlock 绑定（看数据） -->
            <Border Background="#161B22" CornerRadius="8"
                    Padding="15" Grid.Column="0">
                <StackPanel>
                    <TextBlock Text="📊 实时数据（OneWay 绑定）"
                               Foreground="#3FB950" FontWeight="Bold"
                               Margin="0,0,0,12"/>

                    <TextBlock Text="温度" Foreground="#999" FontSize="11"/>
                    <!-- 绑定 + StringFormat 格式化 -->
                    <TextBlock Text="{Binding Temperature, StringFormat='{0:F1} °C'}"
                               Foreground="White" FontSize="28"
                               FontWeight="Bold" FontFamily="Consolas"
                               Margin="0,0,0,15"/>

                    <TextBlock Text="压力" Foreground="#999" FontSize="11"/>
                    <TextBlock Text="{Binding Pressure, StringFormat='{0:F1} bar'}"
                               Foreground="White" FontSize="28"
                               FontWeight="Bold" FontFamily="Consolas"
                               Margin="0,0,0,15"/>

                    <TextBlock Text="转速" Foreground="#999" FontSize="11"/>
                    <TextBlock Text="{Binding Speed, StringFormat='{0:F0} RPM'}"
                               Foreground="White" FontSize="28"
                               FontWeight="Bold" FontFamily="Consolas"/>
                </StackPanel>
            </Border>

            <!-- 方式2：TextBox 双向绑定（可编辑） -->
            <Border Background="#161B22" CornerRadius="8"
                    Padding="15" Grid.Column="2">
                <StackPanel>
                    <TextBlock Text="✏️ 参数设置（TwoWay 绑定）"
                               Foreground="#D4A017" FontWeight="Bold"
                               Margin="0,0,0,12"/>

                    <TextBlock Text="修改设备名" Foreground="#999"
                               FontSize="11"/>
                    <!-- TwoWay 绑定：修改 TextBox → 数据更新 → 左侧标题联动 -->
                    <TextBox Text="{Binding DeviceName, UpdateSourceTrigger=PropertyChanged}"
                             Width="200" Height="28" Foreground="White"
                             Background="#0D1117" BorderBrush="#30363D"
                             CaretBrush="White" Margin="0,0,0,5"/>

                    <TextBlock Text="提示：修改上方文字，左侧标题会同步变化"
                               Foreground="#666" FontSize="11"
                               TextWrapping="Wrap" Margin="0,5,0,0"/>

                    <Separator Background="#30363D" Margin="0,10"/>

                    <TextBlock Text="数据刷新说明" Foreground="#AAA"
                               FontSize="11" FontWeight="Bold"/>
                    <TextBlock Text="• 温度/压力/转速每秒自动更新"
                               Foreground="#999" FontSize="11"/>
                    <TextBlock Text="• ViewModel 属性变化通知 UI"
                               Foreground="#999" FontSize="11"/>
                    <TextBlock Text="• StringFormat 绑定中直接格式化"
                               Foreground="#999" FontSize="11"/>
                </StackPanel>
            </Border>
        </Grid>
    </Grid>
</Window>
 ```
>
> 运行后：温度/压力/转速每秒自动变化——ViewModel 属性 set → PropertyChanged → Binding → UI 自动刷新。修改设备名 → 左侧标题同步变化——TwoWay 绑定。

> [!scene] 适用场景
> ✅ 上位机数据监控——所有的实时数据显示都用 Binding
> ✅ 表单输入——用户修改 TextBox，ViewModel 自动收到数据
> ✅ 控件间联动——Slider 值绑定到 ProgressBar
> ✅ 列表显示——ItemsControl/DataGrid 绑定集合数据
> ❌ 一次性赋值的静态文本——不需要绑定的开销

> [!pitfall] 常见踩坑
> 坑 1：**绑定不更新——数据源没实现 INotifyPropertyChanged** → 这是新手最常见的问题。数据变了 UI 不动，因为 WPF 不知道数据变了。解决方案：ViewModel 实现 `INotifyPropertyChanged`，每次 setter 中调用 `OnPropertyChanged()`。
>
> 坑 2：**双向绑定修改了属性但源不更新——UpdateSourceTrigger 默认是 LostFocus** → TextBox 默认在失去焦点时才更新数据源。解决方案：加 `UpdateSourceTrigger=PropertyChanged` 实时同步。
>
> 坑 3：**DataContext 设为 null 后所有绑定失效** → `DataContext` 沿树继承——如果在子控件中错误覆盖了 DataContext，所有子绑定都会断。

> [!best] 最佳实践
> - ViewModel 中所有要被绑定的属性都加 `OnPropertyChanged()` 通知
> - 只读数据用 OneWay 绑定，可编辑数据用 TwoWay
> - StringFormat 直接在 XAML 绑定中做格式化，不要创建额外的格式化属性
> - 数据绑定调试失败时，先检查 Output 窗口的绑定错误信息
